## 二、结论与拆分建议

估算约 **4250 行**，远超 1500 行上限；BE-15a 的豁免（DEC-597）只给 #400，本单不适用。

建议按派发单推荐的方式拆为两单，各约 2000 行，仍超 1500 行，因此每单开工时再各自估算，必要时再拆测试：

- **BE-15b1：考核对象 + PB-R4～R6 + “考核中”视图 + PB-R9 检查点 + 并行规则**
  覆盖 AC-PB-01、02、03、10，约 2250 行（含该部分测试约 650 行）。
- **BE-15b2：自动发起考核 + 每日批次 + PB-R20 / R21 考核类失败条件 + F-223**
  覆盖 AC-PB-06、08、11（考核部分）、12，约 2000 行（含该部分测试约 550 行）。
  AC-PB-08 依赖 b1 的考核对象；F-223 的“锁内复核读最新规则状态”改动面在 `auto-regularization.ts`，与 b2 同属自动执行骨架，放 b2。

若 b1 仍超 1500 行，可进一步拆为 b1a“考核对象 + 审批适配器 + 转正生成 + 视图”和 b1b“PB-R9 检查点 + 并行规则”（后者约 230 行 + 测试约 250 行，独立可测）。
