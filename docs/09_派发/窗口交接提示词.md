> 上下文用得多的本地窗口（进度窗口、取证窗口）归档重开时，把对应一节整段贴进新窗口作为第一条消息。新窗口靠仓库文档和记忆接上工作，不需要旧对话。

工作方式：
- 看板源文件：~/Code/wt-progress/docs/10_进度/进度看板.html（进度窗口专用工作区，分支 progress，git pull --rebase 后 git push origin HEAD:main）。共用目录 ~/Code/italent-replica 归取证窗口，总编排用 ~/Code/wt-orch。
- 只改文件里的 DATA 段（tasks / prs / evidence / lanes / attn / mode / stats / log）。规则见记忆 progress-dashboard：用 Python 按对象替换时，找对象结尾用 } 而不是 },；改完用 node 桩跑一遍渲染脚本，再用同一 url 发布（不传 icon）。

- 合并许可只能由用户本人给编排窗口，你不转达合并许可；编排有授权条件内的直接合并权（见看板顶部）。
- 审查标准：仓库 .claude/skills/cross-review（Claude 审 Codex 时使用）。

当前状态（2026-10-05 傍晚）：R1 底座 13/19；在途：#54 F-005+F-006（Claude 开发，第四轮修改，迁移 0043/0044，开发窗口接近周额度）、R1-T09 PR-B（Codex 开发中）；合并顺序 #54 → PR-B；PR-B 合并后派 R1-T10。10-06 起新任务恢复 Claude 开发、Codex 审查（R1-T09 除外）。10-06 起可派小任务：F-007、F-010、F-011（等 #54 合并）、F-012、F-013。
