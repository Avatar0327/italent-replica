## 2. 车道之间的契约：先合并一个小 PR（由 Claude 车道提交）
T02 的数据范围要引用组织，并处理“包含下级”；这需要读组织层级，而组织层级由 T03 实现。所以先由 Claude 车道提交一个契约 PR：`claude/contract-org-hierarchy`。它只包含接口，不含实现，合并后两边才开工：
- `packages/domain/src/contracts/org-hierarchy.ts`：
  - 接口 `OrgHierarchyReader`：按租户、维度（行政 / 业务 / 财务…）、时点，返回某组织的所有下级 ID，以及某组织是否启用；
  - 类型 `OrgId`、`OrgDimension`。
- T02 在测试里用内存桩实现这个接口；T03 负责真实实现，并在自己的 PR 里加一条契约测试，证明实现满足接口。

## 3. Claude 车道任务
### R1-T01 权限模型
- 规格：
  - `docs/04_路线图/01` 的 R1-T01 行；
  - `docs/03_需求基线/02_需求基线_R1底座.md` REQ-PRM-001；
  - `docs/02_业务建模/04_权限模型_官方规则结构.md`、`06_权限模型_运行实证.md`（§7：8 类管理员、身份对象权限）；
  - `03_需求基线/01_角色与权限实测矩阵.md`。
- 相关决策：DEC-020（自动身份 + 可选扩展身份）、DEC-039（身份权限导入导出）、DEC-042（多身份权限取并集）。
- 要点：
  - 三层：平台运营 / 租户管理 / 业务角色；
  - 身份按“身份 × 应用”授权；
  - **功能权限与数据权限分表存放**；
  - 身份对象权限分三类：字段查看 / 编辑、按钮编码 × 级别、增删改开关。
- 验收：AC-PRM-01~08、19~23（以追溯表为准）。
- 与 R1-T00 的衔接：替换 T00 里的“授权钩子”（代码中注释为“R1-T01 接入”），默认拒绝。

### R1-T02 数据范围
- 规格：
  - R1-T02 行；
  - REQ-PRM-002；
  - `docs/02_业务建模/11_数据权限模型.md` §10/§12/§13/§14。
- 相关决策：DEC-043（数据范围按“用户 × 应用”存一份，撤销身份后不回滚）、DEC-057（审批人最小披露）。
- **硬规则**：
  - 数据范围默认**为空**（fail-closed）；
  - 身份与数据范围**多对一**；
  - 撤销身份不连带删除范围；
  - 管理员也不能在代码里写死“全部组织”。
- 验收：AC-PRM-03~07、14~18、21、29。

## 4. Codex 车道任务
### R1-T03 组织对象
- 规格：
  - R1-T03 行；
  - `docs/03_需求基线/03_需求基线_组织审批调动.md` REQ-ORG-001、REQ-ORG-002；
  - `docs/02_业务建模/10_组织对象_实测规格.md`（多维度组织设置 SwitchTypes 88~92）。
- 相关决策：DEC-021（全称从租户根算起，显示层级可配）、DEC-037（排序编码照搬）、DEC-038（显示顺序固定）、DEC-040（设立日期只作记录）、DEC-060（内部 ID 与业务编码分离，导入保存原站编码映射）。
- **硬规则**：
  - 组织层级**不得**只用单一 `parent_id`，每个维度有各自的上级和顺序号；
  - 有生效 / 失效日期；
  - 编码自动生成时要预占，不能重号；
  - 所有表带 `tenant_id` 并开启 RLS（CI 守卫会检查）。
- 验收：AC-ORG-01~09、AC-ORG-12；**AC-TEN-01**（两个租户同名组织互相不可见。T00 目前用测试夹具表验证，T03 要改用真实组织表补测）。
- 还需实现契约 `OrgHierarchyReader`，并带契约测试。

## 5. 每个 PR 的通用要求（摘自 AGENTS.md §3）
1. 先把 AC 写成失败的测试（`tests/acceptance/AC-*.test.ts`），再实现。
2. `pnpm lint && pnpm typecheck && pnpm test` 本地通过；CI 全绿，包括真 PG 那个 job。
3. PR 描述写明：
   - 覆盖的 AC；
   - 未覆盖的 AC 及原因；
   - 偏离规格之处（附 DEC 编号）；
   - 参考了 `reference/` 的哪些文件；
   - 新开的 `需取证` issue；
   - 迁移是否 rebase 后重新生成过。
4. 规格没写到的地方不要猜：开 `需取证` issue，代码里留 `TODO(需取证 #n)`。
