## 2. 前端使用的接口

| 能力 | 接口 / 返回 | 前端边界 |
|---|---|---|
| 我的待办 | `GET /approval/todos` | page / pageSize；使用 instanceId 打开详情，不混用 taskId |
| 我已处理 / 我发起的 | `GET /approval/instances?role=processed\|initiated` | page / pageSize、businessId；不增加后端未支持的搜索或状态筛选 |
| 本节点表单、原值 | `GET /approval/instances/:id` 的 form.values / originals | 只显示返回的字段，不补拉业务单、人员档案或流程定义恢复隐藏内容（DEC-057） |
| 编辑元数据与任务定位 | 同一详情的 form.editMode / editableFields、taskId / retrieveTaskId | 可编辑字段不能超出已披露表单；节点编辑模式决定独立编辑或随同意提交 |
| 进度、日志 | 详情 tasks / logs；tasks / logs 分页接口 | recordsHidden 时不读取历史分页；显示服务端的节点、事件及记录，保留 DEC-115；事件时间按响应中的租户时区展示 |
| 同意 / 不同意 / 驳回 | `POST /approval/tasks/:id/approve\|disagree\|reject` | 仅按 actions 展示；不同意与驳回分别调用；驳回意见使用 comment，目标由节点配置决定，接口无可选目标参数 |
| 转交 / 加签 / 抄送 | `POST /approval/tasks/:id/transfer\|add-sign\|cc` | 输入用户账号 UUID，规范化后提交；不把员工 ID 当用户 ID；加签选项取详情最小元数据，单人节点不提供并加签；规则以服务端校验为准 |
| 申请撤回 / 催办 / 重提 | `POST /approval/instances/:id/withdraw\|urge\|resubmit` | 只展示服务端公布的动作；不支持的业务不会出现重提 |
| 审批人撤回 | `POST /approval/tasks/:id/retrieve` | 使用后端返回的 retrieveTaskId，历史隐藏时也不推断任务 ID |
| 独立编辑 / 编辑并同意 | tasks/:id/edit 或 approve 携带 fields | 仅提交允许字段的改动，显式清空为 null；不补入隐藏的嵌套属性 |

表中路径统一省略 `/api/tenant` 前缀。cancel 只是内部函数，未添加审批中心 cancel 写入口。

## 3. 错误、并发与最小披露

写命令携带实例 revision / If-Match 与 Idempotency-Key。
revision / 并发 409 后要求刷新，再由用户显式重提；其他业务类 409 显示服务端原因，不自动重试写操作。
结果未知时先回查原实例，再允许用户用相同命令 ID、载荷和 revision 重放。
原命令重放遇到确定性的 4xx 时退出结果未知，显示服务端提示并允许继续操作。
单张单据 403 / 404 清空该单详情、草稿与历史，保留列表；列表请求无权限时清空整个工作区。
显示权限提示，不补拉不可见内容。
读取开始、接受写响应与清理详情共用递增请求代次；旧 GET 的成功与错误响应均不得覆盖当前详情。
催办和权限变更即使不推进 revision，也会在接受写响应后废弃更早读取，避免恢复撤权字段或倒退审批状态。
租户切换取消读取并重建工作区，避免旧租户响应回填。
业务日期保留接口值，事件时间按服务端返回的租户时区展示，不使用浏览器本地时区。
