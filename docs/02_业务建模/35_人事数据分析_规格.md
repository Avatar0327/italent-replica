### 2.2 员工名册
- **员工时点名册**：选一个日期，任职、合同、组织**同时取该时点**的数据（依赖三者的时间轴，`07`、`10`、`32`）。
- 离职员工名册（含合同）、上月曾在职名册（上月末在职 + 上月离职）、员工汇报关系（一行展示整条汇报链）、管理幅度统计。

### 2.3 流动情况
- 员工流动统计：按一级组织，年初人数、本年流入（按人员来源展开）、内部调动（按异动类型）、流出、年底人数；**净增长率 = (年底 − 年初) × 2 / (年初 + 年底)**。
- 各月 / 各机构入离职：**离职率 = 离职人数 / (期初 + 期末) × 2**。
- 流入 / 流出按 职务序列、职级、工作地点 三维。

## 补充：流动情况各报表的算法（Q-M0-123 ③，2026-10-08，A0，只读）
来源：组织员工 → 数据分析 → 流动情况。每个页签都是 Ocean 自由报表，数据以电子表格包（zip）返回，单元格公式可直接读出。筛选条件取自 `ReportFilterApi/ReportRunFilter`。

| 页签 | 结构 | 公式 / 口径 | 默认筛选 |
|---|---|---|---|
| 员工流动统计（本年总体流动分析） | 一级组织 × 年初人数、本年入职、本年调动、本年离职、年底人数、净增长人数、绝对增长率、累计人员变动量；可按组织层级下钻 | 净增长 = 年底 − 年初；**绝对增长率 = 净增长 × 2 ÷ (年初 + 年底)**；累计人员变动量 = 入职 + 调动 + 离职 | 参数-本年 = 今年；雇佣关系 ∈ 内部员工、实习生；部门；另带“任职记录-开始日期 = 2023-12-01～2023-12-31”（疑似保存过的旧筛选，导致当日数字很小） |
| 各月入离职统计 | 1～12 月 × 期初人数、入职人数、离职人数、期末人数、离职率 | **离职率 = 离职 ÷ (期初 + 期末) × 2**（IFERROR 为 0） | 数据集“部门人数”：期初日期、部门 |
| 各机构入离职统计 | 一级机构 × 同上五列（指定年、月） | 同上 | 同上 |
| 员工流入统计 | 职务序列 × 合计、性别、学历（博士 / 硕士 / 本科 / 大专及以下）、年龄段（25 以下 / 25-30 / 31-35 / 36-40 / 41-50 / 51 及以上）、平均年龄 | 计数 | 雇佣关系 ∈ 内部员工、实习生；任职记录-开始日期（本年）；部门 |
| 员工流出统计 | 离职类型 × 离职原因 × 人数（合计 = SUM）；职务序列 × 性别、学历、司龄段（6 月以下 / 6 月~1 年 / 1~2 年 / 2~5 年 / 5~10 年 / 10 年及以上）、平均司龄、离职类型、离职原因、是否关键人员 | 计数 | 同流入 |
| 组织编制统计 | — | — | 编制类型 = 组织编制；是否最新版本 = 是；开始日期 ≤ 今天；结束日期 ≥ 今天 |

- F-431 实测（2026-11-01，A0，只读；结论回填 BE-13b 后续）：
  - ① 一级机构 / 一级组织取行政组织树的第一层，即根组织下面的直属组织，不看机构类型（机构大类）。
    - 证据：HRBP工作台 → 数据分析 → 流动情况 →「员工流动统计」点运行后，「一级组织」列的行是 XX集团公司(POC中勿动)、连锁集团、(勿动)YX集团、TC酒库公司、华生集团这类具体组织名称。
    - 在「组织管理 → 组织」列表里，这些组织都挂在根组织下面，机构类型却不统一：XX集团公司、连锁集团、华生集团是「部门」，同层的华夏九洲集团、PC Group 是「机构」，XX餐饮有限责任公司是「公司」。
    - 报表只列 A0 负责范围内有人员的一级组织。TC酒库公司没有出现在当前启用的根下组织里，推测已停用或已调整，报表按历史任职数据仍保留这一行。这一点未核实。
    - 「各机构入离职统计」用同一套一级机构口径，本月筛选下（期初日期 = 本月）还没有数据，所以表是空的。页面提示「该数据集每3小时更新最近12个月数据」。
    - 组织列表里另有「是否总部一级部门」字段，报表没有用它。
    - 复刻：一级机构 = 员工所在组织沿行政上级链追溯到根组织下一层的那个组织；不按机构类型筛选，不跳过类型为「部门」的节点。
  - ② 6.32 的窗口是「开始日期 最近12月（含本月）」，按自然月计，含当月。
    - 证据：在人事看板 → 人员流动分析里，把鼠标悬停在 6.32 图表的筛选图标上，提示为「累计司龄（年）小于等于 0.083；开始日期 最近X月（含本月） 12」。
    - 2026-11 查看时，窗口为 2025-12～2026-11。旁证：6.26 的横轴也是 202512～202611。
    - 筛选字段是任职记录的开始日期，不是离职日期；分组维度是「部门」，不是一级机构。
    - 「入职一个月内离职」= 累计司龄（年）≤ 0.083（约 1 个月），不是按入职日与离职日的差算天数。
    - 数据范围：负责范围内的正式员工，不含实习生。

- 当日数据（2026 年）：
  - 各月期初 / 期末在 3332～3685 之间；6 月离职 303（离职率 8.5%），7 月离职 151。
  - **某月的期初 ≠ 上月的期末**（如 6 月期初 3685，5 月期末 3509；9 月期初 3357，8 月期末 3348）。说明期初、期末是按各自日期分别取的时点人数，不是“上月期末 + 入职 − 离职”推算出来的。
  - 流出合计 515，与人事看板“本年离职 515”一致。看板口径为“按最后工作日、含退休”，两者对得上。
- 对复刻：
  - 离职率和增长率都以“平均人数 = (期初 + 期末) ÷ 2”为分母。
  - 期初 / 期末用时点切片（与 `35` 补充中的时点花名册同源）。
  - 流入 / 流出按任职记录开始日期取数，范围为内部员工 + 实习生（不含外部人员）。
