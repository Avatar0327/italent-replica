## 1. 两代盘点机制（⚠️ 关键）

| | 基于**盘点流程**（旧） | 基于**盘点模板**（新，2025-08 起推荐） |
|---|---|---|
| 切换 | 「设置 > 开关参数 > 发起方式」 | 同左 |
| 评价内容 | 流程节点上各自配置的审批详情页（表单） | 模板中的**模块**（盘点信息 / 指标评估 / 继任信息）+ 每个步骤的模块权限 |
| 状态 | 不再迭代 | 持续迭代 |

→ **复刻只做“基于盘点模板”一种**。

## 3. 规则（🟡 官方文档）

### 3.1 盘点项目
| # | 规则 |
|---|---|
| TR-R1 | 状态：**新建 → 进行中 → 已结束**；新建可编辑、启动、结束、删除；进行中可编辑、结束、删除；已结束**禁止修改**，可**重启**回到进行中 |
| TR-R2 | **删除项目前须先删除项目下全部盘点对象** |
| TR-R3 | 可见范围 = 管理单元内的项目 ∪ 上级组织**向下公开**的项目 ∪ **共享组织**对应的项目；下级组织对向下公开的项目**只读** |
| TR-R4 | 盘点计算规则可按项目统一设，也可按人设；报告模板按项目默认，可按人改 |
| TR-R5 | 场景化创建（盘点场景 + 场景步骤）：人才盘点 → 填项目 → 选人才标准 → 选工具（能力：测评 / 360 / 评价表 / 导入；潜力：测评 / 评价表 / 导入；经历、绩效：评价表 / 导入）→ 添加对象 → 启动采集。删除启用场景下的“设置人才标准 / 选取工具方法”步骤会导致无法创建项目 |
| TR-R6 | **提名盘点人员**场景：提名人在流程中提名待盘点人员（默认可提名直线下级及本人负责部门内人员）并写理由，之后一键加入正式盘点项目 |
| TR-R7 | 创建项目时自动带上租户内所有启用的九宫格，可增删 |

### 3.2 盘点对象
| # | 规则 |
|---|---|
| TR-R8 | 添加方式：手动（选管理范围内员工，必选**盘点模板**，可选“是否引入最近一次盘点结果”）、从其他项目添加（按身份：盘点对象 / 继任者 / 被提名人 / 提名人，**按操作人管理单元过滤**，**同一人不重复添加**）、导入 |
| TR-R9 | **带入上次结果**：“上次” = 当前项目开始时间之前、开始时间最近的项目（开始时间倒序，再按结束时间倒序），排除「不包含的盘点项目分类」；按字段映射规则复制（来源与目标字段**类型相同**；枚举编码一致；Lookup 视图一致）；预置一条“标签 → 标签”映射 |
| TR-R10 | 盘点对象可一键加入**人才评定活动**（需先有申请类别 / 级别或职级），校验同人才评定提名（`24` EV-R22） |

### 3.3 盘点模板
| # | 规则 |
|---|---|
| TR-R11 | 模板三步：基本信息（名称唯一、盘点流程必填、所属组织、向下公开、状态）→ 模块设置 → 权限设置（按流程步骤） |
| TR-R12 | 已被盘点项目使用的模板**不能删除**；上级公开的模板下级管理员**不能编辑或删除**；复制模板时须重选流程，**权限设置恢复默认** |
| TR-R13 | 模块类型：**盘点信息**（各步骤显示不同表单，如员工自评：近三年贡献、发展方向、调动意愿；上级：优势、待发展项、业绩 / 能力 / 绩效 / 潜力）、**指标评估**、**继任信息** |
| TR-R14 | 指标评估的指标来源：**任职资格**（按指标类型或指标评价）或**人才标准**（按盘点对象主职最新生效任职的职位 / 职务绑定的人才标准，或指定一个人才标准；可选 能力 / 潜力 / 经历 维度） |
| TR-R15 | 算分方式：加权求和、算术平均、算术求和、**按指标数目**（按评价结果数目匹配模块等级，如“做到 ≥10 项 = 高”；此时评价规则只能选等级类） |
| TR-R16 | 步骤权限：每个步骤 × 角色 × 模块设 可见、评分（启用 / 必填）、评语（启用 / 必填）、**节点权重**；同一模块各评分步骤权重之和须 = 100%，否则模板报配置错误（模块名旁红色感叹号） |
| TR-R17 | 步骤类型：**盘点评价**（多人评估步骤只能是此类型）或**审核校准**；盘点方式：**单人**或**多人批量**（多人评估步骤只能单人） |
| TR-R18 | 多人评估步骤 = 审批流中的**会签**节点，需先添加盘点角色再按角色配权限 |
| TR-R19 | 盘点结果设置：用公式把一个或多个**模块结果**（得分或等级）写入盘点字段（如 专业力 = avg(专业知识, 专业技能) → 高 / 中 / 低） |
| TR-R20 | 评价规则：数值类（最小分、最大分，最大 > 最小）或等级类（等级名 + 对应分值，下拉或平铺，可启用“无法评价”——不参与计算）；已被使用的规则不能删；**修改规则或模块等级不影响已发起的盘点** |

### 3.4 算分（246809029）
| # | 规则 |
|---|---|
| TR-R21 | 数值打分取分值，等级打分取等级对应分值；“无法评价”、未评价的指标不参与计算 |
| TR-R22 | **指标结果分 = Σ(各执行人打分 × 步骤评价权重) / Σ步骤评价权重**（只计有评分权限的步骤） |
| TR-R23 | 模块结果分：算术平均 = Σ指标结果分 / 有效指标数；算术求和 = Σ指标结果分；加权求和 = Σ(结果分 × 指标权重) / Σ有效指标权重；按指标数目 = 取**最后一个**有有效评价且有评分权限的步骤的结果 |
| TR-R24 | 多人评估：指标角色分 = 该角色所有有效评分的平均，再按模块算分规则得模块角色分 |
| TR-R25 | 触发时机：失焦 → 算当前执行人步骤分和结果分；保存 / 提交 / 节点结束 → 另跑计算规则；审批“不同意” → 流程结束，当前步骤评分失效；管理员可随时手动“开始计算” |
| TR-R26 | 管理员可调整单个指标结果（按数目算分的模块调等级，否则调得分），调整后**不自动重算**，需手动开始计算 |

### 3.5 盘点计算规则（外部结果取数）
| # | 规则 |
|---|---|
| TR-R27 | 计算规则 = 多个**计算项目**（盘点字段 + 优先级（数字越小越先算）+ 公式）；项目间有依赖时靠优先级串行 |
| TR-R28 | 预置取数函数：最近一次 360（问卷 / 维度 / 题目 × 自评 / 他评 / 角色分，“最近” = 盘点项目**结束时间前**最近开始的 360 活动）；测评 `LastestAssessmentCent(测验信息.总分|维度得分|…, 过滤条件)`（“最近一次”口径两处文档不一：结束时间前 / 开始时间前；复刻做成参数，默认结束时间前，DEC-031）；绩效 `PerformanceCent/Grade(年度, 周期)`（同年同周期多条取子集**最后修改**的）、`PerformanceLastCent/Grade(N)`（最近第 N 年，不要求连续年份，无结果返回空而非 0）；**排名** `Ranking(百分位|排序号, 字段, 范围…)` |
| TR-R29 | 计算失败常见原因：空值参与比较（须 ToNumber）；单选列表须按选项值而非文本比较 |
| TR-R30 | 流程中保存时只在公式依赖字段**发生变化**时才触发；排名函数不建议在流程中触发 |

### 3.6 九宫格
| # | 规则 |
|---|---|
| TR-R31 | 预置两个：**业绩-能力**、**绩效-潜力**；可自定义 X / Y 轴（任意盘点字段，含自定义）、第三维度、格子名称与颜色；每个九宫格须指定**格子位置字段**（校准前 / 校准后分别存储），**不同九宫格不能共用同一个格子位置字段**（否则互相覆盖） |
| TR-R32 | 落位数据来源：仅校准前 / 仅校准后 / **有则校准后，无则校准前** |
| TR-R33 | **比例规则**：一个九宫格可有多组规则（一组为默认）；每条 = 格子集合 + 运算符（>、<、≥、≤、范围（含边界））+ 百分比；**组内规则为“且”**；控制范围：盘点项目和校准会（结束时校验）/ 盘点流程（提交时校验）；控制方式：仅提示 / 提示且不允许提交（或结束）；可设起始人数（落位人数小于它时不校验）；**状态为“终止”的对象不计入** |
| TR-R34 | 比例计算范围 = 当前用户数据权限内的人；有部门筛选时另显示“整体比例异常 N” |
| TR-R35 | 绿化率：九宫格可设为绿化率参考，并勾选计入绿化率的格子；**绿化率 = 计入格子人数 / 该九宫格落位总人数**，显示在组织继任地图 |
| TR-R36 | 盘点评价页只显示 X、Y、第三维度对当前执行人**都可见**的九宫格 |

### 3.7 校准会与结果审批
| # | 规则 |
|---|---|
| TR-R37 | 校准会关联一个盘点项目；添加对象时同步该项目中对象的最新结果；可从项目勾选对象一键发起（跨页全选时异步处理，结果以消息与报告返回） |
| TR-R38 | 九宫格拖拽校准：轴允许拖拽且视图配置了编辑按钮时可直接拖；“校准原因”区块有必填字段时，拖拽会弹出校准原因表单，否则**实时保存**；记录校准路径 |
| TR-R39 | 校准中记录校准原因、优势项、待发展项、发展建议、备注，保存时**同步回盘点项目**；结束校准会后校准结果同步到盘点项目与报告 |
| TR-R40 | 校准会九宫格默认用来源项目该九宫格的比例规则；比例按校准会自身落位计算 |
| TR-R41 | 结果审批：管理员对管理范围内的项目发起，审批人可查看 / 编辑结果；审批明细保存结果快照（`CalibrationApproveDetail`） |
| TR-R42 | 从九宫格勾选人员**加入人才池**（统一设置或逐人设置 指导人角色、准备度；逐人值优先），字段按“储备人才字段映射”带入（来源为盘点继任信息时取**最早创建**的一条） |

## 7. 盘点对象状态（🟢 本租户只读抽样，G-052）

### 8.2 空值语义（Q-M0-78）
- 🟡 通用公式编辑器：字段为空时按类型赋默认值（数值 0、是否 False、文本 ""、日期 0001-01-01）；是否类型字段为空时按“否”判断（171640267），需要区分时用 `是否为空()`。
- 🟡 盘点计算规则：取数函数**取不到数据时返回空，不自动当 0**；空值参与大于 / 小于比较、求平均会让该对象“计算失败”（207126957 问题 1、210929396 §4）。官方解法是先 `ToNumber(…)` 转换（推定 `ToNumber(空)` = 0），或 `Def` 变量后再 `ToNumber`。
- 🟡 人员范围：计算规则圈定了人员范围时，范围外的人不出值（207126957 问题 2）。
- 精确行为（空值参与四则的结果、`ToNumber(空)` 是否为 0、`Average` 是否跳过空）需要在原站建规则试算，列为后续 Q-M0-95。

- 🟡 字符串参与四则运算或类型转换会导致无结果；数字字段建议 `ToNumber`。
- 🟡 单选列表字段按**选项值**比较和赋值（如“高”= 3），不是按显示文本。
