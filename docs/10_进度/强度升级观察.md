# 强度升级观察记录（DEC-268 补充，2026-10-07 用户定）

> **10-07 DEC-273 修订**：不再“超过 3 轮自动升 Max”，改为**按问题难度**由审查合并窗口判断档位（例：#96 第 5 轮改动小，用户定 Fable High）。下文原规则仅作历史记录；观察表继续记录每次档位与结果，用于总结“难度 × 档位 × 结果”。

原规则（已修订）：开发或审查超过 3 轮 → 先调到 **Max**；Max 档仍不收敛（再跑 2 轮仍有同类数据正确性 / 权限问题）→ 进度窗口建议改用 **Ultracode**（多代理编排，开销大），经用户确认后执行。换模型同样须用户确认（#99 换 Fable 用户 10-07 未同意）。
用途：积累一段时期后，按任务复杂度与结果总结“哪类任务该用 Max / Ultracode / 换模型”，给用户建议。
