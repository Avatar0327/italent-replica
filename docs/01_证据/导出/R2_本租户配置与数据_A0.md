## 4. 设置取值（2026-09-28 复核版）

### 4.0 读取方法与更正
- ⚠️ **更正**：本文件初版写的 SW 11「离职交接流程 = 未设置」、SW 41「终止在途流程 = 未勾选」**是错的**。原因：读的是表单组件上的 `biz_data`（始终为空），真实取值在 FormView 返回体**顶层的 `biz_data` 记录**里；另有截图在页面加载完成前拍摄，控件显示为默认关闭。
- 可靠方法（已用 SW 39 对照截图验证一致）：`POST /TenantBaseMRest/100000/FrontExt/GetSwitchIdAndViewName`，请求体 = 开关号字符串数组（如 `["39"]`），得到记录 ID → `GET /api/v2/UI/FormView?…&viewName=TenantBase.SwitchFormView&id=<ID>`，读顶层 `biz_data[0]` 的各字段；多开关页用 `FrontExt/GetFormBySwitchTypes`（同样的数组请求体）取各区块的记录 ID。Offer 设置走 `Offer/loadOfferManageSwitch`。规则列表类设置按页面完整加载后的文字读取。
- 注意：部分单选字段的显示文字因共用数据源而错配（如 SW 49 显示“一寸照片”、入职电子签时机显示“两寸照片”），以**取值编码**为准。
