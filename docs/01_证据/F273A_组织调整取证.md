## 1 A-4：停用方式与同步调整编制

### 1.1 停用组织弹窗（已证）

| 字段 | 控件与取值 | 证据 |
|---|---|---|
| 组织 | 当前要停用的组织 | 1_01 |
| 是否分批转移 | 单选：否（默认）/ 是。提示：否 = 统一转移到一个组织；是 = 组织及其下级的职位、任职分批转移到多个组织 | 1_04 |
| 停用组织的职位、人员转移到 | 组织选择，可不填 | 1_01、1_05 |
| 同步调整编制 | 复选框，默认不勾 | 1_01～1_06 |
| 停用方式 | 只在“同步调整编制”勾选且填了转移目标时出现，单选两项：「各上级编制同步减少」/「编制转移至目标组织」（默认后者） | 1_05、1_06 |

“同步调整编制”的提示随场景变化：

- 组织没有编制：复选框置灰，提示「此组织不存在编制，无需调整」（1_01）。
- 没有转移目标：提示「勾选后，各上级组织的【含下级编制】同步减少 N 个」，N 是被停用组织的含下级编制。E1_ORG_02 显示 8，E2_ORG_02 显示 1（1_02、1_03）。
- 有转移目标，选「编制转移至目标组织」：提示各上级组织【含下级编制】减少 N，目标组织及其各上级组织编制增加 N。问号说明「目标组织及各上级组织存在组织编制时，才会增加编制」（1_06）。

### 1.2 变更组织（划转）弹窗（已证，仅提示）

修改上级组织后出现“变更”标记，并多出必填项“是否新增任职”“新负责人的直线经理是否调整”。“同步调整编制”的提示为「原上级【…】及各上级组织编制将减少 N 个，新上级【…】及各上级组织编制将增加 N 个」，问号说明「变更后各上级组织存在组织编制时，才会增加编制」（1_07、1_08）。

待核对：同一个组织在变更弹窗里的 N（2）与停用弹窗里的 N（1）不一致，没查清是哪个口径（含下级 / 本级 / 其他）。

### 1.3 新建下级组织（拆分）（已证）

新建下级组织弹窗有「确定」和「确定并设置编制」两个按钮。后者打开新建编制表单，其中有复选框「同步更新上级组织的编制」，提示「将同步更新【ORG_01】的组织编制及组织中维度相同的细分编制」（1_09、1_10）。

同步对象不是直接上级 E1_ORG_02，而是 ORG_01，即最近一个同方案、同年度、有编制的上级。没选年度时提示「暂未匹配到上级组织编制，无需向上更新」。

### 1.4 实测：新建和停用，勾选与不勾选对照（已证）

基线（1_11）：ORG_01 含下级编制 2、本级编制 2、实有 28、缺编 -30。E1_ORG_02、E2_ORG_02 没有编制记录。

**申请 A「ZZ_F273A_编制联动A」**（生效 2026-10-19，主体组织和调整范围都是 ORG_01）

- 在 E1_ORG_02 下新建 ZZ_F273A_SPLIT_01，编制本级 1 / 含下级 1，**勾选**同步更新上级。
- 在 E1_ORG_02 下新建 ZZ_F273A_SPLIT_02，编制 1 / 1，**不勾选**。
- 审批前预览显示 ORG_01「编制 3↑1」（1_12）。
- 审批通过后显示“已执行”，提示“成功执行2个调整”。
- 执行后（1_13）：ORG_01 含下级 2 → 3，本级仍为 2，缺编 -30 → -29。两个 SPLIT 各自 1 / 1。

**申请 B「ZZ_F273A_编制联动B」**（生效 2026-10-20）

- 停用 SPLIT_01，**勾选**同步调整编制，没有转移目标（1_14）。
- 停用 SPLIT_02，**不勾选**（1_15）。
- 审批前预览显示 ORG_01「编制 2↓1」（1_16）。
- 执行后（1_17）：ORG_01 含下级 3 → 2，回到基线，缺编 -30。两个 SPLIT 的编制行都从组织编制列表消失。

**结论**

- 勾选：把被新建或停用组织的含下级编制，加到或减去最近一个有编制的上级（同方案同年度）的「含下级编制」。上级的「本级编制」不变。
- 不勾选：上级编制不变。被停用组织自己的编制行照样从列表消失，所以不勾选时上级的含下级编制里会留下差额。本例中 SPLIT_02 新建和停用都没勾选，两次都没影响上级，正好抵消。
- 审批明细列表里没有“同步调整编制”这一列，只能在明细弹窗和调整预览里看到效果。

### 1.5 未证

- 「是否分批转移 = 是」时编制怎么处理，没测。

## 3 A-18：架构图导出

- 入口（已证）：组织调整申请详情抽屉 › 调整预览 › 切到「架构图」视图 › 「导出」下拉。「树状图」视图没有导出（3_01）。
- 格式（已证）：「PNG图片下载」「SVG图片下载」两项（3_02）。
- 内容（部分已证）：架构图上方有「展示调整后架构」复选框，用来切换调整前 / 调整后；预览里用标记显示差异，例如「编制 3↑1」、「停用」标签（1_12、1_16）。导出文件是不是跟随这个开关，**没有下载核对**，下载需要用户明确同意。
- 权限（未证）：候选编码是 `ExportOrgApprovalDatas`（导出，应用页），但没证实它管的就是架构图导出；也可能不受按钮权限控制。
