## 路线概览

讲 360 评估管理端的三件事：套卷（含评价角色、评定等级、指标、题目）怎么建、怎么预览和启用；活动怎么新增，详情里有“基本信息 / 评价关系 / 套卷”三个页签；评价关系里评价对象和评价者怎么配，以及启用时服务端的校验。要说清边界：本页面片覆盖活动、套卷与评价关系，进程控制、作答与报告页面另行接入（后端已有对应接口）；列表按接口返回的至多 500 条分页，不捏造评价人数或进度。授权（身份与数据范围）属于 06_企业设置.md 的路线，这里不再演示。

- 授权：由系统管理员（演示）按 06_企业设置.md 末尾的授权配方，给 HR专员（演示）授予“360系统管理员 (standard_360_system_admin)”，并按（用户 × 应用）给 Survey360 设“管理单元”类数据范围（该应用不接受“组织范围”类型）。本演示库已授好，全新库（`pnpm demo:reset` 之后）需先做一遍。360 身份由企业管理员在“用户授权”里授予，不消耗许可，数据范围不预置，默认为空（fail-closed，DEC-043、DEC-280）。

## 步骤 1：评估活动页签与状态筛选

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360`，顶部三个页签“评估活动 / 套卷 / 题库 · 企业自定义”
- **操作**：点“360 评估”；看页签条；在“评估活动”下看状态页签“全部 / 草稿 / 已启用 / 已停用”并逐个点；看列表下方灰字；把鼠标停在“导出”上；再点“套卷”页签，看状态页签“全部 / 草稿 / 已启用 / 已使用”。不要点“题库 · 企业自定义”（见讲解要点）。
- **讲解要点**：原站活动以全部、草稿、已启用、已停用页签区分，详情含基本信息、套卷、评价关系，题库以企业自定义套卷模板列表呈现；我们的取舍：活动、套卷、模板、评价关系接现有接口，操作与字段由权限驱动，列表按接口返回至多 500 条分页，“筛选与分页仅作用于本次返回结果”，不捏造评价人数或进度（注释层 survey360）。三个页签是否出现取决于活动和套卷对象的查看权。“题库 · 企业自定义”页签实测打开即显示“加载失败，请稍后重试 / 页面或记录不存在”，点“新增套卷模板”能打开抽屉但保存同样报“页面或记录不存在”：前端请求 `/api/tenant/survey360/templates`，后端只登记了 `/questionnaire-templates`，路径不一致，属前端缺陷，演示时跳过，只说“题库页后续修复”。
- **预期结果**：活动列表表头“名称 / 应用场景 / 评价形式 / 状态 / 启用时间 / 停用时间 / 操作”，初始为空态“这里什么都没有…”和“共0条”；右上有“刷新”“新增活动”和灰掉的“导出”（提示“导出功能准备中”）；列表下方灰字“接口最多返回 500 条；筛选与分页仅作用于本次返回结果。”；套卷列表表头“名称 / 套卷类别 / 状态 / 操作”，右上“刷新”“新建套卷”“导出”。开启“注释”后列表上方出现“原站做法 / 我们的取舍”卡片和“DEC-464 DEC-456 DEC-280 DEC-149 L3”徽章。
- **高亮目标**：顶部三个页签；列表上方“全部 / 草稿 / 已启用 / 已停用”状态页签；右上“新增活动”按钮；列表下方“接口最多返回 500 条…”灰字。

## 步骤 2：新建套卷

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360`，页签“套卷”，右侧抽屉“新建套卷”
- **操作**：点“套卷”页签右上“新建套卷”；名称填“领导力 360 套卷”；“套卷类别”选“关键行为”（可选“关键行为 / 等级评定”）；“总分规则”选“加权平均”（可选“加权平均 / 加权求和”）；“指导语”填“请根据日常观察，客观评价被评价人的领导行为”；点“保存”。
- **讲解要点**：套卷是一组带评价角色、评定等级、指标、题目的问卷；创建时只填头部信息，内容在保存后通过“编辑”整卷提交（新建抽屉里没有内容编辑区，只有“基本信息”）。套卷状态为草稿、已启用、已使用，已使用的套卷只能改文字与权重（页面提示“已使用套卷只能修改文字与权重；启用活动引用时由服务端拒绝修改”）。创建命令未确认结果时降为 L2：重开仅可查看，不恢复在途表单（DEC-464）。
- **预期结果**：保存后抽屉关闭，列表出现“领导力 360 套卷 / 关键行为 / 草稿”，行尾有“查看”，右下“共1条”。
- **高亮目标**：“新建套卷”抽屉里的“套卷类别”“总分规则”下拉；抽屉底部“保存”；列表中新增行的“草稿”状态。

## 步骤 3：套卷内容、预览与启用

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360`，套卷详情抽屉（页签“基本信息 / 预览”，右上“刷新 / 编辑 / 启用”）
- **操作**：点套卷名称“领导力 360 套卷”打开详情抽屉；点右上“编辑”，在“题目与计分”里依次点各分组下的“添加”：“评价角色”添加三行，分别选“上级”“同事”“自评”（下拉项为自评 / 上级 / 同事 / 下级 / 客户 / 其他），权重填 50、50、0；“评定等级”添加一个，名称“五分制”，其下点“添加”五次，“选项文字 / 分值”依次填很不符合 1、不太符合 2、一般 3、比较符合 4、非常符合 5（每个选项另有“不计分”“必填说明”复选框）；“指标”添加“战略思维”（权重默认 100，“评定等级”不选）；“题目”添加“能清晰说明团队方向”，“所属指标”选“战略思维”，“评定等级”选“五分制”；点“保存”；切到“预览”页签；再点右上“启用”，在“确认操作”框点“确定”。
- **讲解要点**：内容按稳定编码引用（指标引用上级指标、题目引用所属指标与评定等级），整卷一次写入，缺失引用不会被当作空值清掉，数据不完整时页面提示“套卷引用或字段不完整，无法安全编辑”。服务端有两条实测会踩的规则：套卷类别为“关键行为”时，评定等级只能挂在题目上，挂在指标上会被拒（“只有等级评定的指标设评定等级”）；启用时“自评权重固定为 0”，否则拒绝（“套卷不满足启用条件”）。这两条拒绝页面都只显示统一的“请检查表单字段”，看不到具体原因（见“待核对”的疑似缺陷），所以演示时按上面的填法一次通过。启用会校验套卷；一旦被启用的活动引用就成为“已使用”，之后只能改文字与权重。评价角色来自租户评价角色（内置：自评、上级、同事、下级、客户、其他，首次读取时自动补齐）。
- **预期结果**：保存后“预览”页签展示指导语和四张表（评价角色、指标、题目、评定等级；评定等级行可展开看选项与分值，“权重”列显示“—”），其中“评价角色”表的角色列目前显示的是角色编号而不是名称；点“启用”后确认框正文为“启用会校验套卷与评价关系；停用会触发计分。将按当前版本提交。”，确定后抽屉里“启用”按钮消失，回列表该套卷状态为“已启用”；步骤 6 活动启用后会变成“已使用”。
- **高亮目标**：详情抽屉右上“编辑 / 启用”按钮；编辑表单里“评价角色”“评定等级”“指标”“题目”四个分组各自的“添加”；“预览”页签；“确认操作”对话框。

## 步骤 4：新增活动

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360`，页签“评估活动”，抽屉“新增活动”
- **操作**：点“新增活动”；“基本信息”分组填名称“2026 年度领导力 360”、应用场景“年度领导力盘点”、评价形式选“一次评价一人”（可选“一次评价一人 / 一次评价多人”）；“评价者作答页面设置”分组填欢迎语“感谢您参与本次 360 评估”，“作答页评价者姓名”选“显示”（另有“不显示”），“评价角色是否显示”选“显示评价角色名称”（另有“显示角色预设文本”“不显示评价角色”）；点“保存”。
- **讲解要点**：活动头部信息分基本信息和评价者作答页面设置；评价形式在活动离开草稿后不再可改（非草稿时该字段只读，现象见“待核对”）；作答页的匿名与角色展示策略（评价者姓名是否显示、评价角色是否显示）由租户在活动层配置，对应原站作答页设置。新建同样受命令保护，未确认结果时只读（DEC-464）。
- **预期结果**：保存后抽屉关闭，列表出现“2026 年度领导力 360 / 年度领导力盘点 / 一次评价一人 / 草稿 / — / —”（启用时间、停用时间为 “—”）。
- **高亮目标**：“新增活动”抽屉的两个分组标题；“评价形式”下拉；“评价角色是否显示”下拉；列表新行的“草稿”状态。

## 步骤 5：活动详情：基本信息与套卷页签

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360`，活动详情抽屉，页签“基本信息 / 评价关系 / 套卷”
- **操作**：点活动名称；在“基本信息”看字段；点“套卷”页签，读顶部说明并看嵌套的套卷列表。
- **讲解要点**：详情复用统一的右侧抽屉。活动本身不直接挂套卷：套卷通过评价对象关联到活动，页签顶部说明原文为“可选套卷库：套卷通过评价对象关联到活动，请在评价关系中为人员选取套卷。”，这里的套卷列表是可选库，不是已关联清单。右上“编辑”“启用”按权限出现。
- **预期结果**：详情抽屉标题为活动名称，右上“刷新 / 编辑 / 启用”；“基本信息”显示名称、应用场景、评价形式（一次评价一人）、欢迎语、作答页评价者姓名（显示）、评价角色是否显示（显示评价角色名称）；“套卷”页签显示套卷列表，其中有步骤 2～3 建的“领导力 360 套卷 / 关键行为 / 已启用”（列表内还有“新建套卷”按钮）。
- **高亮目标**：详情抽屉的三个页签；“套卷”页签顶部说明文字；右上“编辑”按钮。

## 步骤 6：评价关系：评价对象与评价者

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360` → 活动详情 → 页签“评价关系”，弹窗“添加评价对象”，二级抽屉“设置评价者”
- **操作**：点“评价关系”页签，读灰字说明；点“添加评价对象”，在弹窗里点开“选择人员”下拉看候选，“选取套卷”下拉选“领导力 360 套卷”；（有 360 人员时）选一位人员，点“保存”；在列表行点“设置评价者”，在抽屉里依次点“添加评价者”，选人员并选“评价角色”（上级 1 人、同事 3 人），每次点“保存”。
- **讲解要点**：评价关系 = 评价对象（谁被评）+ 评价者（谁来评、什么角色）。每个评价对象须选 1～3 个不重复的已启用套卷，否则提示“每个评价对象请选择 1～3 个不重复的已启用套卷”；设置评价者抽屉提示“建议各评价角色至少3人（上级和自评除外），以增加匿名性和准确性。”人员来自独立的 360 人员库，服务端按当前范围裁剪，这是 360 人员与组织员工分库、通过同步挂接的设计（规格 25，DEC-030 同步规则）；本页面片不带“从系统管理中同步人员信息”入口，种子也没有 360 人员，所以全新库里这一步只能演示到“选择人员”下拉为空。
- **预期结果**：评价关系页签的列表表头“评价对象 / 套卷 / 操作”，初始“暂无数据”；全新库里“选择人员”下拉为空，无法继续（数据缺口）；有 360 人员时，保存后列表出现评价对象行（如“秦俊志”），“套卷”列目前显示的是套卷编号而不是名称，行尾“设置评价者”；评价者抽屉标题“设置评价者”，表头“评价者 / 评价角色”，保存后行里显示人员姓名和角色名称（如“高嘉琳 / 上级”“罗伟帆 / 同事”）。添加评价对象保存时可能短暂闪过“处理中，请勿重复提交”。
- **高亮目标**：“评价关系”页签里的灰字“人员来自独立的 360 人员库…”；“添加评价对象”按钮及弹窗的“选取套卷”；“设置评价者”抽屉里的匿名性提示和“添加评价者”按钮。

## 步骤 7：启用活动

- **演示身份**：HR专员（演示）
- **页面与路由**：360 评估 `/survey360` → 活动详情抽屉右上按钮
- **操作**：在没有评价对象的草稿活动详情里点“启用”，在“确认操作”框点“确定”，看提示（全新库建不出评价对象，直接就是这个场景；若步骤 6 已配好评价关系，可先新增第二个活动来演示被拒，或口述）；有评价关系的活动再点“启用”确定，看状态；不要点“停用”。
- **讲解要点**：启用会校验套卷与评价关系，所以没有评价关系的草稿活动启用被服务端拒绝（原因“活动至少需要一个评价对象”，错误码 NO_OBJECT），但页面只显示统一的“请检查表单字段”，具体原因要从网络面板才看得到，这是已知缺口。停用会触发计分，确认框正文原文为“启用会校验套卷与评价关系；停用会触发计分。将按当前版本提交。”启用后生成作答链接等后续（进程控制、作答、报告）不在本页面片里。所有写操作带对象版本号，版本不一致返回 409，需刷新后显式重提，不自动盲重试（平台通用约定）。
- **预期结果**：没有评价关系时，抽屉标题下出现红色提示“请检查表单字段”（带“刷新”），活动状态保持“草稿”；评价关系配好后启用成功，抽屉右上按钮由“启用”变为“停用”，回列表状态为“已启用”，“启用时间”有值（当前显示为未格式化的 UTC 时间串，形如 2026-10-14T14:43:31.605Z），“停用时间”为 “—”；步骤 3 的套卷在套卷列表里变为“已使用”。
- **高亮目标**：详情抽屉右上“启用 / 停用”按钮；“确认操作”对话框正文；红色提示条；列表中状态与“启用时间”列。
