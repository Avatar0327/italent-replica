## 前置准备

1. 启动与重置：`pnpm demo`（写入种子并同时起后端 :3000 与前端 http://localhost:5173），出问题用 `pnpm demo:reset`，细节见 README“本地演示”章节。
2. 种子只给了组织员工应用的权限，没有任何身份拥有盘点权限。先用右上角“切换演示身份”切到 系统管理员（演示），进入 企业设置（左侧“设置”分组）。
3. 企业设置顶部导航按钮为：内部员工、全部用户、外部用户、身份管理、用户授权、管理单元、数据变更日志（按身份可见）。授权摘要如下，完整配方详见 06_企业设置.md 的授权配方：
   - 用户授权页右上“新增”→ 抽屉“新增用户授权”：填“用户编号”（本租户用户 UUID，输入框提示“输入本租户用户编号”）、在“身份”下拉选“盘点管理员（人才盘点） (standard_talent_review_admin)”→“保存”。
   - 列表行“操作”列的“数据范围”按钮（需管理单元编辑权）→ 抽屉“数据范围”：填“用户编号”、“应用编码”填 TalentReview → “查询数据范围”→“编辑”，选“组织范围”→“添加组织”，填组织编号并勾选“包含下级”→“保存”。页面提示“数据范围按‘用户 × 应用’共享；默认管理单元为空范围，撤销身份不会删除共享范围”。
   - 按预置，盘点管理员对盘点项目、盘点模板与各设置类对象预置“看全部”（DEC-415），所以多数情况下不设范围也能看到列表；若列表空白并提示“当前没有可查看的数据范围”，再按上面补一条组织范围（待核对）。
4. 授权完成后切到 HR专员（演示）。菜单“人才管理”分组出现“人才盘点”。建议打开顶部栏“注释”开关，讲解时展示“原站做法 / 我们的取舍 / DEC / 实现档位”。

- **演示身份**：HR专员（演示）

  - 页签是否出现取决于服务端权限快照里是否有对应对象（项目 / 模板 / 九宫格），前端不硬编码角色；“盘点校准会”页签随盘点项目对象一并出现。
  - 真实接口：盘点项目、盘点模板、九宫格设置三块的列表、详情、保存和状态流转都走后端；演示桩：项目详情里的八个页签内容、九宫格落位、整个“盘点校准会”页签，都是前端合成样例，页面会标“演示数据”。

- **预期结果**：默认落在“盘点项目”页签，列表为空（种子无盘点项目），视图为“进行中的盘点项目”；注释卡显示上述内容与 DEC-456 / DEC-056、L2 标签。
- **高亮目标**：页面顶部的四个页签；顶部栏右侧的“注释”开关；注释卡片。

## 步骤 2：新增盘点项目（真实接口）

- **演示身份**：HR专员（演示）
- **页面与路由**：/talent-review，“盘点项目”页签
- **操作**：
  1. 点列表右上“新增”（蓝色主按钮），右侧抽屉标题“新增盘点项目”，分组“基本信息”。
  2. 填“编码”DEMO_REVIEW_2026、“名称”2026年度人才盘点（演示）、“所属组织”选“研发中心”、“盘点年度”2026、“盘点周期”2026年度。
  3. “开始时间”选 2026-10-01，“结束时间”先故意选 2026-09-01，点“保存”看校验；再改成 2026-12-31。
  4. 可选填：“所属分类”“人才标准”“盘点计算规则”“业务日期”“向下公开”“引入上次结果”“共享组织”。
  5. 点“保存”。
- **讲解要点**：
  - 必填项是编码、名称、所属组织、盘点年度、盘点周期、开始时间、结束时间；编码规则“以字母开头，仅含字母、数字、下划线，最多50位”，名称最多 50 字；结束早于开始会提示“结束时间不能早于开始时间”。
  - 所属组织、所属分类、人才标准、盘点计算规则是下拉引用，选项来自服务端；写请求带对象 revision 与命令 ID，结果未知时提示“结果未知，请关闭表单并刷新列表，按编码或名称回查后再决定是否重新提交”，体现平台“写命令幂等 / 禁止盲重试”约定（AGENTS §10）。
  - 所属分类、盘点计算规则若租户里没有候选（种子没建），下拉为空，留空即可，不影响保存。
- **预期结果**：保存后抽屉关闭、列表刷新，出现“2026年度人才盘点（演示）”，状态“新建”，盘点年度 2026，“开始时间”2026-10-01、“结束时间”2026-12-31；“所属组织”列可能直接显示组织 ID 而非“研发中心”（注释：关联名称接口待补）；“盘点场景”“盘点报告模板”“结果审批流程”三列显示“--”。
- **高亮目标**：列表右上“新增”按钮；抽屉里的“编码”“所属组织”“开始时间”“结束时间”字段及红色校验提示；列表新出现的一行及其“状态”列。

## 步骤 3：启动、结束、重启与三种视图

- **演示身份**：HR专员（演示）
- **页面与路由**：/talent-review，“盘点项目”页签
- **操作**：
  1. 在新项目行“操作”列点“启动”→ 状态变“进行中”，操作变为“编辑”“结束”。
  2. 点列表左上视图标题处切换视图（“进行中的盘点项目 / 已结束的盘点项目 / 全部盘点项目”）。
  3. 点“结束”，在确认气泡“结束评估后，盘点项目数据禁止修改。是否继续？”点“确定”→ 项目移入“已结束的盘点项目”，操作只剩“重启”。
  4. 再点“重启”并确认，项目回到进行中；用“名称 ▾”“所属组织 ▾”“开始时间 ▾”“结束时间 ▾”或“高级筛选”演示筛选。
- **讲解要点**：
  - 状态机：新建 →（启动）→ 进行中 →（结束）→ 已结束 →（重启）→ 进行中；按钮由服务端返回的权限和项目状态共同决定，新建可“编辑 / 启动 / 结束”，进行中可“编辑 / 结束”，已结束只能“重启”。结束后数据禁止修改（原站口径）。
  - 已结束视图的列多出“共享组织”“参与人数”“应用场景”，进行中视图则是“结果审批流程”，对应原站两个视图；“盘点场景”筛选按钮灰置（暂不支持）。
  - 列表是完整读取授权结果后在前端筛选和分页，最多 4000 条，超过会报错而不是展示不完整列表（注释里写明）。
- **预期结果**：每次操作后列表自动刷新，状态列依次为“进行中”→“已结束”→“进行中”；确认气泡文案如上；视图切换时列数变化。
- **高亮目标**：项目行“操作”列的“启动”“结束”“重启”链接；确认气泡；列表左上的视图切换标题；筛选区的“高级筛选”链接。
