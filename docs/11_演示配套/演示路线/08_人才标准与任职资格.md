- **操作**：从左侧“人才管理”分组进入“人才标准”；看列表标题“指标库”和列名“名称 / 类型 / 状态 / 顺序号 / 操作”；点右上“新建”，在“新建 · 指标库”抽屉里填名称“领导力能力库”，“类型”选“能力”（可选能力 / 潜力 / 经历），顺序号 1，“状态”选“启用”，“所属管理单元”选“研发中心”，点“保存”；再对这一行点“编辑”，确认抽屉里只剩“名称 / 顺序号 / 状态”，“类型”和“所属管理单元”不再出现；把鼠标停在搜索框（占位“搜索本页名称”）上看提示，输入“领导”筛选。
- **讲解要点**：原站把指标库按能力、潜力、经历分三类，列表显示名称、类型和状态；我们复用统一列表外壳（无面包屑、15 条分页），读现有接口，类型建后不可修改（注释层 talent-library：DEC-456、DEC-281、DEC-294，L3）。“导入”按钮灰掉并提示“此入口暂未接入；当前可查看和维护基础配置。”；“导出”灰掉，提示“导出功能准备中”。搜索只筛选当前页，鼠标停在搜索框上提示“仅筛选当前页，翻页后重新筛选”。
- **预期结果**：新建抽屉里“所属管理单元”必填（漏选时该项提示“请填写此项”），保存后抽屉关闭，列表出现一行“领导力能力库 / 能力 / 启用 / 1”，行尾有“查看”“编辑”（新建前列表为“这里什么都没有…”）；编辑抽屉标题“编辑 · 指标库”；输入“领导”后仍只剩这一行。

## 步骤 6：任职资格：级别、类别、标准

- **讲解要点**：原站任职资格按类别→级别→标准组织。级别列表显示编码、名称、层级和顺序号，默认每页 15 条；新建时省略顺序号由服务端决定，前端不算最大顺序号（注释层 qualification-level：DEC-456、DEC-285，L3）。类别按所属管理单元与“向下公开”管理，双列居中弹窗（qualification-category：DEC-456、DEC-026、DEC-324）。标准按分类组织，详情按级别页签看能力标准，图谱、课程和完整明细编辑后续接入（qualification-standard：DEC-456、DEC-055、DEC-026）。类别必选“所属分类”，而页面上没有维护“分类”（category class）的入口，全新库里现场无法新建类别，也就无法建标准，这是当前页面片的边界；走查时曾用同源公开接口建过一条分类“专业序列”，之后“类别→标准”才走通，但那不是页面操作，演示时不做，口述“补种子或补分类入口后即可建类别、建标准”。
