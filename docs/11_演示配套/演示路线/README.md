## 怎么用

1. 启动与重置：`pnpm demo`（写入种子并同时起后端 :3000 与前端 http://localhost:5173）；回到干净数据用 `pnpm demo:reset`（先停掉 `pnpm demo`）。见仓库 README“本地演示”。
2. 切换身份：开发模式下顶部栏“切换演示身份”下拉，选人后整页刷新；各路线里的“演示身份”写的就是下拉里的名字。路线不涉及任何账号凭据。
3. 打开顶部栏“注释”开关后，各页面显示“原站做法 / 我们的取舍 / DEC / 实现档位（L2·L3）”，路线的“讲解要点”引用的就是这一层。
4. 页面上标“演示数据”的区域是前端演示桩（`apps/web/src/demo-stubs/`）的合成样例，不是真实业务数据，讲解时要先说明。
5. **R3 各模块（8～12）的先决条件**：种子只给了组织员工应用的权限，没有给任何身份授予人才类标准身份，数据范围默认为空（fail-closed，DEC-043）。需先由系统管理员按 [06 企业设置的授权配方](06_企业设置.md) 给 HR专员授身份、建管理单元并设数据范围。**`pnpm demo:reset` 后授权会丢，需重做。**
6. 走查会留下数据：本 PR 走查时在本地演示库里写过一些对象（盘点项目 DEMO_REVIEW_2026、指标库、360 套卷与活动等，均为合成数据）；重新录屏 / 彩排前先 `pnpm demo:reset`，否则“现场新建”的步骤会遇到重名。
7. 调动场景（04、05）会改变种子调动单的状态（DEC-477 用户接管，种子此后不再复原）；要重演同一张单先 `pnpm demo:reset`。

## “高亮目标”约定（给后续演示模式片）

- 每步“高亮目标”用页面区域 / 控件的文字描述，如“列表右上‘新建’按钮”“详情抽屉的‘任职记录’页签”；不含 CSS 选择器、class 或 testid。
- 建议演示模式片按“`<模块序号>-步骤<N>`”给每步编号（如 `03-步骤6`），与本目录文件名、步骤标题一一对应。
- 同一步多个高亮目标按文中顺序依次高亮；两字按钮在页面上渲染为“变 更”这类带空格文本，匹配时请先归一化空白。
