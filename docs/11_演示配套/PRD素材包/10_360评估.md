## 1. 业务理解
### 1.1 模块目标
360 评估让一名员工同时收到上级、同事、下级、本人及客户等多个角色的评价，按角色加权得出他评分，产出个人报告与结果报表，并作为人才盘点“能力分”的取数来源（`25` §3.5，取数函数 Lastest360Cent）。
使用者是 360 管理员（系统 / 高级 / 一般三类身份，由企业管理员授予）和评价者（内部员工或外部人员）。
原站把 360 当作测评云里一套独立的人员与评价关系体系；复刻照此自建 360 人员表，可以脱离组织员工数据独立使用（DEC-027）。
首版范围按 `25` §4：活动状态机、关键行为与等级评定两类套卷、角色加权计分、评价关系（手工 / 导入 / 按组织架构自动添加 / 请上级确认）、站内待办与邮件邀请、屏蔽与重新作答、一个标准版个人报告与结果报表、题库。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 评估活动 | 名称、应用场景、评价形式、欢迎语、作答页两个匿名开关、计分批次 | 草稿 → 已启用 → 已停用；评价形式启用后不可改 | `25` §2、§8.3 |
| 360 人员 | 内外部人员同一张表，邮箱为唯一标识 | 按员工 ID 关联组织员工并保留关联日志；同步后邮箱锁定 | `25` §2、§5 G-057；DEC-027、DEC-030 |
| 套卷 | 关键行为 / 等级评定；复合指标 → 基础指标 → 题目 → 选项；角色权重 | 草稿 / 已启用 / 已使用；已使用不可删 | `25` §3.1 E3-R1～R9 |
| 套卷模板（题库） | 企业自定义模板 | 被套卷引用时复制，套卷修改不回写模板 | `25` E3-R10 |
| 评价角色 | 内置 6 个 + 租户自定义 | 租户最多 90、单套卷最多 15（DEC-033） | `25` E3-R4 |
| 评价对象 | 活动 × 人员 | 选 1～3 个已启用套卷；一个活动最多 30,000 个 | `25` E3-R3、E3-R16 |
| 评价关系 | 活动 × 评价对象 × 评价者 × 角色 × 套卷 | 每个对象最多 500 名评价者；可屏蔽 / 恢复；确认后前台不可改 | `25` E3-R17～R19 |
| 作答链接、凭据与待办 | 评价者 × 活动一组 | 待办按评价者 × 活动去重；重发即换新链接与凭据 | `25` §10.3；DEC-401③④ |
| 答卷、得分、个人报告、结果报表 | 题目 / 指标 / 问卷 × 角色得分 | 停用活动后计分、生成报告 | `25` §3.2、§3.4 |
| 管理员身份与活动授权 | 系统 / 高级 / 一般；活动级“已授权用户” | 授权只有添加 / 移除，能力由身份决定 | `25` §8；DEC-280 |

### 1.3 关键流程与规则
1. 主线五步：创建活动 → 设置套卷 → 设置评价关系 → 进程控制（启用、邀请、催促、重新作答）→ 停用后出结果（`25` §1）。
2. 计分与报表只在停用活动后进行；改权重、屏蔽或重新作答后要“启用—停用”才重算，旧报告随之失效（`25` E3-R15、§10.3 ⑫）。
3. 每个评价对象 1～3 个套卷；自评权重固定为 0，他评角色权重不能全为 0，否则套卷不能启用（`25` E3-R3、E3-R5；AC-360-01、02）。
4. 角色加权：角色分取该角色评价者简单平均，他评分 = Σ(角色分 × 权重) / Σ权重；缺失角色从分母去掉；“不做评价”选项不计入，不按 0 分（`25` E3-R6、E3-R11、E3-R13；AC-360-03～05）。
5. 已使用套卷不可删；替换套卷须确认，清空该对象已有作答并留审计（`25` E3-R2；F-034；AC-360-09）。
6. 匿名照原站：不设最少评价人数阈值，单人角色照样单列分数；设置评价者页只给不拦截的提示；另有活动级“作答页评价者姓名 / 评价角色”和报告模板“文本答案是否呈现评价角色”两个开关（`25` §7；DEC-149；AC-360-16）。
7. 管理员可见范围：系统管理员看全部活动，高级 / 一般管理员只看自己创建和被授权的活动，一般管理员看不到人员同步入口（`25` §8；DEC-280；AC-360-13）；开启精细化权限后，活动内人员也按数据权限裁剪（DEC-289①）。
8. 人员同步：首次按邮箱、手机、工号查重，冲突列给管理员确认，不自动合并；再次同步以组织员工为准覆盖（`25` §5 G-057；DEC-030；AC-360-12、14、15）。
9. 待办按评价者 × 活动去重；“重新作答”清空答卷，但不重发通知（`25` §10.3 ②⑩⑪）。
10. 一键屏蔽疑似无效数据（平均单题耗时 < 1.5 秒、放弃作答 > 50%、全部选同一选项）两小时内只能用一次；耗时按“首次打开 → 提交”整段计算（`25` §10.1、§10.5；DEC-392）。
11. 通用网址作答（复刻有意收紧）：每租户一个网址，序列号 10 位、密码 8 位，只存加密摘要、管理员不能查看或导出，失败 5 次锁 15 分钟，会话 8 小时绝对过期（DEC-377①、DEC-379③、DEC-401；差异 D-070、D-073～D-075）。
12. 匿名披露：一般管理员不能从答卷审计还原逐题分值（DEC-364）；所有写操作与审计同事务落库，表与流程实例带租户维度（AGENTS §2、§10）。
