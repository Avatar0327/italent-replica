## 1. 业务理解
### 1.1 模块目标
继任管理回答“关键组织、关键职位出缺时谁能接上”。继任管理员和 HR 给组织负责人、关键职位登记继任者和准备度，按时间轴保留历史；
组织 / 职位两张继任地图把梯队覆盖、职位风险等级、组织健康度画在卡片上；盘点结束后，盘点里的提名可以同步进继任地图。
人才池是相邻的一条线：按池沉淀储备人才、跟踪阶段与出池，也是 IDP 的发起来源。
首期现状：继任后端按拆分方案 17 个实现子 PR 推进，除 D5（只加测试）外都已合并；人才池未开工；页面在 FE-R3d 开发中。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 继任记录 | 组织继任 / 职位继任 × 目标 × 继任者 × 准备度 × 起止 × 结束原因 | 同目标同继任者区间不重叠；结束日不晚于今天；默认只列当前生效 | `27` §1.1、§8 Q01 / Q03；DEC-305 |
| 关键职位 | 职位上的布尔标记 `isKey`，不建关键岗位库 | 职位继任的目标只能选关键职位 | `27` §4 G-054；DEC-305③ |
| 准备度 | 共享字典，由 R3-T04 交付、继任只引用 | 被继任记录引用时受引用守卫保护 | `27` §1.1；DEC-301① |
| 职位风险等级 / 结果 | 有序等级 + 结构化条件行 + 表达式；结果可手动赋值 | 先匹配先得、默认颜色兜底；手动值不被计算覆盖 | `27` Q-M0-82、Q-M0-178；DEC-261、DEC-449 |
| 组织健康度等级 / 结果 | 结构同上，规则可引用“人员范围” | 手动 / 导入值受保护，只有“重置”才覆盖 | `27` §8 Q05 / Q06；DEC-305④ |
| 人员范围 | 自定义命名人群（条件行），供健康度规则引用 | 被引用时不能删除 | `27` Q-M0-82；设计 §1.4 |
| 组织统计 | 卡片上的在岗人数、绿化率、编制数 | 定时计算（默认每 4 小时）或改显示设置时触发 | `27` SC-R6；设计 §4.5 |
| 计算任务（run） | 风险、健康度、统计、离职扫描的异步任务 | 幂等键、逐页保存点、完成后发通知 | 设计 §4.6 |
| 同步批次 | 消费一次盘点结果：提名 → 目标 → 继任记录 / 健康度 | 追加 / 覆盖 / 范围内覆盖三种策略 | `27` §1.3；同步协议 v5 |
| 人才池（R3-T06） | 分类、池、成员（阶段、准备度、指导人角色）、入池规则 | 离职自动出池；梯队地图 = 人才池 × 准备度 | `27` §2、§7；DEC-343② |

### 1.3 关键流程与规则
1. 时间轴：开始、结束都不得晚于今天，结束为空即当前生效；允许补录不重叠的过去区间；列表默认只看当前生效，可切到已结束（`27` SC-R2、§8 Q01；DEC-305①、DEC-343③；AC-SC-01）。
2. 唯一性：同目标、同继任者的区间不得重叠；同一人可做多个目标的继任者，不设上限（`27` §8 Q03；DEC-305②、DEC-034）。
3. 继任者候选按原站全租户搜索（含待入职，每次最多 30 条）；记录的列表 / 详情仍按数据范围裁剪，数据范围默认为空（fail-closed），范围外人员出现在记录中时照常显示（DEC-308、DEC-311③；AGENTS §2）。
4. 离职：组织继任由夜间 `exit_sweep` 结束，职位继任由离职事件触发；结束日 = 离职生效日（最后工作日次日），原因“离职”，记录保留；事件前已离职的不补处理，只提示“继任者已离职”（DEC-343①④；AC-SC-02）。
5. 风险 / 健康度规则照原站“结构化条件行 + 只含 and / or / 括号的表达式”录入，保存时编译为 R3-T00 表达式；等级按顺序先匹配先得，全不匹配显示默认颜色（新租户初值 #7498FB / #F2F3F5，不允许为空）（DEC-261、DEC-420；D-062、D-077）。
6. 职位风险：每日 0 点自动算，也可在地图手动触发，异步执行、完成发通知；手动赋值的职位不参与计算，清除手动值即恢复按规则计算（`27` Q-M0-178；DEC-449）。
7. 组织健康度：“计算”覆盖权限范围内全部组织但跳过手动 / 导入值；“重置”把所选组织改回按规则计算，遇他人手工修改按 revision 冲突拒绝；缺少授权覆盖的规则组合保存即拒绝（`27` §8 Q05；DEC-305④、DEC-311、DEC-460；AC-SC-07）。
8. 组织地图从一个根展开 2～4 层（默认 3），可隐藏虚拟组织；职位地图中间职位停用时下级挂到其上级，权限断层则多根显示（`27` SC-R5～R8；DEC-453④；AC-SC-06）。
9. 显示开关分两层：“显示无继任者职位”是职位地图的个人筛选（初值“是”）；“隐藏虚拟组织”“展示当前任职人员”是租户级设置（`27` Q-M0-177；DEC-443）。
10. “本人继任者是否可见”= 否时，登录人看不到自己的继任者；SELF 判断在所有出口统一投影（`27` SC-R7；设计 §8.4）。
11. 盘点同步：策略由租户开关决定（原站测试租户为“追加”）；盘点对象仍在流程中时其继任信息整组失败并列入错误报告；健康度随组织继任一起同步（`27` SC-R14～R16、§6；AC-SC-03～05）。
12. 人才池（未做）：向下公开后下级只能加各自范围内的人；离职自动出池、出池日 = 离职生效日；梯队地图只显示填了准备度的成员，拖拽只改准备度（`27` TP-R1、TP-R7、§7；DEC-343②）。
