## 1. 业务理解
### 1.1 模块目标
员工自助让普通员工看自己的档案与任职变动、查看本人发起的申请、按授权发起本人调动；经理工作台让部门负责人看团队成员与待办，并为负责组织（含下级）的在职员工发起调动。
它是调动闭环的发起端（审批与执行在 04 模块），也是“员工 / 经理两类非 HR 用户”的权限样板：身份按关系自动取得，可见字段与按钮全由服务端授权决定。
首期范围（DEC-200）：我的档案、人事申请（本人任职列表）、我的申请、本人调动、他人调动；本人离职 / 新增兼职入口待 R2 接入（F-020）。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 员工身份（自助） | 预置标准身份“员工”，按用户↔员工绑定自动持有 | 三个本人调动按钮迁入该身份，默认允许、管理员可收回 | DEC-399、DEC-402；`23` §19 |
| 部门负责人自助身份 | 当上组织负责人即自动取得，撤换即失效 | 范围 = 负责组织含全部下级 | `12` 附 §1、§4；DEC-168 |
| 本人任职记录 | 人事申请页列出本人全部任职版本，带审批状态 | 只读；别人代发起的在途调动也在此可见 | `12` 附 §2（J-04） |
| 调动申请业务 | 本人 / 他人调动生成的任职业务与审批实例 | 与 HR 端同一张表单，按字段权限裁剪 | DEC-205；`12` 附 §3、§4 |
| 我的申请 | 本人发起的申请列表（七列） | 只列本人发起；HR 代发起的不出现 | `12` 附 §6（Q-M0-73） |
| 团队成员分类 | 在岗 / 试用中 / 实习生 / 待入职 / 离职中 | 按组织关系统计，口径来自任职状态字段 | `12` 附 §8（Q-M0-76） |
| 经理待办 | 待处理 / 已处理 / 已申请三页签 | 详情只读，办理进审批中心 | `12` 附 §5；DEC-057 |
| 命令结果 | 写命令的命令 ID 与处理结果 | 仅申请人本人可按命令 ID 回查 | F-120（#310） |

### 1.3 关键流程与规则
1. 员工身份按绑定自动持有，不需手工授予；本人调动三个按钮任一缺失即不显示发起入口（DEC-399、DEC-402；AC-TRF-01、AC-TRF-39）。
2. 本人接口只认当前会话的员工：改用他人 ID、跨租户 ID 或已解绑账号一律拒绝（AC-TRF-37；AGENTS.md §2 租户隔离）。
3. 自助调动表单与 HR 端同一张，可见 / 可编辑字段按发起人身份字段权限裁剪，不写死字段清单（DEC-205）。
4. 本人跨部门调动时新任职记录职位自动置空，不拦截（DEC-232；`12` 附 §9）。
5. 我的申请只列本人发起的单；“审批通过”与“已生效”明确区分，员工不能自助撤回（AC-TRF-45；`12` 附 §6）。
6. 经理调动候选 = 当前任职在负责组织（含下级）内的员工；范围外或已调出者搜不到，负责人被撤换后立即失效（`12` 附 §4；DEC-168；AC-TRF-40、AC-TRF-44）。
7. 团队成员按组织关系统计五类，在岗含试用与实习生，离职中可同时计入在岗（`12` 附 §8；F-022；AC-TRF-42）。
8. 无 HR 身份的经理不提供汇报关系页 / 图，接口直接请求也拒绝（DEC-206；AC-TRF-43）。
9. 团队列表无行操作，经理只能从“人事申请 → 他人调动申请”发起（`12` 附 §5）。
10. 写命令带命令 ID 与 revision；结果未知时页面只读锁定“处理中 / 结果待确认”，不盲目重试；服务器明确拒绝时保留输入可改正重提（DEC-464、DEC-473；AGENTS.md §10 幂等）。
11. 待办详情只给本单摘要，审批人不因审批获得档案范围（DEC-057）。
12. 本人提交与幂等重放写审计，审计员按对象、字段权限查看（AC-TRF-46）。
