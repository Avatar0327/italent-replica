## 1. 业务理解
### 1.1 模块目标
职务体系给岗位一套统一的“尺子”：职层、职等、职级、序列、条线定义岗位的级别与归类，职务是通用岗位，职位是“组织 × 职务”
的具体坑位，并自带直线 / 虚线汇报树。任职、调动、编制、人才标准都引用这些对象。编制管理按“组织 × 周期”给出可用人数，
在调入、Offer、入职时判定是否超编，并按严格控制决定拦截还是提醒。使用者是 HR、组织与编制管理员。首期做职务体系八类对象
的维护页面、序列同步任职，以及编制方案的只读概览；编制的完整写侧和带编调动只在后端实现。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 职层 / 职等 | 职层是字典；职等含等级与评估分上下限 | 职等挂职层 | `19` §2 |
| 职级类别 / 职级 | 如管理类、专业类；职级有级别与开始～结束职等 | 职级挂类别，对应一段职等区间 | `19` §2 |
| 职务序列 / 专业条线 | 两棵树；序列冗余一至十级祖先 | 序列可关联职级类别；首版建议不超过 3 级 | `19` §2、§3.8 |
| 职务 | 通用岗位：序列、条线、职级 / 职等区间、职责与要求 | 区间是任职时的合法性约束 | `19` §2、§3.2 |
| 职位 | 组织 × 职务的实例；直线 / 虚线上级与顺序号 | 职位树可推导员工直线经理（单次选项） | `19` §2、§3.1 |
| 八类对象共性 | 都有生效 / 失效日期与状态 | 按生效日期维护版本；设立日期只作记录（DEC-040） | `19` §1；`17` §3 |
| 编制方案 | 周期类型、起始月、细分维度、维护方式、未匹配处置、占编范围 | 被引用后不能删除，也不能改周期与细分 | `18` §2 |
| 组织编制 | 组织 × 周期：本级 / 含下级 / 预留，实有、预增、预减、缺编 | 四条一致性约束；严格控制 | `18` §3、§10 |
| 细分编制 | 组织 × 周期 × 维度值（首版只按职位） | 组织编制 ≥ 细分之和 | `18` §3、§8 |
| 编制时机 | 调入 / 调出等业务何时占编、释放 | 出厂值照本租户（DEC-075） | `18` §5 |
| 编制调整历史 / 通知 | 调整、复制下期、带编调动留痕与结果消息 | 带编调动留调整历史（DEC-181） | `18` §4、§6 |

### 1.3 关键流程与规则
1. 八类职务体系对象按生效日期追加版本，可按任意日期查看；页面只列有读权限的对象，全无权限显示 403 页（`19` §1；硬规则·版本链、数据范围 fail-closed）。
2. 职务的最低～最高职级 / 职等是任职约束：表单按级别数值过滤候选，服务端保存时再校验一次（`19` §3.2；AC-JOB-01）。
3. 设立日期只作记录，不参与任职候选过滤，也不拦截（DEC-040；AC-JOB-04）。
4. 有在岗人员的职位禁止停用，不做自动转岗（DEC-016；AC-JOB-03）；新建职位或改所属组织按整个时段校验组织是否已排定停用（DEC-151；AC-JOB-07）。
5. 职位改上级职位时“调整员工直线经理”是单次选项：上级职位恰 1 人在岗才同步，为在岗员工追加任职版本；本人即唯一在岗人时跳过（`19` §3.1；DEC-011、DEC-131、DEC-133）。
6. 职务 / 职位改为非空序列时异步同步引用它的任职：只同步当前与未来记录，以追加版本写入；清空序列不同步；审批中同步、作废不同步；当前 / 未来按执行时点判断（DEC-127、DEC-208、DEC-218、DEC-219）。
7. 同部门职位重名由租户开关控制，出厂关闭，跨部门不限（DEC-062a；AC-JOB-06）。
8. 组织编制保存时校验四条一致性约束；缺编数 = 编制 − 实有 − 预增 + 预减，可为负（`18` §3；AC-EST-04）。
9. 严格控制 = 是时调入超编拒绝，= 否时提示后可继续；批量操作不拦截、逐行警告（`18` §3；AC-EST-01 / 02 / 07；DEC-015）。
10. 编制时机出厂：调入、调出都在提交申请时占用 / 释放，驳回或撤销即回退（DEC-075；AC-EST-03）；回退导致超编只提示不拦（DEC-258）。
11. 调整编制的差值只传播到所选调整周期范围；复制下期整批成功或整批不生成，结果走消息（`18` §4；AC-EST-05 / 06）。
12. 带编调动保存即调编，调入 +1、调出 −1 并留调整历史；多方案、缺细分等未取证口径整单拒绝（DEC-181；需取证 #78）。
