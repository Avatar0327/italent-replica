## 1. 业务理解

### 1.1 模块目标
合同协议管理员工与法人公司之间的劳动合同、劳务合同和各类协议，覆盖从签订、续签、变更到终止的全生命周期。
HR 用它盯到期与缺签：哪些人入职了还没合同，哪些快到期，哪些过期没续签；系统按规则自动续签、到期终止，并在离职、调动时联动处理合同。
首期范围：新建 / 续签 / 变更 / 终止（直接办理与申请）、批量与合并待办、六个视图、自动续签与签订次数、离职与调动联动、四种导入（`32` §3）；电子签署、打印模板与合同看板暂缓。
演示产品当前只交付只读页面（F-127a），写操作表单在 F-127b。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 合同记录 | 编号、员工、类型、公司、期限类型与月数、生效 / 终止 / 实际终止日、签订次数、状态、审批状态、版本号 | 版本链：`rootContractId` + `previousContractId` + `versionNo` | `32` §1；`21` §2 |
| 合同变动记录 | 变更时指向变动前合同 | 与任职“变更前取上一条”同一模式 | `21` §2 |
| 合同申请 | 新建 / 续签 / 变更 / 终止的审批单 | 同员工同类型只允许一份在途 | DEC-180② |
| 合同类型 | 劳动合同、劳务合同、协议类等 | 显示顺序；停用后不可再选 | DEC-482①；差距表 A15 |
| 法人公司 | 合同主体 | 主数据，按租户唯一 | `32` CT-R2 |
| 自动续签规则 | 组织 / 人员范围 + 明细（类型、续签月数、提前天数、不续签条件）+ 优先级 | 员工只命中优先级最高的一条 | `32` CT-R5 |
| 合同设置 | 到期自动终止、离职后可签类型、第 3 次无固定期限类型、重聘累计、续签类型 | 仅租户管理员或被授予“合同配置”者可改 | `32` §2.6；DEC-180① |
| 失败待办 / 隔离单 | 激活失败或存量冲突的申请 | 有权 HR 撤销后重提 | DEC-190 |

### 1.3 关键流程与规则
1. 六个视图：即将到期、入职缺失（在职无有效合同）、过期未续签、审批中、有效、全部；即将到期排除已有后续合同或在途续签的合同（`32` §2.1；F-128 A1）。
2. **版本链**：变更与续签都生成新合同记录并指向原合同，不原地覆盖；“变更前”从链上一条取（`32` §1；AGENTS 硬规则）。
3. 变更编号：新生效日 ≤ 原生效日 → 原合同作废、沿用原编号；> → 原合同终止、生成新编号；新终止日默认取原终止日（`32` CT-R11、CT-R12；T-403 实测）。
4. 续签：只有审批生效且有效 / 终止的合同可续签，不能改类型；手工续签生效日默认原终止日次日，终止日按原期限顺延（`32` CT-R3；DEC-482①）。
5. 签订次数与期限类型：所选类型第 3 次签订起为无固定期限，手工与自动续签统一按“第 3 次无固定期限类型”设置判定（`32` CT-R7、CT-R16；DEC-482①）。
6. 自动续签：只对同类型终止日最晚、有效且实际终止日为空的合同发起；发起人显示“系统代发”（`32` CT-R5、CT-R6）。
7. **审批通过 ≠ 生效**：同员工同类型只能有一份在途（审批中或已批准未生效），再提交返回 409 `CONTRACT_IN_FLIGHT`；已批准未生效的由调度到期激活，失败进 HR 待办（DEC-180②、DEC-190）。
8. 流程匹配：合同审批条件当前只开放 `processCode`、`business.kind`；含未实现字段的已发布流程发起时报 `APPROVAL_CONDITION_UNSUPPORTED`，不按空值误匹配（本条依据规格 `32` 的 F-016 补充，DEC-180 不包含此审批条件规则）。
9. 数据范围：新建 / 续签校验人员新建范围；变更 / 终止 / 编辑按目标合同真实创建人判断（DEC-202）；合同属员工应用，复用任职可见性。
10. 离职联动：不在“离职后可签类型”内的合同，开始日晚于最后工作日则删除，否则终止于最后工作日（`32` CT-R14；端口待离职 #100 接线）。
11. 编辑导入已终止合同照原站加护栏：到期终止可延期恢复，离职 / 人工提前终止受保护，违规返回 409（DEC-167；`32` CT-R18b）。
12. 配置门禁：合同设置与续签规则仅租户管理员及被授予“合同配置”者可改，普通 HR 身份不预置（DEC-180①）。
13. 照原站不做手动删除合同，合同只由离职规则与“按人员初始化”导入删除（DEC-484）；停用的合同类型不可再选用（DEC-482①）。
