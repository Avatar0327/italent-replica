## 1. 业务理解

### 1.1 模块目标
企业设置是租户管理员一侧的“后台”：管理账号（用户）、给账号授予身份（功能权限）、为账号配置数据范围（数据权限）、维护管理单元，并通过数据变更日志追溯谁改了什么。
它服务三类人：8 类企业管理员（职责分离，不是一个超级管理员）、平台运营方（开通租户、发放许可），以及所有员工（个人设置里的头像）。
首期范围是 PC 端的用户管理、身份管理、用户授权、管理单元与数据范围、数据变更日志，以及企业设置菜单本身的权限驱动渲染；其余 60 项后台菜单只保留入口定义。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 租户用户 | 租户内账号，分内部员工 / 外部用户 | 内部员工随人员建档产生、与人员一一对应；外部用户必须带业务身份；可属于多个租户 | DEC-128；`06` §9 |
| 身份（Profile） | 按应用划分的功能权限包：菜单、页面、对象（字段 / 按钮 / 数据操作） | 标准 / 自定义；身份 ≠ 角色 | `04` §2、§5；`06` §3、§7.2 |
| 授权记录 | 用户 × 身份 | 来源分手工 / 自动；自动的不可手工撤销；消耗许可 | `04` §3；DEC-020 |
| 数据范围 | （用户 × 应用）一份 | 与身份多对一；默认 = 空；撤销身份不删范围 | `11` §2、§12；DEC-043 |
| 管理单元（MOU） | 命名的组织范围集合 | 范围可引用 MOU，或逐条组织 + 维度 + 是否含下级 | `11` §10、§14 |
| 企业管理员 | 8 类固定管理身份 | 决定企业设置 67 项菜单的可见与可写 | `06` §7.1；`packages/domain/src/permission/enterprise-menus.ts` |
| 许可 | 按类型的余额 | 授权消耗名额；余额为 0 仍可授权并提示超额 | `06` §4；DEC-143 |
| 数据变更日志 | 字段级前后值、删除快照、任务级日志 | 按查看人当前权限裁剪 | `20` §5；DEC-019、DEC-197 |
| 租户 / 租户配置 | 平台开通的租户与其配置覆盖 | 覆盖可恢复为系统预置 | REQ-TEN-001；AC-TEN-03 |

### 1.3 关键流程与规则
1. 功能权限与数据权限是两套独立机制，分别配置、分别校验；“菜单可见 + 接口 200”推不出“能看到数据”（`11` §1；`04` §5）。
2. **数据范围默认值必须为空（fail-closed）**：“默认管理单元”= 无数据范围权限，任何角色不得在代码里写死“全部组织”（`11` §2、§9；AGENTS 硬规则）。
3. **数据范围按（用户 × 应用）存一份**，该用户在此应用下所有身份共享；新授身份时表单预填现有范围并提示共享；撤销身份不回滚、不删除范围（`11` §12；DEC-043；AC-PRM-14～16）。
4. 多身份权限取并集，不做拒绝优先（DEC-042；AC-PRM-07、20、22）。
5. 管理员只能授予自己“可授权业务身份”集合内的身份；自动授权（员工、经理等自助身份）按关系自动持有与回收，不可手工撤销（REQ-PRM-001 R1；DEC-020；AC-PRM-10、11、27、28）。
6. 授权消耗许可；余额不足时授权照常保存、余额记负数并在回执中提示超额，由平台运营补发（`06` §4；DEC-143；AC-PRM-08、09）。
7. 企业设置菜单按 8 类管理员矩阵渲染；前端只消费服务端权限快照里的 `adminMenus`（可见 / 可编辑），不硬编码角色（`06` §7.1；#307、#313）。
8. 用户与人员一一对应、由建档产生，内部员工不提供手工建账号或改绑；无人员档案的账号只能登记为外部用户（DEC-128；AC-PRM-31～33）。
9. 所有对象的增删改进入统一字段级数据变更日志，删除保留完整快照；系统任务记为“系统”（`20` §5；DEC-019；AC-AUD-01～04）。
10. 日志审计仅租户管理员、审计管理员可见；查询按查看人当前范围与字段权限裁剪，在分页前完成；无归属的配置类日志对持有者可见（DEC-197、DEC-203；AC-AUD-06～14）。
11. 审计保留期做成租户级配置并严格执行（DEC-198；AC-AUD-05）。
12. 租户隔离：所有表、缓存、流程、定时任务带租户维度，跨租户一律拒绝；平台层负责开通 / 停用、标准预置下发、许可发放、按租户备份恢复（DEC-006；AC-TEN-01～06）。
13. 范围内下级组织停用后范围不收缩（DEC-146；`11` §18）。
