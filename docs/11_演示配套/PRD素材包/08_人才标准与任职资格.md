## 1. 业务理解
### 1.1 模块目标
人才标准回答“某类岗位的优秀人才长什么样”：用能力、潜力、经历三类指标库搭出人才画像，供盘点、人才池、IDP 等下游引用。
任职资格回答“某个任职类别在每个级别上必须达到什么能力标准”，并给员工展示纵向晋升和横向转岗的发展通道。
主要用户是 HR / 人才发展管理员（预置“人才标准管理员”“任职资格系统管理员”），员工本人只读查看自己的发展通道。
首期做配置全链路与任职资格子集（初始化 + 任职生效自动同步）；测评方案、标签库、行业指标、学习课程、AI 生成不做（`23` §4）。

### 1.2 核心对象与关系
| 对象 | 说明 | 关键关系 / 约束 | 规格位置 |
|---|---|---|---|
| 指标库 / 指标 | 库分能力 / 潜力 / 经历；指标带等级描述、行为描述、发展建议、面试问题四类子表 | 库类型、指标所属库建后不可改；编码库内唯一 | `23` §2.1、§7 |
| 库内分类、发展建议类型 | 库内分类是独立对象（名称 + 顺序）；建议类型为数据源 | 指标以查找字段引用分类 | `23` §7 #3、#4 |
| 人才标准 / 标准分类 | 标准按能力 / 潜力 / 经历 / 成就分栏；潜力页可上传模型图 | 标准内指标为引用关系，只有能力指标有权重和目标 | `23` §2.2、补充 F-038 |
| 任职类别分类 / 任职类别 | 分类最多 5 级；类别可新建或从岗职务引入 | 同类型内一个岗职务只能关联一个类别 | `23` §3.1、§11 |
| 层级 / 任职级别 | 级别顺序号从低到高 | 可从职级 / 职等引入 | `23` §3.2 QL-R2 |
| 指标类型 / 指标（任职资格） | 指标挂在多层级类型下；通用 / 非通用；评分 / 评级 | 评级指标必须选启用的等级方案 | `23` §3.2 QL-R4～R6 |
| 等级方案 / 等级明细 / 指标等级描述 | 明细增删改联动各指标的等级描述 | 只更新“未手工修改”的描述 | `23` QL-R7 |
| 任职资格标准 | 类别 1:1；级别 × 指标网格，每格 1～10 条能力标准 | 原地修改，无版本（DEC-055） | `23` QL-R8～R11、R18 |
| 发展通道 | 类别内纵向晋升 + 任一级别多条横向路径 | 横向目的地不校验是否有标准 | `23` QL-R13、§15 |
| 任职资格子集 | 人员子集 `TenantBase.Qualification`：类别、级别、起止日期、最终得分、是否自动同步 | 每人一条不重叠的时间轴；当前资格按日期计算 | `23` §10、§13；DEC-335 |

### 1.3 关键流程与规则
1. 标准引用指标而不复制：库里改定义，标准详情立即显示新内容；只能引用启用的指标；被引用的指标不能删，有指标的库不能删（`23` §2.2 TC-R2、R4、R5；AC-TC-01、02）。
2. 只有能力指标能设权重与目标：数值 1 位小数、可空可负，权重新增默认 1，无合计 100% 约束（TC-R3；DEC-281①②；AC-TC-03）。
3. 被引用指标可直接停用，不拦截、标准详情不加停用标记，只拦新引用（`23` §7 #8；DEC-281⑧）。
4. 人才标准对象的所属人 = 创建人、所属管理单元 = 创建人的授权单元，表单不显示；查看与写入按管理单元控制，数据范围默认空（DEC-294、DEC-281⑨）。
5. 任职资格配置数据“查看照原站全员可见、写入按管理单元”，比原站严，登记差异 D-065；不建资源集合，用所属组织 + 管理单元 + 向下公开（DEC-352、DEC-355、DEC-026）。
6. 一个任职类别只对应一条标准；标准原地修改、不做发布审批和不可变版本，评定侧在评分时快照（QL-R8、QL-R18；DEC-055、DEC-153）。
7. 通用指标的指标说明带入各标准且不可编辑；非通用改为通用时覆盖写入能力标准，改回后保留覆盖后的副本（QL-R5；`23` §12）。
8. 等级方案明细变化联动指标等级描述：新增补一条、删除删对应条、编辑只改未手工修改的条（QL-R7；AC-QL-04）。
9. 发展通道：纵向为本类别级别晋升，横向可多条；目的地无标准时照原站放行，显示侧保留提示（QL-R13；`23` §15；DEC-348①）。
10. 子集生成三条路：初始化（只新增）、任职生效后岗职务唯一映射自动同步（跨类型多命中取 职位 > 职务序列 > 职级类别）、评定结果发布（QL-R15；T-408；AC-QL-06）。
11. 自动同步走任职记录事件 → 同步队列 → 处理器，到生效日才处理（审批通过 ≠ 生效，F-055）；SW74 关闭后已有自动同步记录追溯锁定（设计 §4.3；`23` §10 W-677 / W-678 实测）。
12. 员工本人看发展通道靠预置“员工”标准身份的页面权限，前提是子集里有当前类别和级别（QL-R14；`23` §19；DEC-399）。
