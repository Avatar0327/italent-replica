# FE-0 前端底座实施计划（DEC-456）

**目标**：交付页面片可叠放的布局、路由、权限、客户端和组件契约，沿用现有演示身份与业务页面。

**架构**：`foundation/` 暴露公共入口；`demo-stubs/` 隔离缺失的导航与会话资料适配；`annotations/` 保存注释。后端对象权限和企业设置菜单直接读取，数据范围无法读取时保持空，业务查询仍由已有接口裁剪。客户端同源 Cookie 与租户头沿用既有契约，身份签名仅由现有开发代理完成。

**技术栈**：React 19、React Router 当前稳定大版本（安装时 8.4）、Ant Design 5、Vite、Vitest、Playwright。

## 实施顺序

1. 在 `tests/acceptance/AC-FE-0-{client,contract,components}.test.ts` 写客户端、路由、权限与注释红测；运行三个文件并单独提交（5011466c）。
2. 在 `apps/web/src/foundation/` 实现契约、布局壳、15 个应用路由和通用模板，`App.tsx` 接入。先通过相关测试、lint、typecheck、build，推送可运行骨架并开 Draft。
3. 在 `apps/web/playwright.config.ts` 与 `apps/web/smoke/` 提供浏览器冒烟，验证演示身份切换、15 个应用、旧路由、无权与注释开关。测试数据均为合成数据。
4. 补组件交互、权限数据源与失败边界测试，运行相关存量迁移页面测试。检查本机效果。
5. 按开发自检技能逐文件执行 OCR 委托规则，核对设计与 DEC。完成 `pnpm build`、`pnpm lint`、`pnpm typecheck`、受影响测试与 Playwright。F-039 无后端路由变更，运行差异说明工具验证待说明为 0。
6. 推送、更新 PR 恢复点和实际验证证据，转 Ready 并贴“开发完成，待审”。不合并。
