# R1-T12 人员信息与人员子集交付说明

核对日期：2026-10-02。实现依据为本仓库 `AGENTS.md`、派发单 §1/§5、对象规格 `17` §1/附录、`22` §1–§3、R1-T12 需求及验收表，遵循 DEC-005/019/031/037/045/060/080/081/082。基线为 `origin/main` 的 `68adfc338843498f65d0183392a2f3a5e3050d1d`；不将其他旧复刻仓库的结果计入验收。

## 对象、接口与事务

沿用 `employment_employees` 的唯一人员 ID；人员属性追加到 `personnel_employee_versions`，未维护时人员信息 revision 为 0，与任职记录 revision 分离。原主表保持不可变；原任职模块读取姓名时通过版本投影得到最新值。账号关联沿用 `permission_user_person_links`，没有第二套员工主表。

新增 29 张具备租户 RLS ENABLE/FORCE 的表：人员版本 1 张、13 个子集各自的当前表和不可变版本表 26 张、变更申请和 outbox 各 1 张。核心对象均为明确列；申请的 JSON 仅保存待批准命令内容。子集删除保留版本和审计快照；字段审计、outbox、命令台账与业务写入同事务。

人员接口位于 `/api/tenant/personnel/employees`，支持列表、详情、修改、历史和按需任龄；子集支持全局列表、人员内列表、详情、增删改和历史。每次请求按真实操作、按钮及实际提交字段授权，响应（含历史、重放、嵌套子集）按当前字段权限裁剪。人员范围在分页前以关系 SQL 约束，越界返回 404；列表默认 50、最大 200。

员工信息仅登记实际存在的修改和历史按钮，创建人员仍由任职模块负责。敏感字段不做显示脱敏；无权限即不返回。错误日志不输出数据库原始诊断或个人数据，outbox 只含对象标识。

按 DEC-005 跳过：待定的护照、弹性退休、完整度、国央企专用字段、残疾人字段和其他语言检索；演示类港澳地址/身份扩展、星座血型宗教、农历生日、独生子女、健康证体检、专家/人才标签等；不纳入的招聘、360/测评对接、过时社交及原站技术债字段。租户自定义演示字段不纳入。

13 个子集为教育经历、工作履历、家庭成员、培训经历、证书、奖励、项目经验、技能、语言能力、考核结果、惩罚、专业技术职务、职业资格。各对象按规格有独立业务列、来源、人员关联、版本及创建元数据。考核结果与培训为人工维护，预留类型化同步接口；DEC-031 测验结果属于 R3-T00，未建设。
