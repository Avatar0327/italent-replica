# F-048 PR-2 判定接入：路由权限声明

> 依据：F-048 设计 §6、§8.1；DEC-329、DEC-331⑤；沿用 R3-T01 的 F-039 声明格式。
> 本 PR 没有新增路由，也不改变任何路由的功能 / 按钮 / 数据范围权限；只改变命令内的回避判定（冻结的 S / U(S)）、
> 定义校验和仿真输入。F-039 PR-A 框架合并后，由其按本表补登记。

## 共用契约

- 回避判定只读实例冻结的主体集合 `S` 与账号集合 `U(S)`（`approval_instance_subjects`），不实时查账号绑定；存量实例（无冻结行）按单主体回退。
- 节点级（`avoidSelf` / `avoidSubjects`）：办理人、转交 / 加签 / 管理员改派目标、抄送目标；异常管理员任务的办理人按实例级。
- 实例级（不受开关影响）：异常管理员、替代人、接管人、管理员操作人、交接操作人；IDP 所有者干预只回避主体（DEC-321①）。
- 命中的统一拒绝码：办理 / 目标 / 抄送 `409 APPROVAL_SELF_REVIEW`（`details.recusal = self | subjects`）；管理员操作人 `403 APPROVAL_ADMIN_SELF`；
  异常管理员无人可接替 `409 APPROVAL_EXCEPTION_ADMIN_SELF`；交接逐单 `skipped`。
- 详情响应不新增任何主体字段（DEC-057）；动作公布与命令执行共用同一判定。
- REV = 缺 If-Match `400 REVISION_REQUIRED`；不符 `409 REVISION_CONFLICT`。IDEM = 缺命令键 `400 IDEMPOTENCY_KEY_REQUIRED`；同键异内容 `409 IDEMPOTENCY_CONFLICT`。重放：成功命令不重复执行，详情按当前查看人重新裁剪；失败命令不入命令台账（抛错事务整体回滚，见 `commands.ts`），同键重发是在相同状态下重新执行、得到相同的拒绝结果，不是回放缓存的失败体。
