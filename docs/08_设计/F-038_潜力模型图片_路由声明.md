# F-038 潜力模型图片：路由权限声明

> 依据：`23` Q-M0-126、DEC-281⑫、DEC-294、DEC-316，F-039 格式沿用已合并的 R3-T01 路由声明。
> F-039 PR-A 尚未合并，当前以逐路由 Markdown 登记现状契约。

## 共用契约

- 对象 CRIT = `TalentCenter.TalentCriterion`，应用 TalentCenter。
- 范围定位器 `talent.criterion.byId`：父标准的所属管理单元与所属人，复用 `talentScope / requireVisible / lockOwned`。
- 图片详情范围固定采用 CRIT 的服务端 `TalentCenter.TalentCriterion.detail` 页面及同名数据源上下文，读取、首次写响应和重放一致；写命令还须通过原业务范围。客户端不能选择或覆盖上下文。
- 不存在与范围外同一 `404 NOT_FOUND`「人才标准不存在」；不存在、孤儿、已替换或已删除附件同一 `404 NOT_FOUND`「模型图附件不存在」。
- 图片没有独立可见性设置；固定元数据投影 `id / filename / contentType / byteSize / sha256` 随标准详情查看权。
- 编辑 = CRIT update + update@detail。登记、上传、替换、删图均编辑父对象，不需要 CRIT delete。
- REV = 缺 If-Match `400 REVISION_REQUIRED`；不符 `409 REVISION_CONFLICT`。IDEM = 缺命令键 `400 IDEMPOTENCY_KEY_REQUIRED`；同键异内容 `409 IDEMPOTENCY_CONFLICT`。
- UUID 由 `talent/http.uuidParam` 规范化（父 ID、附件 ID），非法 `400 VALIDATION_FAILED`。
- 首次与重放均在查台账或执行业务前重新校验对象、按钮、原业务范围及当前详情范围；缺对象或按钮权返回 403，范围不满足返回 404，revision、附件、审计及命令台账不变。重放出口重新按详情范围读父标准与当前图片，不返回旧图片内容。

## 查看人 × 接口 × 字段

| 查看人 | 模型图状态 / 内容 | 登记 / 上传 / 替换 / 删图 | 审计 |
|---|---|---|---|
| 有标准查看权，标准在当前范围内 | 当前图片元数据与内容；canEdit 按服务端当前权判断 | 有标准编辑与 update@detail 才可写 | 还需日志审计入口权；图片元数据按标准当前范围显示 |
| 只有标准查看权 | 可读；canEdit=false | 403 FORBIDDEN，业务不变 | 同上 |
| 有标准编辑权，缺 update@detail | 可读取决于标准查看权；canEdit=false | 403 FORBIDDEN，重放同样拒绝 | 不因编辑权放宽日志查看 |
| 范围外 / 空范围 | 404 NOT_FOUND | 404 NOT_FOUND，首次及重放同样拒绝，业务不变 | 不显示该标准图片日志 |
| 标准详情 page / datasource 范围为空 | 404 NOT_FOUND | 404 NOT_FOUND，首次及重放同样拒绝，业务不变 | 按日志入口的当前授权与范围判断 |
| 无标准查看权 | 403 FORBIDDEN | 403 FORBIDDEN，写入与重放也要求 view + update + update@detail | 不显示 |
| 其他租户的成员 | 当前租户下对象查询不到，404 | 404，业务不变 | 不显示 |

审计类型 `TalentCenter.TalentCriterionModelImage` 的对象编号使用父标准 ID，查看权限映射 CRIT；
固定字段为 `modelImage / revision` 与统一审计展开的 `modelImage.id / filename / contentType / byteSize / sha256 / status` 完整路径，
不记录完整字节，不把其他标准字段投影到此子资源。
创建人范围复用父标准的 `talent.criterion.create` 保留元数据，删除后也能按原所属管理单元判断。

## 状态 × 操作

| 附件状态 | 读取内容 | 上传 | 被替换 / 删除 / 标准删除 |
|---|---|---|---|
| registered | 404（孤儿不可读） | 当前租户同标准可编辑，revision 正确且内容校验通过才 uploaded | 显式删图或标准删除时 pending_cleanup |
| uploaded（当前图） | 有当前标准查看权及范围才可读 | 新命令不可再次上传；原成功命令按当前状态响应 | pending_cleanup，旧 ID 立即 404 |
| pending_cleanup | 404 | 404，不能复活 | 保留元数据与待清理状态 |

登记尚未上传的新附件不会替换原图；上传失败不修改原图与标准 revision（成功登记已独立递增）。
文件内容与状态持久保存在租户表，随数据库一致备份导出，当前没有外部对象存储依赖。
