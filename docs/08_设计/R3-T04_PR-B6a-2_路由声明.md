# R3-T04 PR-B6a-2 步骤表单与结果公式：路由增量声明

依据：人才盘点设计 §2.3、§4.3、§7，F-082 契约 §8，DEC-387、DEC-391、DEC-415、DEC-416⑥、DEC-423④、DEC-425。
作用对象：复刻系统。依赖 #244；沿用其 5 条模板路由、命令事务、版本链、组织范围及向下公开规则。

## 1. 输入与版本

- POST / PATCH `/api/tenant/talent-review/templates[/:id]` 增加 `stepForms`、`resultRules`。
- 两组字段缺席沿用当前版本，空数组清空；显式提交任一组生成新版本，历史版本不变。只改头部不生成版本。
- `stepForms` = `{ nodeKey, roleId?, purpose, formId }[]`，用途为 `info / calibrate_edit / successor_edit / target_edit`。
  会签席位必须选本步骤角色，其他步骤不带角色；校准编辑用途限审核校准步骤。同一席位与用途唯一。
  表单类型分别匹配 `info / calibrate_edit / succession_edit`；保存时锁住来源表单，冻结字段、三档权限与必填。
  相同步骤 / 角色 / 用途继续选用同一表单时沿用旧快照；停用表单不可挪到其他席位。
  未提交时沿用旧快照；换流程时保留仍存在的席位。缺省无表单，运行期字段缺省不可见（运行期属 PR-C）。
- `resultRules` = `{ targetFieldId, formula, formulaBindings?, priority }[]`。目标在版本内唯一；优先级 0～1000000。
  目标字段类型沿用计算规则限制，不能选择系统写入字段或多选等不允许类型。新增引用须启用，原结果项继续持有的停用引用可保留，不能挪到其他结果项（DEC-425②）。
- 公式目录包含版本内指标模块的 `模块.<名称>.得分 / 等级`，模块名称文本按版本冻结，并以独立引用表绑定模块 ID（DEC-425①）。
  每次新版本按 `previousModuleId` 把旧模块引用迁移到新模块 ID，仅在 AST 引用位置更新名称，连续改名不断绑；
  改名后的回显须通过 F-082 往返校验，超限或不能重提时整体拒绝。
  不带 ID 的同名模块视为新模块，沿用旧公式时返回 400 `RESULT_MODULE_DELETED`，须清空或显式重写公式。
  新增 `盘点对象.<字段>` 引用通过
  F-082 `bindFormula` 绑定 ID，规范文本与派生引用表同事务保存。输入不能提交内部句柄。
- 带绑定证明的引用核对当前名称和 ID；新名称引用要求 `fieldCatalogVersion` 与当前目录一致。
  锁序为模板行、目标与引用字段（排序一次性共享锁）、目录版本共享锁，第二遍绑定须与第一遍一致。
- 裸词必须加引号；不允许多选字段参与公式。循环允许保存并返回提示。文本与数字比较编辑期允许（DEC-391 / 416⑥）。
- 修改模块导致沿用公式失效时整体拒绝，须同时提交新公式。被历史结果规则作为目标或来源的字段、被表单快照持有的字段禁止删除。
- 请求集合上限：表单选用 400 项、结果规则 100 项；公式结构上限 8000 字，正常绑定采用 F-082 4000 字 / 800 词限制。
  隐藏占位符原样保留沿用 F-082 例外。

## 2. 权限与响应

沿用 `Template` 的 create / update / delete 按钮和数据操作权。`stepForms / resultRules` 为新可编辑字段；
`hints / fieldCatalogVersion` 为只读系统字段，不将目录版本当作业务字段要求编辑权。
本片没有新增对象；#244 的模板和表单等对象“看全部”继续按 DEC-415 预置盘点管理员。

| 入口 | 引用与事务内校验 | 出口 |
|---|---|---|
| POST / PATCH | 表单另需 `Form.view` 与目录范围；目标字段另需 `Field.view` 与目录范围；公式证明按当前字段目录四列可见性复核 | 当前字段权限裁剪，新版本结果 |
| GET 列表 | 沿用 #244 分页前组织范围过滤 | 只含头部，不含两组结构 |
| GET 详情 / 历史 | 沿用 #244 模板可读范围 | 公式句柄渲染为当前名或隐藏占位符；绑定证明随可见性裁剪 |
| DELETE / 幂等重放 | `ledgerExit + CommandGuard.before / replayed` 复核当前按钮、对象、范围及请求引用 | 与详情共用当前公式投影；不重复写版本 |
| 审计 | 同事务保存两组结构与公式写入时名称；读取按当前字段目录裁剪 | 复用 F-082 审计引用投影；保留写入时可见名称 |

提示按 `resultRules` 查看权投影。该字段不可见时只留匿名计数；目标 / 依赖不可见时不返回其 ID 与名称。
`configErrors` 仍服从 #244 的 modules / permissions 联合裁剪，不改变原行为。

## 3. 写入口 × 值来源

| 写入口 | 人工输入 | 沿用 | 派生 / 系统值 |
|---|---|---|---|
| 新建模板 | 两组结构、目录版本、绑定证明 | 缺省空数组 | 表单字段快照、绑定文本、引用表、版本号 |
| 修改模板 | 整组替换、显式清空 | 未提交部分与原版本快照 | 新版本、第二遍绑定校验、revision |
| 同键重放 | 原载荷 | 台账规范文本 | 当前权限复核、当前名称渲染；零新增业务记录 |
| 删除模板 | 无 | 删除前完整快照 | 子表级联清理；审计同事务 |
| 字段改名 / 删除 | 字段既有入口 | 版本内公式不改写 | 改名往返校验；目标 / 来源 / 快照拒删 |

## 4. 错误与证据

- 结构、用途、席位、重复目标、类型等返回 400 `VALIDATION_FAILED` 与机器可读 reason；目录不可见与不存在同为 404。
- 名称证明过期或字段目录版本变化为 409，客户端刷新并显式重提；不盲重试。
- 沿用 #244 的 revision / 幂等冲突、向下公开只读、字段编辑权和租户隔离。
- 验收：`AC-TR-04-template-forms-results`、`AC-TR-04-result-module-identity`、`AC-TR-04-forms-results-pg`；原模板、冻结、权限与事务复核用例为回归约束。
- F-039 无新增路由：扩展模板必需项表中的 Form 条件准入；详情与写响应登记 resultFields 可选披露（字段目录对象权、范围及四列查看权），重算摘要与基准；发现探测路由集合不变。
- 不修改 `evidence-core.ts / core-digests.ts`。
- 表单被模板引用的友好拒删由 B6b 接线，本片外键 restrict 兜底；运行期求值、对象字段三档执行属 PR-C。
