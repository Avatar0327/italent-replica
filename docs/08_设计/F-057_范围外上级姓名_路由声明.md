# F-057 范围外上级姓名：路由权限声明

> 依据：DEC-319①、DEC-325③、DEC-327；沿用 R3-T01 的 F-039 声明格式。
> F-039 PR-A 尚未合并，当前以 Markdown 登记现有权限契约，不修改公共路由注册。

## 共用契约

- PERSON = `Survey360.Person`，应用 Survey360；数据范围仍按用户 × 应用存储。
- 人员可见性复用 `personFilter / visiblePerson / personVisible`，列表在分页前按同一 SQL 谓词过滤。
- 精细化权限开启、查看人受限时，上级独立点查仍要求上级在当前人员范围内；范围外与不存在同一 `404 NOT_FOUND`「人员不存在」。
- 仅可见人员的上级引用摘要允许跨出查看人范围：`superior: { id, name, avatar: null }`。没有上级时为 `superior:null`。
- 摘要随 PERSON.`superiorPersonId` 查看权；该字段不可见时 ID 和整段摘要均缺席。摘要内 `name` 还需 PERSON.`name` 查看权；撤权时姓名键缺席。
- 摘要固定白名单，姓名查询仅取本租户 `survey360_people.id / name`；不带邮箱、部门、手机、工号、挂接员工 ID 等字段。
- DEC-327：头像留空，真实头像由 F-058 后补；不读取或返回证件照 `idPhoto`。
- 首次写回执与幂等重放均按当前范围、当前字段权限再次校验和投影；摘要姓名使用当前 360 人员姓名，既有命令台账保留原业务结果。
- 审计新写入的人员前后快照在业务事务内冻结相同白名单摘要；读取时按当前上级 / 姓名联合权限逐路径裁剪差异、文本与快照。
- 既有历史审计没有冻结姓名的仍保留原 ID 快照，不以当前姓名伪造历史值；不改写旧审计。
- 审计范围沿用 `survey360AuditScope('person')`：精细化受限管理员仍看不到人员日志；姓名摘要不授予上级或日志访问权。
- REV = 缺 If-Match `400 REVISION_REQUIRED`；不符 `409 REVISION_CONFLICT`。IDEM = 缺命令键 `400 IDEMPOTENCY_KEY_REQUIRED`；同键异内容 `409 IDEMPOTENCY_CONFLICT`。
- 写入上级 ID 经现有 UUID 小写规范化；未改的上级按原值保留（DEC-319①），改为其他范围外或跨租户人员仍 `400 VALIDATION_FAILED / SUPERIOR_NOT_FOUND`。

## 查看人 × 出口 × 字段

| 查看人 | 详情 / 列表 / 写回执 / 重放 | 人员审计 |
|---|---|---|
| 下属可见，上级范围外，两个字段可见 | 上级 ID、姓名、avatar:null；无其他上级字段；上级独立 GET 404 | 另需原日志查看规则允许；受限管理员仍不可见 |
| superiorPersonId 查看权撤销 | 上级 ID 与整段 superior 缺席 | 上级 ID、摘要、相关差异与筛选结果均裁剪 |
| name 查看权撤销，上级字段仍可见 | 摘要只有 id、avatar:null，姓名键缺席 | 姓名差异、文本与快照字段缺席 |
| 下属移出范围 / 空范围 | 详情与重放 404，列表无该下属 | 不因摘要放宽日志访问权 |
| 对象 / 写按钮权撤销 | 按现有守卫 403，幂等重放同样拒绝 | 不因旧命令成功放宽查看权 |
| 其他租户人员 | 独立 GET 404；不能指定为上级，业务不变 | 固定查询与冻结摘要均只含本租户姓名 |

本任务没有 schema、迁移、附件、任职版本链或公共类型契约改动。
