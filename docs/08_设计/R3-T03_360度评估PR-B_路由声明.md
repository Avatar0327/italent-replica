## 1. 共用名称

### 1.1 对象

| 简称 | 对象编码 | 范围锚点 |
|---|---|---|
| ACT | `Survey360.Activity` | 活动可见：持“全部活动”(viewAll) 看全部；否则本人持有或被授权（`access.activityVisibleSql`） |
| REL | `Survey360.Relation` | 活动可见 + 精细化时评价对象与评价者的人员都在（用户 × Survey360）范围内（`people.personFilter`） |
| ANS | `Survey360.Answer` | 同 REL（答卷归属评价关系） |
| RES | `Survey360.Result` | 活动可见 + 精细化时评价对象的人员在范围内 |
| QN | `Survey360.Questionnaire` | 租户级；修改要本人创建或“编辑他人套卷”(editOthers) |
| SET | `Survey360.Settings` | 租户级 |

### 1.2 拒绝码

| 名称 | 拒绝 |
|---|---|
| `NF(X)` | 404 NOT_FOUND「X不存在」；不存在、无授权活动、范围外对象 / 评价者同一个响应 |
| `F_ACCESS` | 403 FORBIDDEN（缺对象数据操作 / 按钮 / 字段编辑权；不是租户成员） |
| `ID400` | 400 VALIDATION_FAILED「对象标识必须为 UUID」（`job/context.uuidParam`，小写规范化，DEC-194） |
| `REV` | 400 REVISION_REQUIRED（缺 If-Match）；409 REVISION_CONFLICT |
| `IDEM` | 400 IDEMPOTENCY_KEY_REQUIRED；409 IDEMPOTENCY_CONFLICT |
| `NOT_OPEN` | 409 CONFLICT `ACTIVITY_NOT_OPEN`（活动未启用：发送 / 取消待办与邀请；作答写入为“活动暂停中，请稍后评价”） |
| `NOT_DISABLED` | 409 CONFLICT `ACTIVITY_NOT_DISABLED`（停用后才能筛选数据 / 生成报告） |
| `DATA_CHANGED` | 409 CONFLICT `DATA_CHANGED`「数据发生变化,请启用-停用活动后再生成/更新报告！」 |
| `RATE` | 409 CONFLICT `RATE_LIMITED`（屏蔽疑似 / 生成报告 2 小时一次，原站文案） |

### 1.3 谓词、定位器、守卫、投影

| 种类 | 名称 | 含义（现状实现） |
|---|---|---|
| 定位器 | `s360.activity.byId` | `requireActivity`：活动可见，否则 `NF(活动)`；写命令事务内 `FOR UPDATE` |
| 谓词 | `s360.relationStates(admin)` | `progress.relationStates`：活动内未移除的评价关系，评价对象与评价者都过 `personFilter` |
| 定位器 | `s360.relation.byId` | 同上谓词按 ID 取，取不到 `NF(评价关系)` |
| 定位器 | `s360.sheet.byId` | `sheets.submittedSheets`：已提交答卷，评价对象与评价者过 `personFilter`，取不到 `NF(答卷)` |
| 谓词 | `s360.visibleObjects` | `reports.visibleObjects`：评价对象人员过 `personFilter` |
| 定位器 | `s360.template.byId` | `loadQuestionnaire(…, template=true)`：模板入口只取模板，套卷入口只取套卷，`NF(套卷模板 / 套卷)` |
| 守卫 | `s360.editableBy` | 套卷 / 模板：本人创建或 editOthers，否则 403 `QUESTIONNAIRE_NOT_OWNER` |
| 定位器 | `s360.todo.mine` | 待办 ID + 当前账号 → 该评价者当前有效的作答链接；别人的待办与不存在同一 `NF` |
| 定位器 | `s360.reportLink` | X-Tenant-Id + X-Survey360-Token（只存摘要）→ 转发链接；报告须在链接的报告清单里 |
| 投影 | `trim(OBJ)` | `context.trimAs`：按对象查看字段裁剪（列表逐行） |
| 投影 | `pick(ANS)` | 单张答卷卡片按 ANS 字段裁剪（卡片自带 items，不当列表信封） |
| 投影 | `s360.reportPresent` | 报告快照：顶层按 RES 字段裁剪；嵌套的 roleId / roleName / objectName / department / position / score 看不到时任何层级都去掉 |
| 投影 | `s360.tablePresent` | 报表：逐行按 RES 字段；列头的 roleId / roleName 同样裁剪 |
| 投影 | `asIs(receipt)` | 回执只有人数与原站提示文案（协议字段），不含对象字段 |

### 1.4 写入共性

- 写路由带 `Idempotency-Key`（`IDEM`，命令台账 ledger single）。
- 业务写与审计在同一事务（DEC-019 / 216）。
- 命令前（含重放）与命令事务内各判一次：功能权限、按钮、资源。
- 返回前按请求人当前的权限裁剪（新请求与重放同一路径，`context.write`）。
- 活动级批量命令（发送 / 取消待办、邮件邀请、屏蔽疑似、恢复、生成 / 转发报告）不针对单个带 revision 的对象，不要求 If-Match（`revisionFree`）。
- 单对象命令要 If-Match（`REV`）：答卷屏蔽 / 取消屏蔽按答卷 revision，重新作答按评价关系 revision，报告模板按模板 revision，模板新建 / 复制为 0。
