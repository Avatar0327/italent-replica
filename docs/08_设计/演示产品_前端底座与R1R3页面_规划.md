# 演示产品：前端底座与 R1 + R3 页面规划（DEC-456）

> 状态：总编排 2026-10-12 起草（DEC-456 ⑥：规划由 Claude 负责，前端实现优先交 Codex Astra）。
> 目标：2～3 天内出 R1 + R3 第一个可演示 MVP；7 天内 R1 + R2 + R3 完整 MVP。
> 流程：前端底座 FE-0 是契约级（布局、路由、组件、接口客户端、权限渲染），走重流程（Astra max 开发、Sol xhigh 审查）；其余页面片走演示层轻流程（DEC-456 ⑦）。

## 1. 现状

- `apps/web`：React 19 + Vite 8，约 80 个文件，按模块散落页面（org / job / transfer / employee-self-service / talent / account / self-service），`App.tsx` 用 `location.pathname` 手工分支，无路由库、无组件库、无统一布局 / 主题 / 接口客户端 / 权限渲染。
- 后端 `apps/api/src/modules`：org、job、establishment、employment、personnel、transfer、approval、permission、platform、tenant-settings、employee-self-service、avatar、idp、qualification、evaluation、survey360、talent、talent-review、succession、contracts。
- 已有可复用：`demo/` 下的演示身份切换（DemoIdentitySwitcher、tenant.ts）、各模块 `api.ts` / `messages.ts`。

## 2. 原则

1. **页面先复刻北森原站界面**（DEC-456 ④）：整体布局（顶部应用导航 + 左侧菜单 + 面包屑 + 内容区）、列表 / 详情 / 表单 / 抽屉的版式、主色与间距尽量贴近原站。参考截图只在本机 `~/Documents/italent-evidence-raw/`（DEC-456 ⑧），本机 codex exec 直接读取，**截图与原站资源不进仓库**；不拷贝原站图标、图片、字体文件，只复刻版式与配色。
2. **契约按 L3、实现可 L2**（DEC-456 ①）：页面只调用后端已有接口；后端没有的能力，页面照原站画出并接 L2 实现（后端补最小接口或前端演示桩，桩须集中在 `apps/web/src/demo-stubs/` 并在页面上标“演示数据”），升级 L3 时只替换实现。
3. **权限驱动渲染**：菜单、按钮、字段的显示 / 只读一律来自后端权限接口（功能权限 + 数据范围 + 字段权限），前端不硬编码角色判断。
4. **决策注释层**（DEC-456 ⑤）：每个页面可开关显示“注释”，标注原站做法、我们的取舍与对应 DEC 编号；内容放 `apps/web/src/annotations/<模块>.ts`，与业务代码分离。
5. 中文文案集中在各模块 `messages.ts`；业务日期按租户时区（DEC-056）。

## 3. FE-0 前端底座（契约级，约 2,500～3,000 行）

| 项 | 内容 |
|---|---|
| 依赖 | 路由：React Router；组件库：Ant Design 5（版式最接近原站，主题 token 调成原站配色）；表格 / 表单 / 树 / 选择器统一用组件库封装 |
| 布局壳 | 顶部栏（租户名、应用切换、搜索占位、消息、当前身份 / 演示身份切换、注释开关）、左侧菜单（按应用分组，来自权限接口）、面包屑、内容区；空状态 / 加载 / 错误页 |
| 路由 | 按应用分区：`/org`、`/job`、`/staff`、`/transfer`、`/approval`、`/self`、`/manager`、`/settings`、`/talent`、`/qualification`、`/evaluation`、`/survey360`、`/talent-review`、`/succession`、`/idp`；旧路径兼容跳转 |
| 接口客户端 | 统一 fetch 封装：会话、租户、身份头；统一错误码映射（403 / 404 / 409 revision 冲突提示刷新 / 422 字段错误回填表单）；命令幂等键；分页约定 |
| 权限渲染 | `usePermissions()`：菜单树、按钮编码、字段可见 / 可编辑；`<Can button="...">`、字段级只读 |
| 通用页面模板 | 列表页（筛选区、表格、分页、批量操作、导出占位）、详情页（头部摘要 + 页签 + 分区）、表单抽屉 / 弹窗（字段分组、校验、提交）、组织树选择、人员选择、日期（租户时区） |
| 决策注释层 | `<DecisionNote id>` 组件 + 全局开关 + 注释数据结构（原站做法、取舍、DEC 编号、L1 / L2 / L3 档位） |
| 主题 | 原站主色、字号、间距 token；浅色为主 |
| 测试 | Playwright 冒烟框架（登录演示身份 → 打开各应用首页不报错）；组件单测最小集 |
| 迁移 | 现有页面挂进新路由与布局，不重写业务逻辑 |

FE-0 完成前，页面片可叠在 FE-0 分支上开工（叠放最多一层，DEC-454 ⑥）。
