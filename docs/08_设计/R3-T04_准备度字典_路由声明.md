# R3-T04 PR-A 准备度字典：路由权限声明

> 依据：设计 `docs/08_设计/R3-T04_人才盘点_设计.md`（#113 b43df0b）§2.1、§6.1、§6.5“配置对象”行、§7 配置 CRUD 行；DEC-301①、DEC-121、DEC-082、DEC-043、DEC-080、DEC-067、DEC-216。
> 格式沿用 F-039 的逐路由声明与已合并的 R3-T01、F-047 路由声明。
> 范围：PR-A 新增的 5 条路由（`/api/tenant/talent-review/readiness-levels`）；同步端口、健康度端口与准备度端口是进程内可信端口，不是路由。

## 1. 共用契约

- 应用 `TalentReview`；RDY = `TalentReview.Readiness`（字段 `code / name / description / color / sortNo / enabled`，系统字段 `id / revision / createdBy / createdAt / updatedAt`；按钮 `create@list / update@detail / delete@detail`）。
- 数据范围按（用户 × TalentReview）解析，缺省为空（`permission/module-access.ts scopeAppOf`）。RDY 没有组织字段：只认**看全部或创建人**（DEC-121），新建只有看全部可建（DEC-082）。列表在 SQL 分页之前按 `configScopeSql`（`created_by`）过滤；详情、写入、重放中，不存在与范围外同为 `404 NOT_FOUND`。
- 标准身份“盘点管理员（人才盘点）”对 RDY 预置看全部（实体级），其他 TalentReview 对象不预置（设计 §6.1）。
- 响应按 RDY 当前字段查看权裁剪（`trimModuleResponse`，键缺席）；写响应与幂等重放同样按当前权限裁剪。
- REV = 缺或非法 `If-Match` 时 `400 REVISION_REQUIRED`；revision 不符 `409 REVISION_CONFLICT`；新建要求 revision = 0。IDEM = 缺 `Idempotency-Key` 时 `400 IDEMPOTENCY_KEY_REQUIRED`；同键异内容 `409 IDEMPOTENCY_CONFLICT`；命令指纹含 method / path / revision / 解析后的输入。
- 业务写、字段级审计（`talent-review.readiness.create|update|delete`，objectType = RDY）与命令台账同一租户事务。审计查看规则：`audit/visibility.ts` 为 `TALENT_REVIEW_CONFIG_OBJECTS` 登记创建人谓词（保留的 `.create` 元数据，删除后仍可判断）+ RDY 当前字段权。

## 2. 逐路由声明

路径以 `/api/tenant/talent-review` 开头，批次 A。

| 方法 | 路径 | 批次 | 类型 | 对象·操作·按钮 | 范围 | 字段 | 写足迹 | 其他 |
|---|---|---|---|---|---|---|---|---|
| GET | `/readiness-levels` | A | object | RDY；view；无按钮 | list `configScopeSql(created_by)`，看全部或创建人，分页前过滤 | projector `trimModuleResponse(RDY)`；筛选字段同受字段查看权约束：带 `enabled` 筛选而无 `enabled` 查看权 → 403 `FILTER_FIELD_HIDDEN`（第 2 轮 P2-01） | — | page / pageSize / enabled 非法 400 VALIDATION_FAILED；信封 `hasDataPermission = 看全部 ∨ 创建人规则`；排序 sortNo、code、id |
| GET | `/readiness-levels/:id` | A | object | RDY；view；无按钮 | point id → `requireConfigVisible(createdBy)`；范围外与不存在同为 404 | 同列表 | — | UUID 规范为小写；非法 400；ETag = revision |
| POST | `/readiness-levels` | A | object | RDY；create；create@list | guard `requireConfigCreatable`（只有看全部可建，否则 404）；返回前按当前范围复核 | 严格结构；逐字段编辑权（`writeFields`），含显式 null；返回按当前查看权投影 | fields body → `readiness.createReadiness` / `runCommand`；ledger single | REV（=0）、IDEM；编码 / 名称重复 409 `READINESS_DUPLICATE`；颜色 `#RRGGBB`；201；ETag |
| PATCH | `/readiness-levels/:id` | A | object | RDY；update；update@detail | point id → 行锁 → `requireConfigVisible` → REV；返回前按当前范围复核 | 严格结构（不收 `code`：建后不可改，400）；逐字段编辑权含显式清空；**改名要求看全部**：只有创建人范围时名称实际变化一律 403 `READINESS_NAME_REQUIRES_SEE_ALL`，判定在查重之前，不能用重名 409 探测隐藏记录（第 2 轮 P2-01） | fields body → `readiness.updateReadiness`；只记改动字段的审计；ledger single | REV、IDEM；名称重复 409；200；ETag |
| DELETE | `/readiness-levels/:id` | A | object | RDY；delete；delete@detail | point id → 行锁 → `requireConfigVisible` → REV → 引用守卫；首次与重放按删除快照的创建人复核当前范围 | 无字段赋值；返回删除前视图按当前查看权投影 | retained snapshot → `readiness.deleteReadiness`；删除快照审计；ledger single | 被引用 409 `READINESS_IN_USE`（`referrer` 为引用方编码，数据不变）；200；无 ETag |

## 3. 查看人 × 接口 × 字段

| 查看人 | 列表 / 详情 | 新建 / 修改 / 删除与重放 | 审计 |
|---|---|---|---|
| 盘点管理员（预置，看全部） | 全部准备度，字段按查看权 | 按数据操作权、按钮与字段编辑权 | 日志入口权 + RDY 查看权 + 看全部 |
| 有 RDY 查看权、范围缺省为空 | 列表空、`hasDataPermission = false`；详情 404 | 新建 404（不落库）；修改 / 删除 404 | 不可见 |
| 有创建人规则（使用用户） | 只看自己建的 | 只能改 / 删自己建的，不能改名（403，名称冲突不暴露隐藏记录）；新建 404（DEC-082） | 只看自己建的 |
| 缺某字段查看权 | 该键缺席；按该字段筛选 403 | 写该字段（含显式 null）403；响应同样缺席 | 该字段裁剪 |
| 缺按钮 | 正常读取 | 首次与重放都 403，业务不变 | — |
| 撤看全部后重放 | — | 404，业务不变 | — |
| 无 RDY 查看权 | 403 | 403 | 不可见 |
| 其他租户 | 列表不带出；详情 404 | 404 | 不可见 |
