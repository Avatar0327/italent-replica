# R3-T02 C1-7 图谱导出路由声明

依据：实现拆分 C1-7、规格 23 QL-R12、设计 §5.1 / §5.2 #2 / §5.3；PR-A 图谱查看投影。

| 方法 | 路径 | 类型 | 对象 / 操作 | 按钮 | 范围 | 字段 |
| --- | --- | --- | --- | --- | --- | --- |
| GET | `/api/tenant/qualification/chart-export` | object | `Qualification.QualificationStandard` / view | 图谱查看权，无独立按钮 | `ql.openRead(ql_standards)`，类别与标准均带 tenant_id；逐标准与查看共用 rowAccess，复用 loadChart 取数 | `ql.chartExport`，复用 presentChart；文件只来自已裁剪投影 |

- `categoryIds`：逗号分隔 UUID，按 DEC-194 小写规范化；1–20 项，不接受重复。数量超限 400 `VALIDATION_FAILED` / `EXPORT_CATEGORY_LIMIT`；空选择、非法 UUID、重复 400。
- 类别不存在或属于其他租户：整批 404 `NOT_FOUND`，固定文案“任职类别不存在”，无部分文件、无问题编号。无标准对象查看权 403 `FORBIDDEN`。
- DEC-352：管理单元外、空范围的类别 / 标准仍可查看，导出同查看。此处不新增范围限制。
- 有类别尚未建设标准：导出仅含空 `levels` 的工作簿，不补出隐藏字段或类别名称。
- 单选 `.xlsx`；多选每类别一个 `.xlsx`，打成 `.zip`。文件名使用规范化类别 ID，避免名称字段隐藏时仍从文件名泄露。
- Excel：级别横向为列，字段路径为行；值用 JSON 字面量保留字符串 / 数字 / 布尔 / 空值与数组类型。明细和能力标准展开为字段路径，只生成可见字段。标准 ID 在图谱列，空级别写 `levels = []`。
- 10,000 条图谱数据行（级别 + 标准明细 + 能力标准 + 级别描述，整批），加载嵌套数据前检查；标准按 ID 加共享锁，标准编辑 / 导入 / 通用指标覆盖与删除均锁同一标准。整批实际 Excel 工作表合计另限 10,000 行。超限 400 `VALIDATION_FAILED` / `EXPORT_ROW_LIMIT`，不截断。
- 单元格最多 32,767 字符，超限 400 / `EXPORT_CELL_LIMIT`；工作簿 XML 与整个下载最多 8 MiB，超限 400 / `EXPORT_FILE_LIMIT`。均为明确错误，无部分结果。
- 全部单元格用 inlineStr，防公式样式文本执行；JSON 转义控制字符与 Excel `_xHHHH_` 转义串，XML 实体转义；不提供公式或外部链接。
- `Cache-Control: no-store`；每次请求重新授权并投影，不落库、不缓存，没有写操作 / 命令台账 / 审计 / outbox。
- 文件版式与数量 / 行数 / 字节阈值没有原站明细证据：按本次派发选最简单可行版式，标 🟡；不改变 Excel、多选 ZIP 的已知格式。

F-039：`policy.ts` 声明、`required/qualification.ts` 准入义务，随基准 / 发现探测 / 摘要重算；不修改核心门禁文件或授权编码集合。
