### 1.3 谓词、定位器、守卫、形状

| 种类 | 名称 | 含义（现状实现） |
|---|---|---|
| 谓词 | `ql.readable(<表>)` | `qlReadable`：`scopeSql(owner)` ∪ (`public_down` ∧ `publicDownSql(owner_org_id)`)，分页前生效；列表信封 `hasDataPermission` |
| 谓词 | `ql.standardReadable` | `qlStandardReadable`：经所属类别套 `ql.readable` |
| 谓词 | `ql.dictionary` | 看全部 ∪ `created_by = 本人`（DEC-121） |
| 定位器 | `ql.<object>.byId` | 读：`rowAccess` → 读取谓词（`NF`）；写：事务内 `FOR UPDATE` → 可写谓词 `scopeSql`（仅向下公开可见 → `RO`；都不可见 → `NF`）→ revision（`REV`） |
| 守卫 | `ql.referenced(<object>)` | 引用对象：查看权（`NOVIEW`）→ `FOR SHARE` → 读取谓词（`NF`）→ 新引用须启用（`DISABLED`） |
| 守卫 | `ql.ownerUnit` | 资源集合（DEC-324② / DEC-339①，同 #106）：所属人 = 创建人；管理单元 = 创建人在 Qualification 的授权管理单元（`chooseUnit(…, QUALIFICATION_APP, body.ownerOrgId)`：`NO_UNIT` / 一个自动 / 多个须带 `ownerOrgId` 否则 `UNIT_REQUIRED` / 选范围外 `NF_UNIT`），再按新建范围复核；ownerId 不可传，ownerOrgId 只在新建与引入时可传、建后不可改（PATCH 严格结构 400）；引入整批同一个单元 |
| 守卫 | `ql.dictionaryCreate` | 字典（层级、等级方案）只有看全部能新建（DEC-082 / 121），否则 `NF` |
| 守卫 | `ql.jobLinks(<kinds>)` | 关联 / 引入岗职务：对象查看权 + 该岗职务在操作人组织员工数据范围内，否则 `NF(岗职务)`；同一关联类型内一个岗职务只能关联一个类别 / 级别（DEC-331④）：409 CONFLICT reason `JOB_ALREADY_LINKED`「此{职位\|职务\|职务序列\|职级类别}【编码】已有关联的任职类别【名称】」 |
| 守卫 | `ql.importCarry` | 引入时编码 / 名称缺省取自岗职务，仅当操作人当前对该岗职务的 `code` / `name` 有查看权（DEC-309 #4）；看不到又未填 → 400 `NAME_REQUIRED` / 按编码规则生成 |
| 守卫 | `ql.cellCarry` | 新格默认能力标准 = 指标说明，仅当操作人当前对 TGT.`description` 有查看权（DEC-309 #1），否则内容为空串 |
| 守卫 | `ql.commonOverwrite` | 指标改为通用 / 通用期间改说明：须带 `confirmOverwrite: true`，否则 409 `COMMON_OVERWRITE_CONFIRM`（原站确认文案）；锁序 标准（id 升序）→ 指标；引用集合变化 409 `RETRY`；逐标准审计 `qualification.standard.common-overwrite`（DEC-334①，跨范围照原站） |
| 守卫 | `ql.commonLock` | 通用指标所在格不可改能力标准：409 `ABILITY_LOCKED_BY_COMMON`（原样提交不算修改） |
| 足迹 | `ql.commandScope` | 命令内行锁后再判范围；新建按 `ownerUnit` / 字典 `scope.all` |
| 返回后 | `generic { targets: 'id', locator: ql.<object>.byId }` | `runWrite → requireStillVisible`：首次与幂等重放都按**当前**读取谓词复核结果对象；删除按快照锚点与 `scopeAllows`（撤权后重放 `NF`） |
| 形状 | `ql.<object>` | `read-model.view`（不出 tenant_id），经 `trimQualification` 按本对象字段权限裁剪 |
| 投影器 | `ql.standardNested` | 标准视图：顶层按 STD 字段权限；`common_overwrite` 能力标准只在查看人当前对 TGT.`description` 有查看权且该指标在 `ql.readable` 内时带内容，否则 `projectionHidden: true`、无 content（DEC-309 #2） |
| 投影器 | `ql.gradeDescriptions` | 手改行按 TGD.`description` 查看权；未手改的投影行按 GS.`details` 查看权（§5.2 #3）；看不到省略 description |

### 1.4 写入共性

- 全部写路由：`If-Match` 必带（`REV`），`Idempotency-Key` 必带（`IDEM`；命令台账 `ledger single`），业务写与审计同事务（DEC-019 / 216）。
- `write.fields = 'body'`（`parseBody` 严格结构，未知键 400）；`controls = ['confirmOverwrite', 'items', 'ownerOrgId']`：确认框、引入条目与所属管理单元的选择不是写字段，不按字段编辑权拦截（`access.checkWriteFields`；单元由 `ql.ownerUnit` 校验）。
- 按钮：新建 `create@list`、修改 `update@detail`、删除 `delete@detail`；编码规则只有 `update@detail`。

## 3. 示例声明（F-039 PR-A 合并后照此转写）

```ts
const NF = (_label: string): Denial => ({ status: 404, code: 'NOT_FOUND' });
const QL_CONTROLS = ['confirmOverwrite', 'items'];

declare(router, 'PATCH', `${QL_BASE}/targets/:id`, {
  kind: 'object', object: TGT, operation: 'update', button: { code: 'update', level: 'detail' },
  scope: { mode: 'point', target: { param: 'id' }, locator: 'ql.target.byId', denied: NF('指标') },
  fields: { mode: 'shape', shape: 'ql.target' },
  guards: ['ql.referenced(targetType)', 'ql.referenced(gradeScheme)', 'ql.commonOverwrite'],
  write: {
    fields: 'body', controls: QL_CONTROLS, footprint: 'ql.commandScope',
    result: { generic: { targets: 'id', locator: 'ql.target.byId' } }, ledger: 'single',
  },
  invalidId: { status: 400, code: 'VALIDATION_FAILED' },
}, handler);

declare(router, 'GET', `${QL_BASE}/standards/:id`, {
  kind: 'object', object: STD, operation: 'view', button: { none: true, reason: '详情按对象查看权' },
  scope: { mode: 'point', target: { param: 'id' }, locator: 'ql.standard.byId', denied: NF('任职资格标准') },
  fields: { mode: 'projector', projector: 'ql.standardNested', shape: 'ql.standard' },
  // 覆盖写入的能力标准：可选分支，未通过只省略内容并标 projectionHidden（DEC-309 #2）
  optional: {

      scope: { mode: 'list', predicate: 'ql.readable(ql_targets)' },
      fields: { mode: 'fixed', keys: ['description'], dec: 'DEC-309', intersect: TGT } },
  },
  invalidId: { status: 400, code: 'VALIDATION_FAILED' },
}, handler);
```
