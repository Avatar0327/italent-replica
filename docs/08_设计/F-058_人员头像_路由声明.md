# F-058 人员头像路由与授权声明

依据：17 头像来源补充、DEC-327 后续派发、DEC-325③、DEC-331①；沿用 F-039 当前 Markdown 声明格式。

## 授权契约

- 头像属于租户内账号，以 `(tenantId,userId)` 存储，员工和 360 人员经已有账号人员绑定只读引用。原站 `PictureUrl` 对应本系统 `avatar:{id,url}|null`。不从证件照 `idPhoto`、联系方式或邮箱推断头像归属。
- 本人入口由租户中间件的当前用户确定目标，不接收用户或员工 ID。有效成员可设置自己头像，无企业管理员代改入口；不需要给本人授予业务对象或全部组织范围。
- 每次请求校验账号、租户、成员；写入在台账查询前校验，事务内锁成员行后再次校验。登记回执的 revision / ETag 固定为该命令产生的版本，附件元数据按当前状态读取；上传 / 删除回执投影当前本人头像，不能恢复已替换或删除的图片。登记后自动上传只使用登记回执版本，期间有变更即 409，须显式刷新重提。
- 头像展示不要求目标人员在查看人的数据范围内（DEC-327）。租户成员凭不可预测的附件 UUID 读取本租户当前头像，返回图片字节；没有按人员 ID 查询头像的接口，也不返回文件名、哈希、账号、邮箱、部门或员工 ID。
- registered、pending_cleanup、外租户、不存在附件均不可读。图所属成员非 active 时不可读。字节入口统一 `Content-Disposition:inline`、`X-Content-Type-Options:nosniff`、`Cache-Control:private,no-store`，不返回原文件名。
- 人员列表和详情本身继续按原对象权限及范围过滤。真实头像摘要随当前姓名查看权；上级摘要额外随 superiorPersonId 查看权。引用图片不开放范围外人员的独立详情，不扩大候选列表、审计或汇总范围。
- 公开 360 链接继续使用 `X-Tenant-Id` 和 `X-Survey360-Token` 请求头。图片代理仅授权当前有效令牌本单可以显示姓名的人员；匿名评价者无真实头像，候选仍显示默认缩写。令牌不进 URL、审计或响应。
- 本人设置、登记、上传和删除按独立头像 revision 校验，初始值 1；同一事务写头像状态、审计、outbox 和命令台账。字节不进入后三者。所有写请求只接受 JSON、同源和客户端命令 ID；删除即使带空载荷也严格拒绝其他键。
- 原站存储和上传限制仍待 #126 补证。本次按派发复用 F-038 的数据库字节存储、5 MiB 和 JPEG/JPG/GIF/PNG/BMP 静态图片限制，按内容完整解码，不能只校验扩展名或文件头。

## 新路由

REV：缺 If-Match 为 400 REVISION_REQUIRED，旧值为 409 REVISION_CONFLICT。IDEM：缺命令 ID 为 400，异内容为 409；首次与重放同样校验本人当前授权。批次 A。

| 方法 | 路径 | 类型、操作、按钮 | 范围 | 字段 | 写足迹、其他 |
|---|---|---|---|---|---|
| GET | `/api/tenant/account/avatar` | self；头像查看；本人个人设置 | 当前有效账号与成员，仅本人 | revision、本人显示名、avatar 固定引用 | 无；ETag、no-store，不写初始化行 |
| POST | `/api/tenant/account/avatar/attachments` | self；登记；本人上传 / 替换 | 当前有效成员本人，事务内成员锁 → 头像头锁 | 严格 filename/contentType/byteSize/sha256；响应当前本人附件元数据，revision / ETag 为原登记命令版本 | 元数据先登记；头像头 revision、成功审计、outbox、ledger 同事务；首次及重放均不得改用后来版本；旧台账无 revision 时按已匹配原请求版本 + 1 恢复；REV、IDEM |
| POST | `/api/tenant/account/avatar/attachments/:attachmentId/upload` | self；上传；本人上传 / 替换 | UUID 规范化；附件必须本租户本人 registered | 严格 base64；响应当前本人头像状态 | 大小/哈希/内容解码，旧 uploaded → pending_cleanup、新图 → uploaded；全部同事务；REV、IDEM；仅此路径放宽 JSON 上限 |
| DELETE | `/api/tenant/account/avatar` | self；删除；本人删除 | 当前有效成员本人 | 无目标 ID、严格空载荷；响应当前头像状态 | 所有已登记及旧附件 → pending_cleanup，保留元数据和删除快照；REV、IDEM |
| GET | `/api/tenant/avatars/:attachmentId/content` | member；头像展示；无按钮 | 当前有效成员，本租户、当前 uploaded、图所属成员有效；不要求目标人员范围 | 只返回字节及固定 MIME，没有人员字段或附件元数据 | 无；统一 404、inline/nosniff/no-store |
| GET | `/api/survey360/link/avatars/:attachmentId/content` | link；本单头像展示；无按钮 | 当前有效令牌、当前活动 / 单据 / 未移除人员、实名白名单、当前 uploaded | 只返回字节，匿名评价者和他单人员同 404 | 无；复用 linkRead；inline/nosniff/no-store，token 只在头中 |

以下均保留现有功能、按钮、数据范围和裁剪规则，只给已有具名人员摘要增加独立账号头像引用。无姓名查看权不带真实头像；原来只给 ID 的引用不补姓名。

## 查看人 × 出口 × 字段

| 查看人 | 本人设置与写入 | 登录头像字节 | 人员 / 上级摘要与审计 |
|---|---|---|---|
| 当前有效成员本人，无业务身份 | 本人姓名、revision、引用 / 本人登记元数据；允许本人设置 | 允许本租户当前头像，只返回字节 | 不取得其它业务权限；审计另需原日志功能，头像日志只能本人 |
| 当前有效成员，目标人员范围外 | 只能修改自己的头像 | 允许目标头像图片，不能带出人员字段 | 仅原出口允许的具名摘要；范围外上级只带 id/name/avatar，独立 GET 仍 404 |
| 姓名查看权撤销 | 本人账号权独立 | 字节权限不新增姓名查询 | 业务摘要不返回真实头像；审计 id/url、差异、文本按当前字段权裁剪 |
| 成员撤销 / 账号停用 / 租户不可用 | 首次与重放均按原 401/403 拒绝 | 同样拒绝 | 不能用旧响应或命令恢复访问 |
| 其他租户人员 / 附件 | 无跨租户本人写入 | 与不存在同 404 | 查询、绑定、存储、事件均显式限定租户 |
| 有效公开链接 | 无账号头像修改权 | 不可调用登录接口；仅本单实名头像代理 | 不带匿名评价者头像，不扩大到他单；撤令牌、移除关系、取消单据、替换 / 删除图后复核 |

## 状态 × 操作

| 附件状态 | 本人元数据回查 | 图片内容读取 | 上传 | 删除 |
|---|---|---|---|---|
| registered | 原登记命令可回查 | 404 | 本人、当前 revision、有效内容成功；原头像保留到上传完成 | 同事务待清理，旧登记不可再上传 |
| uploaded | 本人原命令显示当前状态 | 当前授权通过才可读 | 新命令不能复用已上传附件；旧命令只重放当前投影 | 待清理，内容立即 404 |
| pending_cleanup | 仅本人原命令元数据 | 404，与不存在相同 | 404；原上传重放不能复活 | 幂等原命令不再写；新命令按当前 revision |

物理清理消费者与事件通知消费者沿用现有待接线边界；本任务完成持久化待清理状态、删除快照与不可读语义。尚未合入 main 的评审组模块复用人员头像查询 helper，不在本分支修改其它任务实现。
