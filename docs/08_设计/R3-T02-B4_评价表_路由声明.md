# R3-T02 PR-B B4 评价表（标准模式）：路由权限声明（F-039 格式，按现状契约）

> 依据：R3-T02 设计 §3.2、§5.1、§5.2 #6；拆分方案第 4 节 B4 行；规格 24 EV-R3～R5、R40；DEC-082、DEC-324②、DEC-352、DEC-374⑥、DEC-380、DEC-388①。
> 已转写为 `apps/api/src/modules/evaluation/policy.ts`，必需项表 `tests/acceptance/support/route-policy/required/evaluation.ts` 逐端点登记。
> 范围：**5 条**（评价表 × 列表 / 详情 / 新建 / 修改 / 删除），另有通用评分项 PATCH / DELETE 新增一个披露分支（引用方评价表的可见范围）。

## 1. 共用名称

| 简称 | 对象编码 | 范围锚点 |
|---|---|---|
| EF | `TEvaluation.EvaluationForm`（评价表，带嵌套评分项） | 所属组织 `owner_org_id` 在范围内 ∪ 所属人 `owner_id`；**无向下公开**（DEC-324②），读写同一谓词，范围外 404 |
| GI | `TEvaluation.GeneralScoreItem`（通用评分项，字典） | 看全部 ∪ 创建人（DEC-121）；评分项引用要有查看权 |
| TG | `Qualification.Target`（指标，只放开查看，DEC-352） | 查看权 + 名称字段权即可，不按范围 |

| 名称 | 说明 |
|---|---|
| 谓词 `ev.owned(ev_forms)` | `scopeSql(scope, { org: owner_org_id, creator: owner_id })`，分页之前 |
| 范围 `ev.evaluationForm.ownerOrg` / 守卫 `ev.ownerOrgInScope` | 新建 / 改所属组织：须存在且在范围内（范围外与不存在同一 404，DEC-082） |
| 守卫 `ev.newFormRefs` | 只校验**新增**的引用：通用评分项——无字典查看权 403 `NO_GENERAL_ITEM_ACCESS`、不存在 / 字典范围外同一 404、已停用 400 `REFERENCE_DISABLED`；隐藏指标——`assertQualificationRefs`（403 / 404 / 400）。原有引用原样保留不重校（DEC-281⑧） |
| 披露 `generalItemRefs` / `targetRefs`（optional，非准入） | 评分项里通用评分项名称（字典查看权 + 字典范围 + 名称字段权）、隐藏指标名称（指标查看权 + 名称字段权），否则只给 ID（设计 §5.2 #6） |
| 披露 `referrers`（通用评分项 PATCH / DELETE） | 停用 / 删除被评价表引用的通用评分项时，409 提示只列操作人看得到的评价表（评价表查看权 + 所属组织范围），其余计入“其他 N 个”（DEC-374⑥） |
| 业务校验 | 评分方式 `by_indicator` 须有总分计算规则、`by_total` 不能有；通过分数 ≤ 满分；standard ≤ 1；权重 0～100（B2 `computeScoreWeights`）；评分项 ≤ 50 🟡；EV-R5 锁 409 `FORM_LOCKED`（`formLockedByActivities`，本 PR 恒不锁） |

写命令经 `runWrite` / `runDelete`：对象权限、按钮、字段、评价表范围与引用访问都在命令事务内由 `ledgerExit` 之前的 `before` 重新解析（首次 / 直接重放 / 失败后回查同一出口，DEC-388①）；删除重放按快照所属组织 ∪ 所属人复核。

## 2. 逐条声明

| 方法 | 路径 | 对象·操作·按钮 | 范围 | 其他 |
|---|---|---|---|---|
| GET | `/api/tenant/evaluation/evaluation-forms` | EF；view | list `ev.owned(ev_forms)` | `ev.filterFieldVisible`；披露 `generalItemRefs`、`targetRefs` |
| GET | `/api/tenant/evaluation/evaluation-forms/:id` | EF；view | point `ev.evaluationForm.byId`（404） | 披露同上 |
| POST | `/api/tenant/evaluation/evaluation-forms` | EF；create；`create@list` | `ev.evaluationForm.ownerOrg` | `ev.newFormRefs`；披露同上 |
| PATCH | `/api/tenant/evaluation/evaluation-forms/:id` | EF；update；`update@detail` | point `ev.evaluationForm.editable` | `ev.newFormRefs`、`ev.ownerOrgInScope`；披露同上 |
| DELETE | `/api/tenant/evaluation/evaluation-forms/:id` | EF；delete；`delete@detail` | point `ev.evaluationForm.editable` | 评分项随评价表删除，快照连同评分项写进审计；被活动引用拒删由 B5 登记钩子 |

编码字段 / 名称唯一性 / 删除 / 停用规则暂按保守默认，待取证 [#216](https://github.com/Avatar0327/italent-replica/issues/216)。
