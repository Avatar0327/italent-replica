## 1.1 F-091 对齐后的设置与出口（DEC-413）

| 打分规则 | 满分 / 通过分 | 总分计算规则 | 评分项权重 | 投票设置 |
|---|---|---|---|---|
| `by_indicator` | 必填、通过分可超过满分 | `average` / `weighted` / `sum` | 可设置并返回 | 不适用 |
| `by_total` | 必填、通过分可超过满分 | 不适用，存 null | 不设置、不返回 | 不适用 |
| `by_vote`、不启用参考评分 | 不适用，存 null | 不适用，存 null | 不设置、不返回 | `votePassRatio` 必填（百分数 0～100）、`indicatorReference=false` |
| `by_vote`、启用参考评分 | 同指标评分 | 同指标评分 | 同指标评分 | `votePassRatio` 必填、`indicatorReference=true` |

- 模式切换隐含清空的分数、规则、投票设置、评分项权重，都按当前字段编辑权复核；只读 / 隐藏字段不能借模式切换改写。
- `weightWarning` 为只读派生字段：加权合计≠100% 返回 `{ total, message }`，正常为 null；评分项不可见时连同警示裁剪。列表、详情、首次回执和重放同一口径。
- 评价表停用在本对象 `FOR UPDATE` 后调用 `rejectInUse(..., 'disable')`。B5 登记实际活动环节引用查询，提示固定为“已在活动中使用此评价表，无法停用”；活动新增引用先对评价表 `FOR SHARE` 并重新检查启用状态，两种顺序均串行。
- B5 活动表尚未合入，`AC-EV-F091-reference-pg` 使用隔离库引用方验证引用钩子及真实锁等待；活动 HTTP 入口集成由 B5 验证。EV-R5 的“已发布且有提名”修改锁仍由 B6 接入，与停用引用检查分开。

写命令经 `runWrite` / `runDelete`：对象权限、按钮、字段、评价表范围与引用访问都在命令事务内由 `ledgerExit` 之前的 `before` 重新解析（首次 / 直接重放 / 失败后回查同一出口，DEC-388①）；删除重放按快照所属组织 ∪ 所属人复核。
