## 2. 取证结论（DEC-380，Q-M0-170 / 171，#196，照原站）与同口径

- **名称租户内唯一**：重名 409 CONFLICT，专用 reason——活动周期 `ACTIVITY_CYCLE_NAME_EXISTS`、message「活动周期名称已存在，请重新输入」；通用评分项 `GENERAL_SCORE_ITEM_NAME_EXISTS`、message「名称已存在，请重新输入」（原站提示原文）。名称 trim 后精确比较（大小写区分，同 B1a / PR-A 字典口径），库内唯一约束兜底并发；创建人范围改名撞上范围外的名称也是同一提示（照原站，DEC-373③）。名称长度按系统统一上限 ≤100（D-069）。
- **活动周期没有描述字段**，请求体带 `description` 400。
- **通用评分项的描述（原站叫「评价标准」）最多 500 字**，超出 400，提示「最多输入500个字」；可空，可显式清空（需编辑权）。
- **被引用时拒绝停用（只拦 启用 → 停用）**，两类各自照原站（DEC-380③）：
  - 活动周期：被活动引用的“停用”事先置灰，服务端拒绝停用 409，提示与 reason 由引用方（B5）登记；
  - 通用评分项：点击后拒绝并列出引用它的评价表——响应 409，message「此评分项被评价表【甲、乙】及其他 N 个引用，无法停用」，`details.referrers`（只含操作人看得到的评价表 `{id, name}`）与 `details.otherCount`（看不到的计数，DEC-374⑥）；引用来源为空（B4 之前不会触发），B4 登记规则时用 `references` 查询给出评价表及“操作人是否看得到”。
- 删除被引用拒删钩子位同 B1a（B4 / B5 登记引用方）。
- 排序只用名称（可见时）再按主键；`?enabled=` 筛选须有 `enabled` 字段查看权（`FILTER_FIELD_HIDDEN`，守卫 `ev.filterFieldVisible`）；名称无查看权时只按主键排序。
