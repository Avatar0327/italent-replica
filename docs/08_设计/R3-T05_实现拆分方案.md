1. 先单独提交失败测试，再提交实现；测试文件名带 AC 编号（设计 §11 的文件按子 PR 拆分归属：AC-SC-01 → A1 / A2，AC-SC-02 → A3，编译器 → B1，AC-SC-07 / 健康度 → B5 / D4，AC-SC-risk → B4，AC-SC-06 → C3，AC-SC-03-04 / sync-protocol → D1 / D2 / D3，pg 交错 → D5）。
2. 本地只跑 lint、typecheck 与改动相关测试（DEC-351）；交审前按 dev-selfcheck 跑 OCR 自检。
3. PR 描述带 §42 提交前自查清单、查看人 × 接口 × 字段矩阵（引用设计 §8.2 对应行）、写入口 × 值来源表（引用 §8.6 对应行）。
4. 超过 1500 行先在 PR 描述提出再拆，停下等总编排确认（DEC-338）。
