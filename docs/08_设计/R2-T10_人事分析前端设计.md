## 1. 范围与分工

- B48～B51 为「人事看板」的四个页签。B55「合同情况」是另一块单板，复用同一外壳，内含合同变动、签署情况两个分区。

- B56 的 152 张报表和报表设计器、Ocean 嵌入、订阅、编辑、帮助设置、预警、打印均在首版范围外。B56 菜单入口推荐隐藏，见 §8 U1。按 DEC-402 直接采用下列路由和接口。

## 3. 共用页面行为与请求边界

### 3.1 筛选、候选与刷新

页面使用复刻系统现有布局、Ant Design 表格和查询表单。看板切页签只读当前概览；B51 的四个分区同屏。报表入口根路径默认展示该入口的第一张已交付报表，页签顺序遵循 §4。日期采用 `session.today` 或 `tenantDate(…, session.timezone)`，发请求用 YYYY-MM-DD，时间戳用租户时区显示。看板默认按租户今天统计，日期仅在下文明确有对应控件时可编辑。应用筛选时验证日期顺序、日期/月份合法性和选项类型，空选择省略参数。初次查询用默认筛选，之后「查询」应用草稿，换筛选页码回到 1。图表、明细和下载一律用**最近成功查询的筛选**，草稿可继续修改；显示当前结果条件，脏草稿不得被截进代表已应用结果的 PNG。

- `useReportRead` 以租户、身份、请求路径和查询代次丢弃过期回执。业务层再按页签、应用筛选和权限刷新周期清理详情、读请求、选项、导出对象 URL 与截屏任务，拒绝旧响应落地。表格、下载、明细只接受当前成功响应；切换身份、租户、筛选查询或收到当前请求的 401/403 后，清掉上一次结果及进行中的下载。页面状态放组件内，URL 仅放页签路径，返回重读。无本地持久化统计、个人明细或下载缓存。
- DEC-763④、DEC-810②要求看板和报表部门候选是租户内完整树，含选到范围外后由统计接口返回空结果的用法。现有 `GET /api/tenant/org/organizations/tree?dimension=admin&asOf=…` 要求组织查看权、经过组织范围及字段裁剪；即使个别用户返回完整树，也不能作为该契约的保证。需要 §8 U2 的独立候选契约。候选不可确认时保留可用的无条件概览和其余筛选，该控件显示「筛选项暂不可用」；已选候选读失败时保留已应用条件并提供重试，不能以无条件结果覆盖旧条件。
- 字典按下表复用已授权读路径。候选对象 403、字段缺席、分段结果为零和候选接口失败各自处理。缺候选时只影响该筛选；业务页成功读取得以继续。分页候选读取到完整成功结果后才视为候选可用；复用支持服务端搜索/分页的控件时保留其分页语义。

2. 以当前**成功且仍有效**的显示版本为输入，固定标题、口径说明、已应用筛选回显、图形、图例和数值标签。捕获整块看板纵向内容，包括首屏以下组件；B51 四分区都在同一张图。尺寸以当前 PC 内容栏宽度和现有断点布局为准，避免强制截 1440px 而裁掉窄窗的右列；长表按组件当前纵/横滚动可视区裁切。「当前可见行」指当前页与表格视口交集内的行，部分露出的行只截露出部分；不展开表、改变分页、关闭虚拟滚动或收集隐藏数据。抽屉与弹层在捕获根之外。
3. 使用模块内前端捕获适配，优先捕获本地已渲染内容（固定布局的 HTML 与可内联图形）；开发前以 B50 的编制表和 B51 四分区验证截图方案。捕获不发 API、图片、字体等网络请求，图形/文字资源用本地已就绪样式或内联系统资源。PNG 不依赖 CDN、后端生成、重新取数或导出队列。捕获时尺寸、滚动偏移和筛选集中读一次；动作进行中防重复，显示「正在生成图片」。字体或图表未就绪、内嵌表格未加载完成时等待就绪或取消，显示失败及可重试。
4. 以浏览器可分配画布为限，在捕获适配中先检查宽高和像素预算，必要时在保证可读性的情况下等比降采样，仍超限就提示「看板过大，无法生成图片」，避免生成缺页或截断图。生成期间换看板、换已应用筛选、重排/滚动导致版本变化、租户或身份切换、权限重载或收到当前请求的拒绝，丢弃旧结果。下载前复核捕获版本与当前显示授权状态，撤回 Blob URL、释放克隆节点。该本地操作以**当前客户端已知**的权限状态为边界，服务端静默撤权在收到新快照或拒绝之前不会被 PNG 独立探知。
5. 空数据权限或页面未成功时停用下载。可访问的真实零值看板仍可保存。失败只显示「图片生成失败，请重试」，保存成功前校验 Blob 类型和非空；不送出半张图或旧条件文件。开发验收须解码实际 PNG，核对宽/高、筛选、首尾组件和可见行，不能仅断言下载事件。
