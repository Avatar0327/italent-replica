## 1. 共用名称

### 1.1 对象

| 简称 | 对象编码 | 范围锚点 |
|---|---|---|
| AT | `TEvaluation.ActivityType`（活动类型，字典） | 无组织字段；看全部 ∪ 创建人 `created_by`（DEC-121）；新建只认看全部（DEC-082 / DEC-356②） |

TEvaluation **没有向下公开**（设计 §5.1，DEC-324②），也没有“看得到但不在写范围”的一层：读、写同一谓词，范围外的行读写都是 404（不存在与范围外同一个响应体），所以没有
`RO` / `RO_SCOPE` 这类拒绝码。

### 1.2 拒绝码

| 名称 | 拒绝 | 现状来源 |
|---|---|---|
| `NF` | 404 NOT_FOUND「活动类型不存在」（不存在与范围外同一响应体）；字典新建遇到非看全部同样 404 | `access.requireVisible`、`store.rowAccess / lockEditable`、`activity-type-service.createActivityType` |
| `F_ACCESS` | 403 FORBIDDEN（没有对象数据操作权 / 按钮 / 字段编辑权，含显式写 false、清空） | `evaluationContext`、`evaluationWriteContext`、`checkWriteFields` |
| `ID400` / `Q400` | 400 VALIDATION_FAILED（路径 UUID 非法 / page、pageSize、enabled 查询参数非法；请求体结构不符、未登记的键） | `talent/http.uuidParam / pageQuery / booleanQuery`、`parseBody` |
| `REV` | 400 REVISION_REQUIRED（缺 If-Match）；409 REVISION_CONFLICT（新建非 0 / revision 不符） | `talent/http.revision / requireNew`、`store.lockEditable` |
| `IDEM` | 400 IDEMPOTENCY_KEY_REQUIRED；409 IDEMPOTENCY_CONFLICT（同键异内容） | `runCommand` |
| `IN_USE` | 409 CONFLICT，reason 由引用方给出（B5 登记 `ACTIVITY_TYPE_IN_USE`）；B1a 没有引用方，不会触发 | `usage.rejectInUse` |

### 1.3 谓词、定位器、守卫、形状

| 种类 | 名称 | 含义（现状实现） |
|---|---|---|
| 谓词 | `ev.dictionary` | 看全部 ∪ `created_by = 本人`（`access.scopePredicate`，分页之前生效）；列表信封 `hasDataPermission = scope.all ∨ 有创建人维度` |
| 定位器 | `ev.activityType.byId` | 读：`rowAccess` → 范围谓词（`NF`） |
| 定位器 | `ev.activityType.editable` | 写：事务内 `FOR UPDATE` → 同一范围谓词（`NF`）→ revision（`REV`） |
| 范围 | `see-all` | 新建只认看全部（DEC-082 / 121），否则 `NF` |
| 足迹 | `ev.commandScope` | 命令内行锁后再判范围；新建按 `scope.all` |
| 返回后 | `generic { targets: 'id', locator: ev.activityType.byId }` | `runWrite`：首次与幂等重放都按**当前**范围复核结果对象；删除按快照的创建人与 `scopeAllows`（撤权后重放 `NF`）；响应按当前字段权限裁剪 |
| 形状 | `ev.activityType` | `read-model.view`（不出 tenant_id），经 `trimEvaluation` 按本对象字段权限裁剪 |
| 钩子位 | `usage.registerInUse(object, rule)` | 被引用拒删：B4 / B5 登记引用查询，删除命令在同一事务里执行，命中 409；**不是权限判定，不登记为 guards** |

### 1.4 写入共性

- 全部写路由：`If-Match` 必带（`REV`），`Idempotency-Key` 必带（`IDEM`；命令台账 `ledger single`），业务写与审计同事务（DEC-019 / 216）；审计动作 `evaluation.activity-type.create|update|delete`，对象 `TEvaluation.ActivityType`，前后值在同事务内回读。
- `write.fields = 'body'`（`parseBody` 严格结构，未知键 400——含“同步任职记录”，DEC-025 不提供）；没有控制键。
- 按钮：新建 `create@list`、修改 `update@detail`、删除 `delete@detail`。

## 2. 逐条声明

批次一律 A。

| 方法 | 路径 | 类型 | 对象·操作·按钮 | 范围 | 字段 | 写足迹 | 其他 |
|---|---|---|---|---|---|---|---|
| GET | `/api/tenant/evaluation/activity-types` | object | AT；view；无按钮（列表按对象查看权） | list `ev.dictionary` | shape ev.activityType | — | `Q400`（enabled 过滤；page / pageSize）；按顺序号、名称排序 |
| GET | `/api/tenant/evaluation/activity-types/:id` | object | AT；view；无按钮（详情） | point `ev.activityType.byId`（`NF`） | 同上；ETag = revision | — | `ID400` |
| POST | `/api/tenant/evaluation/activity-types` | object | AT；create；create@list | `see-all`（`NF`） | 同上 | fields body → ev.commandScope / generic | `REV`（requireNew）；`IDEM`；字段 name 必填 ≤100、displayOrder ≥0、enabled 缺省 true、syncQualification 缺省 false |
| PATCH | `/api/tenant/evaluation/activity-types/:id` | object | AT；update；update@detail | point `ev.activityType.editable`（`NF`） | 同上 | fields body → ev.commandScope / generic | `ID400`；`REV` |
| DELETE | `/api/tenant/evaluation/activity-types/:id` | object | AT；delete；delete@detail | point `ev.activityType.editable`（`NF`） | 同上（删除前快照） | fields none → ev.commandScope / generic | `ID400`；`REV`；`IN_USE`（钩子位） |
