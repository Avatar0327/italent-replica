## 取证操作注意事项（原站界面陷阱，取证窗口维护）

- **用户授权的组织范围选择器，“包含下级”默认是勾选的**（2026-10-09，W-710 / DEC-356）：右侧“已选组织”表头和每一行的“包含下级”在界面上都是勾着的，但读取 input 的 checked 值是 false，读不出来。不手动取消的话，保存后显示“组织名(包含下级)”，范围会把下级带进来。需要“不含下级”时，必须在界面上点掉那一行的勾，保存后再核对列表文字里有没有“(包含下级)”。
- **流程设计器点「编辑」会自动生成草稿版本**（W-688）：只想查看时，从「历史 → 查看」进入。
- **任职类别「停用」没有确认框，点下立即生效**（W-705）：只读核对时不要点。
- **打开任职资格标准详情页，前端会自动调用一次 saveQualificationDetails**：这是页面加载行为，不算手动写入。
