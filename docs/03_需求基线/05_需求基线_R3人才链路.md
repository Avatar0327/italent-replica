# 需求基线：R3 人才链路

> 版本：v0.2（2026-09-28，纳入 DEC-024~027）
> 本文件给 R3 的规格文档编需求号，使路线图任务、需求、验收三者可以追溯。规则细节以规格文档为准，这里只写**要做什么、边界在哪、按什么验收**。
> 证据标记：🟢 运行 / 配置证据，🟡 官方文档或推断，🔴 未取证。R3 的规则**全部来自官方文档（🟡）**，对象与字段来自配置证据（🟢）；本租户未做写入测试。
> 范围依据：DEC-009（继任与发展为唯一入口；人才标准独立；人才评定作为任职资格子功能纳入；人才模型、标签库暂缓）。

## REQ-EXP-001 统一表达式引擎与函数库（R3-T00，DEC-024）

| 项 | 内容 |
|---|---|
| **依据** | DEC-024：完整复刻北森函数库 |
| **范围** | 表达式语法（字段引用、四则、比较、逻辑、if/then/else、Def 变量、ToNumber 等类型转换、中英文函数名）；取数函数：绩效（`PerformanceCent/Grade`、`PerformanceLastCent/Grade`）、360（`Lastest360Cent` 各参数）、测评（`LastestAssessmentCent`）、排名（`Ranking` 百分位 / 排序号）、平均等聚合；盘点与评定专用函数（取模块分或结果、统计指定结果的模块数、指定模块所有评委平均分、统计指定得分或结果的评委数、所有评委平均分）；计算优先级与依赖顺序；错误提示（空值比较、单选列表按值比较） |
| **使用方** | 盘点结果设置、盘点计算规则、人才评定高级模式、组织健康度、职位风险等级、人才池规则、评定参评条件 |
| **规格** | `26` §3.4–3.5、`24` EV-R8、`27` SC-R9/R10 |
| **测评数据（DEC-031）** | 人员子集“测验结果”（测验名称、维度名称、总分、维度得分、测验时间、来源），导入或开放接口写入；`LastestAssessmentCent` 从该子集取数；“最近一次”口径为计算规则参数，默认盘点项目结束时间前，可改为开始时间前 |
| **开发判定** | 可开发（函数语义来自官方文档 🟡，须逐函数写单元测试） |

## REQ-360-001 360 度评估（R3-T03）

| 项 | 内容 |
|---|---|
| **规格** | `02_业务建模/25_360度评估_规格.md` |
| **首版范围** | 活动（草稿 / 启用 / 停用）；关键行为与等级评定套卷；角色（内置 + 自定义，单套卷 ≤15）与权重；角色加权计分与缺失角色默认规则；评价关系（手工 / 导入 / 按组织架构自动 / 请上级确认）；站内待办 + 邮件邀请；屏蔽、重新作答；个人报告（一个版本）与结果报表；套卷模板 |
| **不做** | 民主推荐表、多选题、指标聚合计分、去最高最低分、手松手紧、短信 / 企微 / 二维码、团队报告与多版本报告、北森胜任力库 |
| **人员（DEC-027）** | 自建 360 人员表：内外部同表、邮箱为键、可从组织员工同步、跨活动复用、外部人员可被评价；360 独立管理员身份与活动授权；无组织员工数据时可独立使用 |
| **同步规则（DEC-030）** | 关联表按员工ID挂接，保留旧员工ID与关联日志；首次同步按邮箱、手机、工号查重，冲突列给管理员确认；同步后邮箱锁定、其余可改、下次同步以组织为准；批量导入评价者可选“不同步” |
| **验收** | AC-360-01 ~ 15 |
| **开发判定** | 可开发（G-057 已由 DEC-030 决策） |
