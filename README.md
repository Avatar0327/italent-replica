## 本地演示（F-025）

在本机浏览器里以不同角色走 R1 调动主线。**仅限开发环境**：开发身份切换与本地 PGlite 只在 `NODE_ENV=development` 下可用，生产构建与生产进程里都不存在。

### 前置
- Node ≥ 22.12、pnpm（版本见 `package.json` 的 `packageManager`），已执行 `pnpm install --frozen-lockfile`。
- 不需要 PostgreSQL：未设 `DATABASE_URL` 时后端用本地 PGlite（数据在仓库根 `.demo/`，已被 git 忽略）。
- 签名密钥放仓库根 `.env.local`（已被 git 忽略）；没有时 `pnpm demo` 自动生成随机 `DEV_IDENTITY_SECRET`。键名见 `.env.example`。

### 命令
| 用途 | 命令 |
|---|---|
| 写入演示数据（幂等）并同时启动后端 `:3000` 与前端 `http://localhost:5173` | `pnpm demo` |
| 只写入演示数据（已存在则不重复写） | `pnpm demo:seed` |
| 重置：删除本地 PGlite 与演示清单后重新写入（**先 Ctrl+C 停掉 `pnpm demo`**） | `pnpm demo:reset` |

打开 http://localhost:5173 ，页面顶部的黄色“本地演示”条里有“切换演示身份”下拉；选人后自动跳到该角色的入口，各页面的租户已预填。浏览器只记住“选了谁”（Cookie），身份头由本地 vite 开发代理用 `.env.local` 里的密钥签名后转发，密钥不进浏览器。

### 角色清单（全部为合成数据，邮箱均为 example.com）
| 角色 | 演示用户 | 入口 | 说明 |
|---|---|---|---|
| 系统管理员 | 系统管理员（演示） | `/` 调动管理、`/jobs` | 租户管理员，标准“组织系统管理员”身份 + 看全部 |
| HR（HRBP） | HR专员（演示） | `/` 调动管理 | 标准“HR 管理员”身份，数据范围 = 全部一级组织含下级；兼任研发各部门 HRBP |
| 部门负责人（经理） | 平台研发部经理（演示）、数据研发部经理（演示） | `/manager` 管理者工作台 | 部门负责人即下属的直线经理，经理身份自动生效 |
| 普通员工 | 平台研发员工甲 / 乙（演示）、数据研发员工丙（演示） | `/self` 员工自助 | 本人调动申请、本人任职记录 |
| 审计管理员 | 审计管理员（演示） | 审计日志接口 `/api/tenant/audit/*` | 管理员角色 audit_admin + 只读身份 + 全部组织范围 |
| 异常管理员 | 异常管理员（演示） | — | 审批人为空时的兜底 |

演示租户：组织树 研发中心 → 平台研发部 → 前端开发组、研发中心 → 数据研发部、人力资源部、财务部；序列 技术 / 职能；职务 软件工程师 / 研发经理 / 人力资源专员 / 会计；各部门职位。调动审批流“演示调动流程”：**直接上级审批**（以员工所在部门负责人表达）→ **调入部门 HRBP 审核**。

### R1 主线走查
1. 切换为“平台研发员工甲（演示）”→ 员工自助 → 人事申请 → 本人调动：调动日期选今天，部门改为“前端开发组”，提交（状态“审批中”）。
2. 切换为“平台研发部经理（演示）”：管理者工作台“待处理”里出现这张单；审批“直接上级审批”节点。
3. 切换为“HR专员（演示）”：审批“调入部门HRBP审核”节点。生效日不晚于今天时审批通过即生效；生效日在以后的，到期后由定时生效任务落地（演示进程 30 秒轮询一次）。
4. 结果：员工自助“任职记录”出现新部门的一条记录；经理工作台“已处理”可见；HR 在调动管理里选该员工时，调动前信息已是新部门；审计管理员调 `/api/tenant/audit/data-changes` 可查到本次变更。

> 前端暂时没有审批中心页面（同意 / 驳回），第 2、3 步的处理方式待总编排窗口确认，见 PR 描述“需要产品决策的问题”。在确认前可在浏览器开发者工具里调用：`GET /api/tenant/approval/todos` 取待办，`GET /api/tenant/approval/instances/{instanceId}` 取 `revision`，再 `POST /api/tenant/approval/tasks/{taskId}/approve`（请求头 `x-tenant-id`、`If-Match: "<revision>"`、`Idempotency-Key`，请求体 `{}`）。
