## 本批目标与复用
本人任务入口、管理报表与跨模块对账，准备生产验收材料。

已有本人档案/学习/假勤/薪酬入口、待办及范围报表，尚无全量统一消息或自助报表设计器。

## 任务与退出
1. I01核对绩效/招聘/假勤/薪酬新结果是否在本人入口和待办可办理，失效记录不生成错误操作。
2. I02贯通当前组织权限、字段脱敏、导出审计、防公式注入、报表与来源版本一致。
3. I03形成G2/G3综合验收和G4缺口清单，区分本地恢复与云端恢复、API与真人UAT。
4. I04外部集成先提供字段映射和失败重试方案；无真实接口时合成桩验证，不擅自同步真实数据。

退出：以上限定闭环的成功/拒绝路径有证据，专属缺陷已修复或列出具体阻塞；G3/G4准备整体签署由总控处理。未自动通过业务/生产验收。
