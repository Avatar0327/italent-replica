1. S01贯通合成工资批次、条目、提交、独立复核、发布、异议及补差，核对报表账实。
2. S02验证整数分、金额溢出、编制参与者不可复核、本人字段与组织权限，拒绝重复发布/补差。
3. S03依赖假勤冻结契约设计版本化输入与修订处理；接口未稳定时先完成现有核定路径。
4. S04自动计算仅按明确的合成配置验证机制；正式税社保/企业薪酬制度未核实不冒充可投产，不调用支付。
