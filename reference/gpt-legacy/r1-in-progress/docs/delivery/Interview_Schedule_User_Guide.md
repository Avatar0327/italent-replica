# 内部排期—指定人员评价预验收

仅合成数据；现有所有者私有站点，不创建新在线账号或扩大访问。以下HR/指定经理是测试逻辑角色，实际人工多角色验收需已有授权成员；不能拿测试夹具名当在线凭据。

1. 建立已批准合成需求、候选和组织内定版评价表。准备独立在职面试官，其已有有效管理账号并覆盖同组织。
2. 进入“内部面试排期”，选择候选、现场/视频/电话、北京时间起止、地点说明、指定人员和评价表。预期不发送邮件、短信或会议邀请。
3. 重复相同时段，或给同一面试官另一候选安排重叠时段，应拒绝；前一场结束等于后一场开始允许。普通员工、无有效管理账号人员和跨组织人员不可成为唯一评价人。
4. 尚未结束时不能评价；结束后指定人员从排期列表“完成指定评价”进入，使用冻结表逐项评分。其他HR/经理不能代签；普通补录不能绕过仍未完成的排期发起录用。
5. HR修订/归档主评价表后，已安排面试仍使用原快照；成功评价与排期完成一同保存。重复处理不能新增完成记录；审计失败时两者均不保存。
6. 调整指定人员后，旧人立即失去关联评价权限，新人按现行角色和时间办理。调出组织/离职或账号停用后拒绝；HR可明确取消失效安排，保留原因。
7. 查看过程历史，确认调整前后人员与时间仍可追溯。指定评价通过后正常走独立录用审批；最近不通过继续阻止录用。

保留后续：多面试官/多评价表、流程轮次、完整日周月日历、会议服务、候选/面试官/抄送通知、自助约面、多时区和企业例外规则。原站表单字段已核实，实际提交规则未验证。自动化通过不代表人工业务或生产验收。
