# I04 外部适配器契约 v1：只读预验

状态：设计与隔离合成验证；未提供生产入站API、外部连接、任务调度或真实写入。原站依据为Integration_Source_Gaps BC-I01/02的菜单/视图，不声称兼容具体厂商协议。全量映射、认证、同步与消息范围保留。

## 边界与字段归属

| 字段/对象 | v1预验策略 | 后续写入准入 |
|---|---|---|
| tenantId/source配置 | 可信运行上下文，不从外部事件接受租户 | 验证服务身份、签名、作用域和源归属 |
| 外部员工/组织ID | 仅显式映射到内部稳定ID，禁止按姓名猜测 | 映射版本由责任人复核，冲突隔离 |
| code/name/job/email | 严格资料候选字段，不直接保存 | 重读当前修订、字段归属及员工范围，调用现有人事规则 |
| orgId | 候选映射，仅作为差异预览 | 组织变化须走既有调动/任职流程，不能直接覆盖 |
| 入转调离状态、岗位权限、薪酬、凭据 | v1事件不接受，未知字段拒绝 | 另设经过授权的业务契约，不用通用同步绕过审批 |
| 新人员/缺失映射 | mapping_required，不创建空组织或账号 | 新建/关联流程单独确认，不自动迁移真实人员 |

事件schema与可执行检查：`lib/hris/integration-preflight.ts`，合成证据`tests/integration-preflight.test.mjs`。事件含eventId、sourceId、externalEmployeeId、正整数sequence、occurredAt、mappingVersion及严格profile。规范化JSON排序、时间转UTC及字段trim后计算SHA-256；摘要不是签名，不能替代来源认证。

## 事件顺序和幂等

| 情况 | 输出 | 处理要求 |
|---|---|---|
| 当前映射、明确身份、正好下一序号 | ready / DRY_RUN_ONLY | 只得到候选，不产生成功回执 |
| 已持久化同租户/来源事件ID且摘要一致 | duplicate | 返回原committedRevision，不重写 |
| 事件ID同而内容不同、回执/游标不满足唯一性 | conflict | 隔离并查原因，禁止覆盖旧回执 |
| 超过下一序号 | gap | 请求缺失事件或经确认建立恢复基线，不跳过 |
| 旧序号而无成功回执 | stale | 留痕核对，不能假称已经成功 |
| 映射缺失、版本不符或多外部ID歧义 | mapping_required | 修订映射后重新预验，不创建人员 |
| 非约定字段、错误来源或schema | rejected | 脱敏错误码，不将整条个人资料写日志 |

未来提交事务必须同时保存人员变更/审批请求、不可变审计、成功回执与游标CAS；回执只能在事务成功后生成。成功响应丢失靠回执重放恢复；不能先推进游标再尝试人事写入。本轮预验没有持久化，不能单独保障端到端幂等。

## 重试与对账

纯函数integrationRetryDecision仅给建议，不启动任务：网络超时、408、429、5xx允许有限重试；每批最多6次建议，指数延迟且尊重有效Retry-After，上限1小时。401/403需恢复授权，409需读取实际状态和来源版本，400/422需更正契约；不机械重试。真实HTTP含义仍须对应供应商接口核对。

适配器层需持久化attempt、nextAttemptAt、脱敏errorCode和correlationId，加入抖动/速率限制；超过上限进入人工处理队列。实际执行器、锁租约、重放控制尚未实现。对账按来源+外部实体ID逐项核对最后序号、映射版本、内部修订和数据摘要；区分待处理/拒绝/提交成功，不把收到消息计为成功。
