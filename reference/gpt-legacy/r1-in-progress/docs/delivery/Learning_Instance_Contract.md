## 原站现场证据
BC-L02：切换空新建表单的起止时间模式，可见必填计划起止时间；切换循环模式，可见独立必填项“完成循环任务时是否重复获得积分”和“是否重复获得学分”。未填写人员、未保存、已取消。周期/循环可配置学习天数及超期是否继续；循环模式当前表单不显示主动加入选项。具体数值边界、触发循环的调度配置与提交语义仍待核实。

## 实体与兼容
1. learningPlanDefinition：不可变版本号；mode=relative/fixed/recurring；progressSync；orderedStages；orgId；课程要求列表（requirementId、courseVersionId、stageIndex、mandatory）；relative/recurring有durationDays和allowOverdue，fixed有start/end；recurring显式repeatCredit/repeatPoints。共享管理员范围与学员可学范围分别保存。
2. learningPlanAssignment：员工、计划版本、轮次、分派时间、计算后start/due、状态、前轮ID、触发来源。重复请求幂等键为计划版本+员工+轮次；调度重复执行不能产生重复分派。
3. learningRequirementCompletion：assignmentId+requirementId唯一；引用enrollmentId或明确sourceEnrollmentId、来源版本/核验时间快照；完成状态由相同消费者函数投影，不能人工覆盖前序门槛。
4. 旧enrollment记录原样保留ID。没有assignmentId的旧任务继续原唯一规则；新增带assignmentId的任务才按实例唯一，不静默把历史任务搬到新项目或重写旧考试/出勤。

## 进度模式
progressSync=true：仅当前员工、匹配课程版本、满足条件的历史进度可关联到要求；不能复制考试次数或假造线下出席。数据源撤销或权限变化须显式重新核验，冻结快照不恢复已撤权限。
progressSync=false：任务实例从零开始；exam attempts绑定实例，禁止读取旧课程通过结果作为本次过关。
进度同步设置不可修改的页面提示已核实；模式是否可修改尚未验证。内容不采用全面冻结：BC-L03说明未完成学员随内容变更重算，已完成学员默认不受影响；需显式更新已完成学员进度才重新计算。内部仍保存不可变内容版本和变更事件，未完成实例迁移到新版本需原子执行并保留旧证据；完成实例保留结项版本，显式重开才关联新版本。禁止静默改写原成绩、学分或核验记录。

## 奖励与轮次
每笔学分引用唯一实际任务/轮次/配置版本。repeatCredit=false不能因新轮次重复授予同计划课程来源；true可按实际完成的新轮次独立授予，但同轮重试仍唯一。积分独立配置，不与学分混用。撤销与到期继续按原台账计算；复制计划不能复制奖励。repeatCredit默认禁止，界面要求用户显式选择并在发布时冻结。

## BC-L03 计划内容现场核实
既有计划详情包含计划内容、计划学员、统计分析、学习资料、通知提醒。内容支持阶段顺序与阶段内任务顺序两层开关；添加内容、作业、考试、辅导、线下考核五入口；表格显示名称、类型、分钟时长、学分、状态、选必修。只读查看，未点击新增/排序/更新进度等写入操作。
原站说明：变更计划内容会重算未完成学员进度，已完成学员默认不受影响；另有显式“更新已完成学员进度”操作，可重新计算并补发待办，更新可能延迟。以上是页面规则说明，未实际提交验证。实现须保留变更版本与迁移记录，不把全面冻结计划内容当成原站要求。

## A1 配置版本持久化
新增learningDefinition记录，definitionRootId标识计划族，version顺序递增，referenceId指向前版；草稿→sealed（仅配置定版）/archived。定版版本内容不可变，后续版本仍保留冻结的progressSync；每族至多一个草稿，从最新定版继续。组织不可跨版本变更，避免更换组织引起旧历史泄漏。存储与事件复用现有事务。配置管理限admin/hr且当前组织范围，不扩展普通员工读取。

## 显式循环派发契约补充（2026-09-08）

原站有自动循环和重复奖励开关；自动触发日期细则仍待核实。当前开发内部显式 nextRound，不声称自动调度完成。首轮 assign 支持 recurring，后续由HR/admin对已结项的原循环实例指定 start，不能早于今天或上轮完成业务日。保留同一配置版本，新实例记录 previousAssignmentId 和递增 round；旧轮/重复请求拒绝，不写半批。每轮仍最多20要求和1实例原子保存。归档配置、离职/调出/组织停用均不能新派发。

后续轮次的新阶段时间从该轮 start 计算；所有课程和独立考试重新生成任务，不复用上轮完成或考试尝试。首轮仍按冻结 progressSync 处理；这个后续轮次“重新学习”策略为显式内部策略，原站完整循环同步语义待核实。取消/恢复沿用原实例，无新轮次或重置次数。

repeatCredit=false 保持同员工同课程版本一次。repeatCredit=true 的第二轮起，必须新学且整轮结项，才允许独立登记本轮课程学分；同轮重复及撤销后重授拒绝。授予快照保存实例、轮次、重复策略及原核验来源。repeatPoints 仅保存配置，积分台账与实际奖励未实现，不产生积分。历史课程/非循环学分规则保持。自动安排、循环同步细则和积分仍保留完整范围及待核实状态。
