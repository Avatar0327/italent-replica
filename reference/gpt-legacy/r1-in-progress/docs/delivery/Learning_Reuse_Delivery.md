# C1/C2 跨计划独立学习与已完成进度复用

## 已开发
有效learningAssignment内，员工+课程+实例唯一；普通enroll仍保留全员工课程版本唯一，客户端伪造实例ID、人员、课程清单、截止日期或混用trainingId/planId被拒绝。每个实例生成独立enrollment，考试仍按enrollment.id计次数与通过状态。旧取消任务恢复保留ID，不因新增实例失去恢复途径。

progressSync=false：即使已有同课程完成记录，也从独立考试/学习流程开始，不借用其他实例考试。
progressSync=true：仅在分派时查找同员工、精确相同课程版本、completed且有独立核验人与时间的原始任务；有考试时还必须存在其自身通过记录。选择最近有效核验来源，保存sourceEnrollmentId、sourceVerifiedBy/At及sourceExamAttemptId。目标任务引用该完成证据，不创建考试attempt、不移动源任务、不复制学分。没有合格来源则生成active新任务。不同课程版本、尚未核验、已取消来源不会自动等效。复用来源不再作为新的原始来源，避免无限引用链。

该实现仅支持当前单一必修课程清单的首轮relative/fixed实例。多阶段、作业、线下目标出勤、部分课程进度、动态内容迁移和循环仍后续，不宣称已覆盖全部原站同步语义。

## 学分独立规则
本系统当前采用同员工同课程版本只授予一次，覆盖普通任务、独立重学和历史复用。已有授予即使到期或撤销也不能借新实例再次领取。此为当前防止重复发放的保守实现规则，原站跨计划奖励规则未完整核实；未来循环repeatCredit策略须在独立规则版本中实现，不能声称已核实企业规则。前端待登记列表和服务端使用同一去重判断。

## 操作预验收
1. 新建带考试的合成课程，由合成学员通过考试并提交，其他HR核验；登记首次学分。
2. 另建不同步的计划，包含同一课程并派发。目标任务必须重新考试；此前通过结果不能直接提交新任务。取消恢复保留各自考试次数。
3. 新建同步的独立计划并派发。目标任务显示已完成及原任务ID/核验时间；考试记录总数不增加。确认实例开始日期已到后结项。
4. 对重学或复用任务再次授予学分应拒绝；原学分撤销后仍拒绝。原任务、核验、考试与授予事件都保留。
5. 新建相同课程编码的新版本，放入同步计划，目标应仍为待学习，不能借旧版成绩。

自动化通过不是界面、业务或生产验收。真实迁移、访问范围与生产切换保持原授权边界。
