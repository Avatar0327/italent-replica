# 学习计划课程阶段：业务预验收操作说明

状态：v78已私有发布课程要求与阶段门槛；延迟开放为本轮后续增量，发布结果以Execution_Checkpoint为准。自动化不代表用户已确认业务或生产已验收。

## 当前所有者可检查
1. 使用现有所有者身份进入“学习管理”，建立4门名称带“合成验收”的课程并发布。测试内容仅写合成案例，勿填真实人员信息。
2. 进入“学习计划配置”，新建周期30天、不同步历史、按阶段顺序的配置，选择上述4门课程，保存草稿。
3. 展开“详情与历史”，配置第一阶段包含课程A/B/C，其中A必修、B/C选修，最低必修1、选修1；第二阶段仅课程D。保存后定版。
4. 派发给同组织在职合成员工。实例应列出全部4项要求与两阶段门槛；后续版本修改不改变这个实例。
5. 核对审计历史中的配置、定版与派发记录；重复派发应被拒绝，不能产生第二份相同首轮实例。

## 多角色业务闭环（待具备授权账号后人工执行）
- 学员：初始只可办理第一阶段，D不可提前考试或提交；提交A后仅“已提交”不能解锁D。
- 独立HR/经理：核验A及B；学员此时获得D的办理入口。自我核验应被拒绝。
- 学员完成D并由独立角色核验后，HR可结项。C被关闭而非记完成，不产生C的学分；A/B/D完成历史保留。
- 已调出或离职人员的旧实例不可继续结项；取消仍可保留历史。已停用账号不得读取原学习历史。
- 开启历史同步的另一个计划仅引用同课程版本已独立核验来源，不复制考试、不重复发学分；关闭同步则须独立学习。
- 延迟开放增量上线后：阶段设加入2天后开放，即使阶段顺序关闭，也不能提前办理；复用完成记录也不能提前结项。采用中国业务日期，0代表加入当天，固定计划开始日仍为下限。

当前私有发布只面向现有所有者，不提供虚构的线上合成账号。employee/hr等example.com身份只存在于本地测试夹具，不能用于站点登录。多角色真实UI验收需另行具备合适账号及访问授权，本轮不扩大访问。

## 需要集中业务确认的限制
- 结项时关闭未完成选修是本系统明确设计；原站结项后是否仍允许继续选修尚未核实。
- 阶段截止/超期、阶段内任务顺序、独立考试与其他活动、总成绩、循环、在途内容变更仍后续。
- 云浏览器预览仍受访问限制，本轮无完整界面验收结论。现有所有者可直接操作已发布站点，但不能把接口测试身份当线上角色。

## 独立考试首批操作（上线版本以检查点为准）

1. 所有者/范围内HR从学习计划进入“独立试卷”，填写合成题目、选项、正确答案、及格线和最多次数，保存草稿后定版。修改已定版内容必须创建后续版本，原试卷保持不变。
2. 进入“独立考试任务”，选择试卷版本、同组织合成员工与考试起止日期，派发。同员工同版本重复派发被拒绝；当前不支持重复任务重置。
3. 学员用其真实获授权身份打开个人待办中的独立考试，未开始/过期/调出/离职不可答题。错误答案消耗一次机会；次数内通过后关闭作答入口，答题及状态更新一起保存。
4. HR可查看任务与成绩、取消尚在进行中的考试；取消后不清除尝试。跨组织HR和无关经理不能读取该任务或答案。
5. 考试成绩独立保存，不自动记课程完成或发学分。当前只支持等权单选百分制取整；多题型、计划绑定、总成绩仍未完成，不能签署整个学习模块验收。

线上账号边界与上文相同，本轮不创建外部访问或可冒用的合成登录。

## 课程与独立考试绑定计划（本轮后续增量）

在新计划配置中同时选择课程A和同组织定版试卷B；详情配置第一阶段A、第二阶段B，保持阶段顺序。学员先提交A，由独立角色核验后，B才开放作答。B通过后HR可核对阶段要求并结项。考试记录应出现于独立考试台账与人才档案，A仍是课程核验记录，二者不混用。

再建计划后续版本并开启既有课程进度同步：A可以引用同版本历史核验，B必须产生本实例的新考试任务和尝试；取消恢复不能让已耗尽次数的B重考。以用户实际操作结果签署业务验收，自动化仅提供技术证据。

## 计划成绩规则预验收

在含独立考试的草稿计划“详情与历史”中选择成绩规则，并明确选择是否计入未通过作答及保留小数位；定版后不可直接修改。实例页面与“学习计划要求与成绩”报表显示未配置/待定/暂计/已结项四种状态。缺少成绩显示待定，真实0分应显示0。

可用合成分数组合检验算法：A两次0/80分，B一次60分，计入全部作答时，“全部作答平均”为46.67，“各考试最高平均”为70。这个反例为本地自动化数据，线上考试通过即停止重考，构造案例时需使未通过成绩仍在允许次数内。不要伪造线上尝试或改数据库来得到结果。

成绩规则与实例完成规则独立：达到选修数量门槛不等于所有计分考试已有成绩，可能出现实例已结项但成绩仍待定。当前不自动补零或强制授分，人工业务验收需确认该策略符合企业要求。成绩只代表本系统考试，不自动作为人才评级或任用结论。

### 阶段日期与任务顺序增量（v81已发布）

固定日期计划的“几天后开放”以计划开始日计算，迟加入不会把阶段整体后移；周期模式以加入日计算。草稿阶段可勾选“按下面任务顺序学习”，用上移/下移排列课程和独立考试。默认需全部前置任务完成；课程须独立核验，独立考试须及格。可明确勾选“独立考试提交后可进入下一任务”：未及格作答能放行后续实践，但该考试仍未完成，必修门槛仍阻止结项。可用合成失败作答→后续课程提交→HR核验→结项拒绝验证，不使用真实员工数据。

当前包含选修任务的顺序同样要求前置办理，没有自动跳过；这项策略的原站细节待核实。阶段截止计日边界与晚解锁截止重算尚未核实和实现；不得把全计划截止视为阶段截止。

### 合成循环验收步骤（v81已发布）

1. HR创建一门合成课程及学分规则，创建循环计划，明确选择重复学分开关，配置定版后派发首轮。学员提交成果，另一HR独立核验并结项，登记首轮学分。
2. 在学习计划实例区填“循环下一轮开始日”，点击“显式安排下一轮”。预期产生第2轮及全新任务，第一轮历史不变；重复点击不增加任务。尚未结项、原组织不匹配、配置归档不能派发。
3. 第二轮重新学习并核验；整轮结项前不能登记重复学分。结项后，开关关闭应拒绝重复学分，开关开启可登记一次。同轮重试、撤销后重授应拒绝。学分记录显示实例/轮次及重复标记。
4. 当前不自动按时间派发，不产生积分，不发送消息。合成测试角色沿用已有测试夹具，不是可直接登录线上账号；真实多角色界面操作仍待授权账号和预览环境验收。

### 客观题合成验收（v82已发布）

HR新建独立试卷，分别配置单选2分、多选4分（两个正确选项，漏选1分）、判断1分，及格线60%。定版后派发合成学员。第一次单选/判断正确，多选仅选中一个正确项：原始4/7、显示57、未通过；第二次全对：7/7、显示100、通过，不能再次提交。含错误选项的多选应得0分，重复选项请求应拒绝且不消耗次数。HR查看考试台账及档案中的原始分；普通学员不能读取正确答案。

分数显示取整，及格按未舍入比例判断，极端权重下显示100也可能不足100%及格线；原始分及通过状态同时展示。旧单选题按旧等权规则读取；不能通过旧编辑器把新版多题型覆盖为单选。人工阅卷与题库功能尚未完成。

### 作业—课程—考试闭环合成验收（v83已发布）

1. HR在“独立作业”创建合成要求，明确提交次数并定版。学习计划选同组织定版作业、课程和独立考试；第一阶段作业→课程，按任务顺序学习并明确是否允许“作业提交后放行”；第二阶段为独立考试。派发时为每项作业选择非学员本人的在职批阅人。
2. 学员未提交作业时不能办理后续课程。启用提交放行后，提交作业可办理课程，但作业未批阅通过仍不能开启第二阶段或结项。批阅人退回后，学员提交新版本；旧版本保留，不能批阅旧版覆盖新提交。
3. HR转交批阅职责后，旧批阅人不能读取作业、提交或过程历史；新批阅人可处理原待审版本。单项取消→整单取消→整单恢复后，单项仍取消；再恢复单项应回到原待审状态，不创建新提交。
4. 作业批阅通过、课程独立核验后，第二阶段考试才开放。考试通过后HR核对并结项；HR作业台账和人才档案显示批阅记录，评分0不丢失。该流程不自动授作业学分或生成任何原站审批/消息。
5. 循环下一轮新建作业任务与提交计数，默认沿用前轮有效批阅人；可在实例区域选择统一替换的下一轮批阅人。新的提交与旧轮历史严格分开。

指定批阅人需要已绑定的合成成员身份才能实际登录操作；当前 owner-only 私有站点不因此扩大访问。上述角色夹具不是线上账号密码；真实多账号UAT与生产仍未验收。

### 内容权重合成验收（v84已发布）

选用已定版作业与考试，在计划草稿的成绩规则中选择“按内容权重计算”，作业60%、考试40%，明确计入全部或仅通过记录及精度。作业批阅85分、考试100分时，结果应为91分。课程完成不自动获得成绩权重。作业评分缺失或重交待审时显示待定；不把缺失当0，也不把剩余40%重新放大到100%。实例“查看成绩来源”和HR报表可追溯实际批阅/作答记录。

修改资源清单后需检查成绩规则，移除加权作业会清空旧权重。已派发实例保留旧版本及原成绩依据。整计划结项仅决定成绩标为已结项，不构成人工业务或生产验收。


### 内容追加更新预验收（v85已发布）

1. 用合成员工派发一份周期或固定时间计划；进度同步关闭。完成其中一门课程并由另一身份独立核验，但不要将实例结项。
2. 从最新定版配置创建后续版本，保留原课程，追加独立考试或作业并定版。作业必须有非学员本人的原组织在职批阅人。学习模式、时间及同步规则保持一致。
3. 在“未完成实例：预览并更新内容版本”选择实例和后续版本，指定新增作业批阅人，点击预览。预期看到保留/新增/移除内容和完成数量变化；预览不生成任务、不改变历史。已结项/取消、调出/离职、已过期、已有目标实例等情况应列明阻止原因。
4. 填写至少5字的更新依据并办理。预期保留同一个实例ID和原起止日；原课程任务、核验人、核验时间及学分原样保留，仅创建新增内容任务。原版本和新版本可在实例“历史”中追溯，不能再次领取已迁移的旧版本本轮实例。
5. 学员完成新增考试、作业由独立指定人员核验后再结项。并发时若提示数据变化，重新刷新预览；重复请求不能生成第二份新任务。原成绩证据不覆盖，计划成绩按目标版本配置重新计算，缺失分数保持待定。

此批为BC-L03的部分实现：未完成实例需HR逐个显式更新；不自动批量重算或补发消息。暂不支持移除/替换内容、已结项重开、循环实例更新或新增课程历史进度同步。上述边界属于当前实现限制，并非原站业务限制；不得作为全量内容更新已完成。线上所有者私有访问不因此扩大，测试身份只在合成测试中存在，人工及生产验收仍待完成。


### 内容退出与替换预验收（v86已发布）

在进行中的合成实例完成课程并登记一次学分、为考试提交一次未通过作答、为作业提交待审版本。后续定版内容移除这些要求，并保留或新增至少一项学习内容。预览须列出退出与新增清单，办理后旧任务保留原状态，附退出时间和依据；原作答、作业正文、核验及学分均不删除。新课程不继承旧课程完成状态。

退出内容不再计入当前完成门槛或成绩规则，不允许继续提交、批阅、取消/恢复；整单取消恢复也不能重激活。旧批阅人依既有范围可读历史，但没有待办。学分不因内容变更自动授予、撤销或重置去重；原课程已完成的独立学习证据仍保留。课程/考试/作业台账增加退出时间与依据，业务状态与退出标记分别展示。

限定条件：一次新增与退出合计最多20项，以保持原子操作边界；重新加入同一个已退出资源版本暂不支持，不能静默复用旧提交。循环更新、完成重开、新增课程历史同步仍待后续。退出后的后台留存方式未在原站提交验证，上述保留证据策略为本系统明确实现，待人工业务验收；非原站规则全量认证。


### 新增课程同步扩展（随内容退出增量交付）

计划开启进度同步时，新增课程可引用同员工、同课程版本、已有独立核验的原始完成记录。预览显示来源核验时间，更新结果应与预览一致；没有有效来源仍待学习。已被引用的副本不会成为新的原始来源，不复制课程考试作答或学分。可用“先独立完成课程B，再向只含课程A的同步计划追加B”验证。关闭同步时同样追加B必须重新学习。

此扩展覆盖上文“新增课程同步待实现”的旧限制；剩余仍包括循环内容更新、已完成重开、退出后重新加入的进度策略及原站完整异步批量运营。原已完成课程退出某份计划不等于撤销其独立核验；撤销核验/学分须走各自明确流程，内容更新不自动处理。


### 阶段提交期限预验收（当前增量，尚未发布）

1. 学习计划草稿中配置阶段，勾选“设置阶段提交期限”，填写天数，并明确是否允许超期提交；不勾选则保持旧版只有整计划期限的行为。定版后原实例不变，需按内容更新流程显式更新。
2. 当前明确采用北京时间自然日、计划开放当天为第1天，阶段前置任务晚完成不顺延截止。例：9月1日计划开始、延迟2天开放、阶段期限2天，截止为9月4日；9月5日起禁止新提交（若允许超期则仍受整计划期限约束）。此精确计日及超期核验策略为本系统明确配置，原站只核实了字段，尚待企业业务验收。
3. 配置不允许超期时，课程成果、独立考试、作业在截止后均不能新提交，自助可办理清单相应移除。独立HR/批阅人仍能处理期限内提交的成果；不能因为截止到期把待审历史变成无法核验。原始提交与核验时间分别保留。
4. 固定计划迟派发时，若阶段已截止且要求未完成，整单拒绝；不生成部分任务。内容更新预览也会阻止将实例切换到已过期且未完成的阶段。可通过业务允许的后续配置版本延长期限或明确允许超期，不直接改已定版旧配置。

线上多角色及跨日期人工验收仍未执行。自动化使用合成日期参数验证边界，没有修改原站设置或改线上时钟。
