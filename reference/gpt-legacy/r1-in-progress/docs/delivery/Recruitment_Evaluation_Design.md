# 结构化面试评价首批设计

依据 BC-R07，原站可见多维度、逐指标四档评分、分维度评语和独立通过/不通过结论。现有单一1–5级记录保留为旧模式，不自动迁移或换算。总分算法、权重、代评授权和岗位自动选表尚未核实。

首批建立独立的组织内评价表定义（草稿/定版/归档/后续版本），HR/admin维护；每项有稳定的显式编号、维度、名称、说明和四档标签。名称和指标由企业配置，不能把查看到的一张表作为所有组织默认。后续评价在同组织选择定版模板并冻结，保留逐项1–4分和逐维度/综合评语；通过/不通过是评价人显式结论。不生成未经配置的总分或把四分制强转五分制。

填写人继续限定当前范围内HR/admin/manager，以实际账号记为评价人，不开放指定他人代签。通过须填写全部指标；不通过允许只填结论，任何已填评分仍需合法且不补零。这是参照页面说明的限定策略，尚未核实原站提交校验。每次新评价产生独立记录并保留顺序版本；录用只消费最近一次明确建议，沿用原独立审批、原子入职和岗位容量。旧直接评价仍兼容。

安全：同组织模板与岗位匹配；不可见模板/候选403；草稿/归档模板不可新评；候选已结束/录用阶段不可评；模板修订不改历史，审计失败不落部分记录，旧revision409。原接口增加单独命令，创建请求键扩展仅在完整回归后启用，不宣称全接口幂等。

保留后续：职位固定评价表/轮次编排、面试官授权与代理链、排期/邀约/通知、自助约面、维度权重和总分、必填细则、AI、筛选和多职位投递。不得用本批补录评价替代排期。
