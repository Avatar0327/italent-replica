# 薪酬原站证据与实现差异

## BC-S01 薪酬社保导航与发薪方案（2026-09-08）
复用已有原站会话，仅只读；未修改、计算、提交、审批、支付或发消息，未导出人员工资。
可见：薪资档案/兼职档案/调薪；薪酬核算含发薪方案、活动、结果；核算相关数据含填报、经常性支付、欠款、特殊发放、推荐奖金、缓发、地区最低工资、自定义标准和导入；另有社保、资金申请/支付、个税申报缴款、激励、报表、设置。
发薪方案列表字段：名称、编辑权限、使用权限、发薪结果来源、发薪周期、税款所属期；可见系统计算、月/无固定周期和活动中维护税款所属期的显示值。没有据此假定全部可选项、计算公式或企业生效规则。
现有实现为手工核定CNY整数分、独立编制/复核、发布、异议补差及对账，非全套自动算薪和税社保支付。

## BC-S02 发薪方案空表
空表字段：方案名、适用薪资组、发薪周期、使用权限、生效日、结果来源（观察默认系统计算）、税款所属期（活动中维护）、是否个税通算税；月中调动有分别独立核算/由调入方核算全月。读取后取消，未选择开关或保存。
月中调动的企业选择未核实，不将既有按当前组织编制规则称为原站全月核算规则。薪资组和组织不是已确认的一一映射。正式税务/银行操作仍不在本轮授权内。

## BC-S03 发薪活动列表
只读列表区分进行中/已封存，活动进度为数据准备、核算、审核、发放；活动显示发薪方案版本、发薪年月起止、税款所属期、薪资组和实发合计。未前往具体真实活动、批量封存或处理原站提示的自动任务失败。

## 内部S03考勤引用设计边界
沿用原工作包已规划的“冻结考勤版本输入及修订处理”，只引用同员工、同计薪月的冻结期间汇总，不要求覆盖完整月份，不计算工资或认定扣薪。此为本项目可验证的数据一致性设计，尚未证实原站同名合同或完全相同的状态约束。
原站方案/薪资组/税款所属期/活动周期、自动核算和月中调动选项保留全量范围，不能以新增引用取代。
