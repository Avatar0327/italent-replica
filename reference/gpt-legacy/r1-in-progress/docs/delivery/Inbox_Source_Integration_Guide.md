# 统一待办与来源核对预验收

这是对既有内部业务的集成，不宣称原站所有消息、提醒和报表已复刻。

- 按薪酬考勤引用指南建立合成案例。工资来源变化时，草稿编制人看到“工资考勤来源核验”；待复核/已批准批次的独立复核人看到“工资来源变化待退回”，不再显示可直接复核或发布的待办。
- 已发布后的变化由薪酬编制人看到核对事项，不自动产生补差；进入待办应定位对应工资批次。
- 在工资考勤引用核对报表对比引用版本、当前版本、当前期间状态、原计划/请假分钟。行数为实际引用数，不代表完整月度覆盖。其他组织或非薪酬岗位不得读取，普通员工不应看到薪酬管理待办。
- 指定面试结束后，仅仍有该组织管理权限、在职且被指定的面试官看到评价待办；未来、已取消、已完成或失去资格的安排不出现。进入后应定位原排期的冻结评价表。
- 原有其他业务待办继续保留；页面与多角色业务验收仍待实际操作确认。自动化角色不是线上账号，开发数据均为合成。
