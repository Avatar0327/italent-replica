# 假种边界业务预验收

在假勤管理→假期类型，用管理员或本组织HR新建合成假种。HR必须选择有权限组织；管理员可建立全企业假种。现有旧假种保持原全企业语义，不重写历史。

1. 设置60至120工作分钟、带薪并校验余额、填写合成制度说明。在余额流水为同组织合成员工登记240分钟，并安排09:00–18:00、休息12:00–13:00的班次。
2. 员工选择该假种时应看到制度及上下限。09:00–09:30应拒绝；11:00–14:00扣除休息后为120分钟，应待审批并占用120分钟。
3. 本人不能批准；组织有权限的独立经理批准后，余额从待占用转为已用，不重复扣减。申请详情与历史保留原名称、规则和制度。
4. HR停止此假种的新申请。新申请及新余额登记被拒绝；既有待审批仍能独立处理，已批准记录仍可在非冻结期间记录依据取消，余额恢复。停止不销毁余额或记录。
5. 合成员工调至其他组织，不能再使用原组织假种；本人历史流水、余额和申请快照仍可读。新组织负责人按照当前人员权限核对历史；不会自动迁移额度到其他假种。
6. 不同组织HR不能新建/停止其他组织假种，经理不能维护规则。未填组织的全企业创建及停止仅管理员可用。

仅使用现有授权账号或隔离合成测试角色；自动化角色不是线上账号密码。本批不发放法定假期、不自动结转/清零/舍入、不按8小时换算天数、不执行工资扣减。上下限采用扣除休息后的整数工作分钟；非原站全部规则复刻。历史已发布能力照常保留，人工业务和生产验收待确认。
