# 定性指标与目标来源预验收

当前开发验证中；使用已有合成企业的HR/管理员、经理、员工角色。测试中的example.com账号仅是本地身份桩，不是线上密码或可登录账号。未建立新的线上访问范围。

1. HR打开“绩效管理→定性指标库”，在合成员工所在组织新建指标，例如编号SYN-QUALITY、分类合成质量，填写名称和衡量标准；草稿只供HR维护，定版后同组织员工可选。
2. 员工建立目标时选用指标，名称/衡量标准带入，填写符合周期规则的权重。指标衡量标准为空时须补充目标标准。允许补充目标文字，来源仍保留指标原文版本，不自动评分或指定评价人。
3. HR修订指标并将旧版本归档。旧目标详情仍能展开旧指标原文；新目标不能引用已归档版本，新选版本需要显式选择。
4. 目标确认、自评、经理评价和HR发布沿用原流程；发布结果中可以查看目标及其来源快照。指标修订不改变已发布分数、目标或盘点来源。
5. 已确认目标申请更换参考指标，由独立管理者复核。申请先冻结来源，后续归档不会将待审申请改成其他版本；复核通过与计划变更同事务保存，失败不产生半份结果。
6. 跨组织成员不应看到或选择指标；篡改客户端来源版本/名称不会改变服务端快照。未定版不能给员工新引用。

已知限制：首批仅定性、单组织、分类名称；不包含定量自动计算、指标库完整共享分类树、指定评价人、批量下发、状态批量调整或导入导出。定版修订和安全边界为本系统实现设计，不宣称复刻了原站内部数据存储。
