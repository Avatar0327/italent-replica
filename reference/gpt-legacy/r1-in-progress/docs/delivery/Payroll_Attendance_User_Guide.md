# 核定薪酬引用冻结考勤：业务预验收

使用合成组织、员工和现有授权薪酬编制/复核角色。测试逻辑账号payWriter/payReviewer仅位于隔离测试数据库，不是线上登录凭据。

1. 按期间预验收指南，由HR完成合成历史班次来源独立核验并冻结，同一期间须全部位于计划计薪月份。
2. 薪酬编制人创建同月批次，录入明确的合成核定金额。在工资条“引用已冻结考勤”勾选该员工期间，核对计划/批准请假分钟及版本。
3. 保存后金额应保持输入值，不根据请假分钟自行增减；再由独立复核角色批准，编制人发布内部工资条。员工仅见已发布本人工资，不能通过薪酬接口读取原始考勤来源或他人记录。
4. 在提交前由HR重新开放来源：提交应拒绝。重新冻结为新版本后仍不得直接使用旧引用提交；先在草稿重新核验并保存工资条，再提交。
5. 在已提交或已批准时重新开放来源：复核/发布应拒绝，页面提示来源变化。独立复核人可退回编制，重新引用最新版本再走复核。
6. 发布之后考勤发生更正：已发布金额和当时引用不变，薪酬工作台显示来源变化；是否产生补差必须另行核定并经过既有独立流程，系统不会自行生成补差。
7. 历史入口应能同时看到工资条引用V1、重编V2等快照；重复期间、其他员工、跨计薪月或不可见来源应拒绝。审计失败不得留下部分工资记录。

首批引用可选，兼容不依赖考勤的既有核定金额路径；最多31个非重叠期间，可能不覆盖完整月份，不能称为全月出勤已核实。显式移除旧引用不替代新的核定依据与独立复核。不自动税社保计算、银行转账、工资消息或真实迁移。人工和生产未验收。
