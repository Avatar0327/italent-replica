# 绩效指标库与目标引用首批契约

依据BC-P06，复用既有单维目标、模板范围、周期快照与CAS审计。所有代码由总控main唯一修改；不增加其他写入者。

## 首批可验收边界

- 定性指标：编号、名称、分类名称、描述、衡量标准；归属组织是本系统隔离边界，当前只供同组织使用。
- 草稿、定版、修订、归档；定版不可变，归档停止新引用但保留旧来源。
- 目标可选指标引用，同时保留目标自身名称/衡量标准/权重及指标版本快照。引用不会自动改变计分方式。
- 服务器根据可见、同组织、已定版指标解析新引用；不信任客户端传来的来源快照。目标编辑/调整保留已引用旧版本，显式更换才解析新版本。
- 目标变更仍独立复核并原子更新；原结果及盘点引用不被指标修订隐式覆盖。

## 必要验证

同组织/跨组织/本人权限；发布前指标不可被员工选用；归档前后新旧引用；修订版本与旧计划；客户端伪造来源拒绝或忽略并由服务端还原；重复编号和并发修订；目标调整及审计失败回滚；原无指标目标兼容。实际接口与文件实施后补入Shared_Contracts。

## 后续完整范围

定量与正反向公式、完成值采集、计量单位、汇总累计、分类树/共享组织、指定评价人、模板自动下发、批量状态与导入导出。均保留待开发；未经核实规则不默认实现。
