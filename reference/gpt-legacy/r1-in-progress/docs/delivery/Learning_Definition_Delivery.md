# 学习计划配置与版本交付（A1）

## 范围与来源
基于 BC-L01–03 已核实的三种学习模式、课程进度同步不可变和独立重复积分/学分开关，复用现有组织权限、CAS事务和事件历史。新增 /learning-plans、/api/learning-plans 与 learningDefinition 记录类型；无数据库迁移、无真实数据复制。

## 可操作范围
HR/管理员可保存草稿、修改草稿、定版、从最新定版创建后续草稿、归档。计划组织固定；重复课程拒绝；定版重新核实课程仍已发布。一个计划族仅允许一个草稿；已定版版本不被后续修改覆盖。定版后的进度同步策略不得变更。经理和普通员工不能访问配置管理接口；跨组织HR读取/修改被拒绝；当前身份与修订号仍经事务复查。

“定版”只保存配置版本，不等于向员工发布学习计划。现有培训派课、考试、核验及学分继续使用原链路。配置没有隐式定时任务，不会创建奖励或通知。

## 合成操作预验收
1. 以已有权限HR进入学习管理→学习计划配置与版本；选合成组织和已发布合成课程，新建周期/起止/循环草稿。
2. 检查模式条件字段及循环积分/学分开关相互独立；填写无效起止顺序应拒绝，保存有效配置。
3. 定版后检查编辑入口移除、历史保留；创建后续版本，修改标题/课程后定版，原版本内容不变。
4. 新版本修改进度同步策略应被服务器拒绝；重复创建草稿、旧修订提交、无权限组织操作也应拒绝。
5. 查看详情与历史，确认未生成员工学习任务或学分。此时只能验收配置管理，不能验收自动派课。
