# 干部访谈记录首批交付

依据：Cadre_Learning_Source_Gaps.md / BC-C02。本轮云端复用已有原站会话，只读核对列表、空表、类型与角色选项，空表已取消。没有提交业务、发送通知、导入导出或保存人员数据。

已开发：干部管理入口与HR人才档案摘要→访谈登记→更正→作废→不可变事件历史。字段按已观察类型/角色及200字内容上限；列表服务端20条分页及姓名/类型/角色/日期检索，档案可定位记录。没有新增审批、任用结论或通知。

独立设计边界：当前HR/admin需有被访谈人和访谈人双方的当前组织权限；经理、普通员工和审批员不能从专用API、通用记录、历史或档案读取。访谈角色只是分类，不赋权、不证明实际汇报关系。不能维护本人记录、不接受自访谈或未来日期；离职历史可以由当前有权限HR登记。更正身份键不可改，误选作废重登；重复保护与额外依据是本系统规则，未冒充原站规则。

合成验证：3专项场景覆盖更正历史/作废、身份不能替换、非HR隔离、访谈人调动收权、日期及200字、旧修订和审计失败回滚。首次测试重复绑定既有员工账号触发409，改为更新原合成账号角色；未放宽成员唯一性。最终集中247/247、0失败/跳过、14.190秒，类型通过。显式排除既有rendered-html.test.mjs运行环境限制，未宣称该项通过。精确命令与证据在Cadre_Interview_Verification.json和Cadre_Interview_Regression.tap。

预验收入口：干部管理→干部访谈记录（HR）；建立两个合成员工后登记200字以内记录、修正内容并查看旧版、作废后检查档案摘要移除。调动访谈人后原HR列表及历史拒绝访问；经理/普通员工不能读取。人工业务和生产验收未签署，原站权限、关系自动解析、审批与删除语义继续待核实。
