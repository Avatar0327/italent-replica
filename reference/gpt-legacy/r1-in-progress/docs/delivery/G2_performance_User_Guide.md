# H004 绩效合成验收操作指南

本指南依据现有页面/接口核对，未完成浏览器操作验收。仅限隔离合成环境；本轮没有创建线上账号或写入真实员工。

## 合成角色如何使用

可立即复现：在现有仓库运行 `node --test tests/g2-performance-flow.test.mjs tests/g2-performance-lifecycle.test.mjs`。测试使用共享runtime注册的身份替身，通过`act(角色ID)`在单一合成场景内切换；数据在内存SQLite中生成并在场景结束销毁，不会出现在已发布站点，也没有登录密码。

| 测试ID | 角色/范围 | 办理职责 |
|---|---|---|
| owner | admin | 配置/启动周期、发布结果、发布更正 |
| employee | employee，合成员工A | 填目标、申请调整、跟进、自评、申诉 |
| manager | manager，研发组织 | 确认目标、独立批准调整、反馈、评价 |
| hr | hr，研发组织 | 独立复核申诉；不能兼任原评价/发布人 |
| lifecycleApprover | approver，两组织 | 人事调动/离职独立审批 |
| newHR / historyHR | 对应场景中的当前组织hr | 调动后历史权限与申诉核验 |

人工操作前，需由总控提供隔离合成界面环境及真实可登录的测试身份，按此角色关系配置。测试中的example.com地址不是线上可用账号，不能输入作为真实凭据。不要用扩大站点访问替代该条件。

## 同员工主链与预期结果

| 步骤 | 页面/身份与操作 | 预期结果 |
|---|---|---|
| 1 | owner进入`/performance`，绩效周期→新增周期；期间H004-SYNTHETIC，组织研发，日期2026-01-01至2026-12-31，阈值60/80，评级待改进/达成/优秀；启动 | 周期进行中；草稿不能创建目标计划 |
| 2 | employee，目标与评价→新增目标计划；交付质量60%、团队协作40%，每项填写至少5字衡量标准 | 保存草稿；99%/101%均拒绝，不能重复建同周期计划 |
| 3 | manager点确认目标；employee通过目标调整记录进入`/performance-changes`，申请70%/30%及事实依据 | 调整待独立复核；此时自评被阻止 |
| 4 | manager点复核通过 | 调整与计划同次保存，目标V2；申请人或绩效本人不能自审，原60%/40%保留历史 |
| 5 | employee进入`/performance-checkins`，记录本人进展，选V2第一目标，进度100%，填写成果及下一步；manager提供反馈 | 跟进已反馈；自报100%不直接产生绩效分数 |
| 6 | employee回目标与评价提交自评；manager管理评价输入60、70并写依据 | 加权总分63；本人在正式发布前看不到管理评分及评价历史字段 |
| 7 | owner发布结果 | 正式结果63分“达成”；重复发布拒绝；可进入人才盘点形成63分快照 |
| 8 | owner结束周期；employee在绩效结果提出申诉；hr独立复核更正为90、80 | 更正待发布87分；原评价人、原发布人和本人不得复核；hr不能发布自己的复核 |
| 9 | owner在申诉与更正发布更正 | 新结果87分“优秀”；旧结果标历史版本，不能重新申诉；原结果、原计划评分和既有盘点快照仍63分 |
| 10 | 当前授权管理角色查看绩效报表及人才档案 | 最新绩效只有更正结果；详情与历史仍可追溯原版，重复发布更正拒绝 |

每次测试实际ID见TAP中的H004_CHAIN；人工操作可以使用相同合成姓名和数值，但记录ID应由环境生成。

## 异常验收

- 用同组织但关联该员工的manager身份确认/评价本人或批准本人调整：403；不能靠管理角色自审。
- 保留旧revision，在他人成功提交后再发布：409；刷新并核对后显式提交。已发布动作重复请求可能先返回业务400，并非所有旧请求都固定409。
- 通过人事审批将员工调到财务：原研发管理者的绩效及历史访问撤销；新组织HR可看当前授权历史。admin虽能看到两个组织，也不能批准旧周期目标或继续推进旧周期。可拒绝/撤回待审调整、取消未发布计划，再关闭周期。
- 通过人事审批离职：未发布计划停止确认/自评/评价/退回/发布及继续调整/跟进；原记录保留。已发布结果仍能由当前授权角色独立更正。
- owner显式停用离职员工账号：停用成功并保留员工关联；本人三个绩效API和历史均403。离职动作自身不会自动停用账号。
- 日期不存在或结束早于开始：400；同日起止允许。当前日历日期不自动启动/结束周期，不能据此宣称已实现企业截止规则。

服务端新增冻结规则优先于现有按钮/待办提示。部分页面仍可能显示原状态按钮，点击会拒绝；展示一致性建议已交总控/08。技术用例通过不代表G2人工业务或生产验收通过。
