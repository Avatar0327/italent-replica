# H003 / L04 历史课程复用设计（提案，未实现）

依据：H003、Scope_Register L04、SC-1；是独立设计，不是已核实的北森企业规则。首批G1正常新课程派课不依赖此增强。不得用restoreEnrollment冒充历史转认，也不改变已有enroll全员工/课程版本唯一约束。

## 申请与来源

员工或有当前组织权限的管理者显式申请。建议申请记录引用employeeId、sourceEnrollmentId、targetTrainingId、targetCourseVersionId、可选targetPlanId，保存申请原因及证据。不能接受姓名或课程名称作关联键。先只支持同员工、精确相同课程版本；不同课程/标准版本等效认定留待企业确认。跨项目目标必须不同于来源项目。

原任务须completed且有独立核验；来源考试、原出勤、学分记录及事件历史均保留。申请保存来源任务/课程/考试核验的ID与版本快照、原项目、申请者与时间；证据快照不扩大当前读取权限。目标项目须active，课程属于项目，目标员工仍在职且属于当前项目范围；目标计划须属于同员工且标准版本匹配。

## 审核与目标完成

建议状态draft→submitted→approved/returned，申请者可withdraw；独立有权限管理者核验，不得审核本人或自己提交的申请。提交和审核都重新检查源和目标的当前状态、组织权限、版本、修订号，防止申请后撤权或来源变化。失败不得产生部分记录或审计。拒绝重复的有效目标关联；并发申请以唯一性与CAS事务保证。

通过转认只形成目标的显式来源关联，不改写原enrollment.trainingId，不新建伪造考试attempt，不将源项目出勤复制到目标项目。目标此前阶段须完成；目标必修场次须独立核实出席，不能因为历史考试通过就绕过。若目标出勤未满足，保持待完成状态。需要提供可解释的目标进度计算，不能把approved申请直接当成completed学习。

既有阶段判断目前只读取同trainingId的completed enrollment，且enroll拒绝同员工/课程版本重复。实施时需总控决定新增目标完成关联模型及其消费者改造：development.ts、阶段判定、dispatch、计划结项、cadreProfile、报表和权限投影一并评审，不能在学习模块偷偷放宽全局唯一性。当前不增改公共API。

## 学分、撤回与审计

转认不触发award，不复制原学习学分；原award.referenceId仍指向唯一源任务。原学分到期或撤销按原台账计算，转认不恢复额度。未来是否允许不同目标额外学分必须另行明确，默认不授予。

批准后的撤销建议另建独立撤销事件，保留原申请与批准快照；重新计算目标进度及未结项计划。对已经结项或用于后续阶段的转认，须定义补偿/重新打开的治理规则再实现，不静默回滚已完成链路。界面应显示来源、审核者、目标出勤缺口及撤销影响。

## 实施前的合成验收清单

1. 同员工同课程版本正常申请及独立审批；申请者、学员本人自审403。
2. 错员工/错版本/来源未核验/目标已结束/计划不匹配拒绝，四张事务相关表不变化。
3. 源完成但目标前阶段未完成或必修出勤缺失，不产生目标完成。
4. 重复申请、重复审批、旧修订、并发审批不会重复关联或授予学分；审计失败整体回滚。
5. 申请后调动、离职、停用、源状态变化，按当前权限和状态拒绝；旧历史快照不恢复权限。
6. 原考试次数、核验人与来源记录不变；原学分撤销/到期不被转认恢复。
7. 档案、阶段报表、计划结项使用同一有效目标关联，撤销后的消费者一致。

待企业确认：允许转认的课程范围、有效期、证据要求、目标场次豁免是否存在及其独立审批、已结项撤销策略。上述未知规则不阻断G1新课程正常派课。

## BC-L01 原站新证据对旧提案的修订（优先于上文）
原站新建计划支持冻结的课程进度同步/不同步，以及循环学习模式。上文仅人工历史课程转认方案不足以覆盖全量复刻；不删除该方案，但将其保留为显式例外转认。
下一步模型须支持计划配置mode及progressSync不可变快照，计划课程要求与员工任务实例分离；复用历史进度和从零学习是不同完成证据。重复轮次保留不同实例，旧成绩/独立核验/出勤/学分来源不可覆写。服务端唯一性须从全员工课程版本转为经评审的任务实例约束，不能简单删除唯一检查。所有消费者（阶段门槛、计划结项、人才档案、报表、权限）同批改造并测试。原站学分再次授予规则和跨版本等效规则仍未核实，不由截图自动推断。

## BC-L02/03 修订（优先于旧提案）
原站循环学习明确分别配置重复积分、重复学分；开关存在已核实，金额及调度细则未核实。内容变更重算未完成学员，已完成默认保留、可显式更新。因此不能全面冻结发布后的内容；采用版本及显式迁移，历史可追溯。仅进度同步设置不可修改有可见证据，不能声称模式不可修改已核实。阶段支持必修/选修数量门槛，本增量落实该判断；完整实例、阶段开放期限及重开流程仍待实现。
