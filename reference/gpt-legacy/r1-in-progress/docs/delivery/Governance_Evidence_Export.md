# 治理证据只读出口 v1

本出口只读主仓库main的实际HEAD及该提交证据；Scope_Register.json仍是唯一范围/状态事实源。不修改执行队列，不运行生成器、检查器、产品测试、提交、推送、部署或数据库操作。

## 当前可用出口

执行环境命令：`python /workspace/sites/italent-hris/scripts/read-governance-evidence.py`。

输出为单个JSON，包含实际本地HEAD、分支、读取时刻、工作区是否有未提交修改，以及Scope_Register.json、Controller_Resume.md、Execution_Checkpoint.md、项目规划、P1材料和验收/部署文档的已提交原文与SHA-256。文件采用固定白名单规则；不输出凭据、产品数据、Git配置或任意路径。未提交内容不混入已提交证据，远端HEAD明确为未检查。

本命令不是公网HTTP服务。当前独立治理站点为静态Sites，尚无可以访问主仓库的持久只读运行时。现有Sites工具仅提供短期源仓库写凭据，不能把它配置到看板来冒充只读认证。因此本次没有创建或宣称已上线实时HTTPS地址。

## 认证与最小外部条件

当前命令依赖执行环境现有文件读取权限；不新增看板账户，不发放任何主仓库凭据，也不能将当前执行环境权限宣称为已经操作系统隔离的只读账户。

上线按需HTTPS读取，需要部署方提供：持久只读挂载的主仓库（或真正repository-read权限的服务身份）、私有HTTPS运行时，以及仅所有者/看板服务身份可访问的认证机制。服务只允许GET/HEAD固定证据资源，无提交/执行/上传API。写凭据不得作为替代。此条件落实前，看板继续展示最后发布快照并注明非实时。

## 版本与刷新失败

- schemaVersion：`italent-governance-evidence/1`。
- source.head：本次读取锁定的完整main HEAD；不是部署版本，也不是最近修改某份文档的提交。
- version：HEAD加文件清单内容哈希；每份文件单独SHA-256。
- observedAt：本次采集时刻，不改写证据的历史日期。
- source.workingTreeDirty：独立显示；文件内容始终来自已提交HEAD。
- 部署适用版本从原有部署证据读取；没有新证据时保持历史版本，不能按HEAD推算。

HEAD或工作区在读取期间变化、必要文件缺失、分支错误、超时/读取失败时输出ok=false并非零退出，整个新快照作废，保留最后成功快照。消费者显示“刷新失败/当前状态未核实”、最近成功时间/HEAD及本次错误；不得重置为0、提升通过状态或把旧快照时间更新为成功。认证服务未来出现401/403时须停止展示无权内容并清除会话缓存，不能以保留旧快照绕过撤权。刷新失败不调用产品流水线。

## 当前边界

这是主仓库对治理消费者的读取协议与实现。公网实时出口仍受持久只读访问条件限制；没有改变独立看板发布链，没有触发产品提交/测试/部署。安装本读取脚本的治理文档提交与以后的刷新动作严格分离。
