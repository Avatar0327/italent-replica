# G1 可操作验收指南

## 先选择可执行的验证方式

当前可直接重跑的是本地合成API场景；线上站点使用ChatGPT身份登录，没有可提供的合成账号密码，也没有测试角色切换入口。下面example.com身份只存在于测试进程，不可用于线上登录。不要给这些地址发送邀请。

### A. 在项目开发环境重跑（现在可执行）

工作目录为仓库根目录。执行：

```sh
node --test tests/g0-contracts.test.mjs tests/g1-foundation.test.mjs tests/g1-cadre-exit.test.mjs tests/g1-learning.test.mjs
```

这组是7项核心G1/契约场景，完整基础/P3回归命令见G1_Integration_Test_Result.json（116项）。每次创建空内存SQLite，加载现有迁移，API建立合成组织与人员，结束后释放；不会给线上站点写入数据。自动生成ID，不以名称关联。

| 合成身份 | 使用方式与角色 | 预期 |
|---|---|---|
| owner@example.com | fixture中act('owner')，管理员 | 建组织、标准、课程、成员；不能代替独立审批人 |
| employee@example.com | act('employee')，员工A本人 | 考试提交，不得自审；测试可临时赋经理角色仍不得自审 |
| hr@example.com | act('hr')，组织A人事管理员 | 维护/查看授权档案，出勤登记不能自核验 |
| manager@example.com | act('manager')，组织A经理 | 独立核验；不能读取HR专属人员经历 |
| approver@example.com | act('approver')，人事审批人 | 只办理分配审批，不获得人才管理权限 |
| learningOutside/exitOutside | 测试创建的组织B HR | 不得读取/修改组织A范围记录 |
| reviewerAll/managerB | 调动场景追加的独立审批人/新组织经理 | 审批调动后旧经理失去范围，新经理按当前组织可读 |

预期输出全部通过；学习诊断为two stages completed、attempts 2+1 retained、credits 300/100/200。出错时保存原错误，不直改数据库让测试通过。用户可在总控聊天要求重跑指定场景，无需提供密码。

### B. 在已发布站点进行人工界面验收（待条件具备）

使用现有所有者的正常登录会话进入站点。只在明确的合成验收空间内操作，人员工号/课程编码使用G1-UAT前缀。若已有真实业务数据，不执行初始化/覆盖。当前所有者私有访问范围不扩大。

多角色部分必须有真实可登录且已获站点访问的测试身份，以及系统内对应成员/组织授权；仅拥有合成员工档案不等于拥有登录账号。当前尚未建立这种多角色界面环境，因此不能完成整套人工UAT。不得通过修改请求头、后门或共用管理员账号冒充多角色测试。本次不要求为验收扩大访问。

以下入口与控件来自代码核对，尚未由浏览器实际走查，遇到不一致请记录截图和步骤：

| 步骤 | 入口/操作 | 合成输入示例 | 预期 |
|---|---|---|---|
| 1 | 导航台→组织管理/人员信息/岗位与职级 | G1-UAT组织A/B、员工A、岗位A | 建立可关联人员和岗位 |
| 2 | 人才与发展→能力标准→新增能力标准 | G1-UAT-ABILITY、5级可观察行为 | 保存标准版本 |
| 3 | 岗位要求、能力评估、人才盘点 | 同员工/岗位/标准，潜力无依据留空 | 发布盘点；不虚构评级 |
| 4 | 发展计划→新增发展计划 | 目标等级3、截止未来日期、可检验行动 | 计划关联同一标准 |
| 5 | 学习中心→课程资源 | 两个G1-UAT课程，同标准，考试 | 配置考试后发布课程 |
| 6 | 培训项目→草稿详情配置阶段 | 第一课→第二课；未来截止 | 启动后阶段冻结 |
| 7 | 学习任务→新增学习任务 | 同员工、培训项目、关联发展计划、第一课 | 第二课提前派发被拒绝 |
| 8 | 员工考试/提交，出勤由不同人核验 | 失败一次再通过；必修场次 | 考试/出勤不满足不能完成，自审被拒绝 |
| 9 | 第一阶段核验后第二阶段，最后计划核验 | 保留源任务与版本 | 人才档案显示同一计划/学习已完成 |
| 10 | 学分规则/授予及独立撤销 | 100/200单位，撤销100 | 300累计、100撤销、200可用，重复拒绝 |
| 11 | 审批调动/离职、企业与成员管理→停用 | 合成账号保留员工关联 | 旧组织失去范围；明确停用后所有本人读取被拒绝 |

步骤8–11的角色切换当前只在A方式验证成功。不能用管理员单账号完成后声明多角色通过。当前浏览器访问预览被环境拒绝，界面成功证据为空。
