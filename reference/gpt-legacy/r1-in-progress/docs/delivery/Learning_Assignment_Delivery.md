# 首轮独立学习实例交付 B1

## 已开发范围
周期或起止时间、progressSync=false、同组织在职员工，按已定版配置一次派发最多20门课程。实例与任务共最多21条记录，共享一次CAS修订及原子审计事务。通用多记录接口默认20条保持，只有此受约束入口显式使用21条上限。重复计划版本/员工首轮拒绝；已存在任一同员工课程版本任务时整单拒绝，不删除原唯一性约束。

实例保存课程清单、配置版本、轮次、时间及组织快照；每项课程为独立enrollment，复用考试次数、成果提交、独立核验、取消恢复和学分。课程清单目前视为单一必修阶段，不宣称已接入复杂阶段编排或线下场次。全部课程独立核验后可实例结项；取消不视为完成，取消任务需按原流程恢复或保持实例未完成。已定版配置归档不追溯取消既有实例。

## 时间与人员
周期窗口从分派业务日期起含首日；起止模式保持配置日期，可提前派发但到开始日才能学习。到期后可否继续由冻结策略控制；已提交成果可在到期后由独立管理者核验。人员调出原组织或离职，拒绝新学习/提交/核验；历史在现有权限范围保留。实例任务恢复不修改冻结截止日。上述是本系统明确实现约定；未冒充原站提交实测规则。

## 使用
在学习计划配置页定版独立学习配置，刷新下方“首轮独立学习派发”，选择同组织合成员工并派发。转到学习管理，以合成学员角色学习、考试并提交，由其他有权限HR或经理核验，回到实例页核对数量后结项。页面及报表展示实例/轮次。线上不创建伪造登录身份；当前所有者私有发布并不自动赋予多账号验收能力。
